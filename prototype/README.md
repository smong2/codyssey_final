## 실행

### 팀원이 내려받아 실행하기

1. GitHub에서 `dev-ds` 브랜치를 선택하고 **Code → Download ZIP**으로 내려받아 압축을 풀거나, `git clone --branch dev-ds https://github.com/smong2/codyssey_final.git`으로 복제합니다.
2. Node.js 22 이상이 설치된 PC에서 저장소 최상위 폴더(`package.json`이 있는 폴더)의 터미널을 엽니다.
3. 아래 실행 명령을 입력하고, **같은 PC**의 브라우저에서 `http://127.0.0.1:4173/`을 엽니다. 플레이하는 동안 터미널을 켜 두세요.

`npm install`, Python, 영상 변환 도구, API 키는 실행에 필요 없습니다. 이미지·영상·Phaser는 동봉되어 있습니다. 이 주소는 로컬 미리보기이며 다른 PC에 공유하는 공개 배포 주소가 아닙니다. 4173 포트가 사용 중이면 PowerShell에서 `$env:LUMIA_PORT=4175`를 설정한 뒤 실행하고 4175 주소를 사용하세요. 포트를 바꾸면 브라우저 저장 공간도 달라집니다.

이 버전은 엔진 전환 전 HTML UI + Phaser 온실 Adventure 프로토타입입니다. 이후 논의한 중앙 NPC/새 HUD 등의 변경 시안은 아직 반영되지 않았습니다.

별도 패키지 설치 없이 저장소 터미널에서 실행합니다.

```powershell
node prototype/server.mjs
```

브라우저에서 http://127.0.0.1:4173/ 을 엽니다. 종료는 터미널의 Ctrl+C입니다. HTML을 직접 더블 클릭하지 마세요. 이 서버는 정적 파일 제공용이며 인증·DB 백엔드가 아닙니다.

## 흐름과 조작

진입 → 룬 연출 → 타이틀 → 캐릭터 카드 → 입학 → 광장/발렌티누스/시온 → 온실 Life → Adventure → 시온과 대화/선택 → My Room/Reflection → 다이어리 저장 → 100 Heart → 자유 시간/베른 → 하루 마무리 → 다음 날 아침.

- 32명 카드·상세·확대 이미지를 볼 수 있습니다. 시작 버튼은 카엘에게만 표시됩니다.
- WASD/방향키로 8방향 이동, E/상호작용 버튼으로 조사합니다. 바닥 클릭 이동은 자동 길찾기가 없습니다.
- Knowledge는 조사로 얻은 사실 3종이며 발견 순서를 유지합니다. Item인 달빛 약초는 가방에 1개만 수집합니다.
- 3×3 Connect/Rotate 퍼즐을 90도씩 회전하여 연결합니다. 힌트는 3단계이며 벌점이 없습니다.
- 약초 채집과 회복된 꽃 재조사는 선택 사항입니다. 룬 해결 후 입구에서 바로 시온에게 돌아갈 수 있습니다.
- 메뉴/Escape의 잠시 쉬기로 Life에 돌아갔다가 탐험 진행을 이어갈 수 있습니다.
- 다이어리 저장 후 Episode 완료 보상 100 Heart를 한 번 지급합니다. 선택·힌트·Reflection 내용에 따른 평가나 보상 차이는 없습니다.
- 저녁의 베른 대화는 Reflection과 분리된 Small Choice입니다. 선택 답변은 저장하지 않고 완료 여부만 저장합니다. 다이어리는 자동으로 열리지 않습니다.
- 다음 날 아침까지 구현하며 방 밖 이동과 Episode 2는 없습니다.

## 로컬 이어하기

같은 브라우저/origin의 localStorage 키 `lumia-greenhouse-v2`를 사용합니다. 기존 `lumia-greenhouse-v1`은 읽거나 변경하지 않습니다. 새 이야기는 v2 기록 교체를 확인합니다. 저장 실패 시 이전 상태를 유지하고 정확히 같은 저장을 재시도합니다. 하루 종료 도중 다시 열면 다음 날 아침으로 이어집니다.

로그인·API·서버 저장·부모 리포트 UI는 범위 밖입니다. 태블릿 조이스틱과 입력 방식 자동 감지도 보류했습니다.

위 보류 문장은 이전 v2 기록입니다. 2026-10-05 수정에서는 좁은 화면/터치 입력을 위한 조이스틱과 행동 버튼을 추가했습니다. 실제 터치 기기 검증 범위는 VERIFICATION.md의 최신 절을 따릅니다.

## 콘텐츠와 에셋 교체

`content.json`의 assets(이미지 경로), presentation(표현 설정), dialogue(대사), choices(주요 선택), reflections(기억), bernTalk(짧은 대화), copy(화면 문구), map(배치)을 수정합니다. 주요 ID는 유지하세요. 이미지 경로는 prototype 기준이며 후속 URL 연결 시 공급 서버의 CORS 설정을 확인해야 합니다.

`characters.json`은 32명 카드 정보입니다. `tools/build-catalog.mjs`는 원문 캐릭터 문서로부터 이를 생성합니다. 카엘은 승인된 Script v2 예시를 적용했습니다.

SD의 방향·셀 크기·발 기준점·표시 크기는 `sd`, 이동 속도는 `speed`, 충돌은 `collisions`에서 조정합니다. 퍼즐 판정은 이미지와 분리된 `puzzle.mjs`에 있습니다.

원본 재사용 에셋 76개의 SHA-256이 main `c751696`의 파일과 일치합니다. 추가 발렌티누스 이미지는 사용자 제공 그림의 임시 투명 컷아웃입니다. 손·머리 주변 배경 잔여물과 보행·인물 외곽·화분 정렬, 모드별 최종 배경은 디자이너 QA/교체 대상입니다. 현재 연출은 임시입니다.

Phaser 3.90.0과 MIT 라이선스를 `vendor/`에 동봉했습니다.
