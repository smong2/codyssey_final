# Admin

Final Project에서의 관리자 범위는 **읽기 전용 플레이 기록 조회 페이지**로 최소화합니다.

## 목표

게임과 동일한 Firebase Email/Password 계정으로 로그인한 사용자가 자기 계정의 플레이 기록과 완료한 엔딩 편지를 확인할 수 있게 합니다. 원래 검토했던 보호자 전용 계정·자녀 연결 기능은 이번 프로젝트 범위에서 제외합니다.

## 최소 기능

- 이메일/비밀번호 로그인
- 인증된 UID의 자기 기록만 조회
- 회차 완료 횟수와 마지막 플레이 시각
- 세이브 슬롯별 상태·플레이 캐릭터
- 수업·모험·미니게임·NPC 만남 등 주요 누적 플레이 기록
- 확인한 직업 엔딩 목록
- 완료 회차에 저장된 엔딩 편지 읽기

## 하지 않는 기능

- 다른 사용자 검색·조회
- 사용자 정지·권한 변경
- 게임 데이터·스탯·해금 수정
- 콘텐츠 CRUD
- 운영 통계 대시보드
- 별도 보호자 계정과 자녀 계정 연결

페이지 자체가 비밀번호를 저장하지 않고 Firebase Authentication을 사용합니다. 조회 API는 FastAPI에서 Firebase ID Token을 검증하고 인증된 UID와 조회 대상 UID가 일치하는 경우에만 읽기 데이터를 반환합니다.

계정 탈퇴 후에는 해당 UID의 세이브·Global Meta·엔딩 기록이 모두 삭제되므로 이 페이지에서도 더 이상 과거 기록을 조회할 수 없습니다.

상세 기능·비기능 요구사항은 `document/12_REQUIREMENTS_ARCHITECTURE.md`를 기준으로 합니다.
