# 게임 콘텐츠 핵심

기본 흐름: `캐릭터 선택·입학 → 아르카디아 생활 → 사건·대화·조사 → 필요한 경우 직접 탐험 → 선택과 해결 → 세계 변화 → 마이룸·기록 → 다음 이야기/하루`.

- **에피소드**는 갈등·탐색·선택·변화·돌아보기의 완결된 이야기 단위다. 직접 탐험이 필수인 것은 아니다.
- **이벤트**는 조건에 따라 일어나는 장면이다. **목표**는 지금 할 일을 한 문장으로 보여 준다.
- **대화·선택**은 정답 맞히기가 아니다. 중요한 선택은 이후 대화·인물·룬·환경에 영향을 줄 수 있다.
- **지식/단서**는 알아낸 사실, **아이템**은 가진 것이다. 지식은 새 대화·행동·상호작용에 영향을 줘야 한다.
- **조우·퍼즐**은 이해하고 해결하는 장면이다. 독립 전투·체력·죽음·게임 오버·점수 벌점을 기본 체계로 삼지 않는다.
- **세계 변화**가 주요 성취 표현이다. **마이룸/베른/기록**은 안전한 돌아보기의 공간이다.
- 하루는 실제 시계가 아닌 의미 있는 이야기 행동으로 진행한다.
- 후속 장소별 탐험, 질문 풀/서버, 제작·수리 범위, 보호자 피드백 형식은 미정이다.
