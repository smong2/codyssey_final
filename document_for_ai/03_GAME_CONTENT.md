# 게임 콘텐츠의 기본 구조

이 문서는 **기획상 콘텐츠 유형**을 설명한다. 모든 유형의 제작·구현·검수가 끝났다는 의미는 아니다.

현재 기본 흐름: `주인공 선택 → 메인 스토리 → 마이룸 → 52주 주간 육성 → 최종 메인 이벤트 → 미래 직업 엔딩 → 다음 회차`. 한 주에는 월~금 5회의 직접 행동이 있으며 `수업(1~2분 미니게임) / 모험(탐험·획득·NPC 조우) / 휴식(체력 회복)` 중에서 계획한다. 토·일은 별도 선택 없이 지나가며 체력을 소폭 회복한다. 메인 이벤트의 회차와 발생 주차는 시나리오 확정 후 결정한다.

| 요소 | 의미와 경계 |
|---|---|
| 에피소드 | 하나의 갈등을 발견하고 변화와 돌아보기까지 경험하는 이야기 단위. 직접 탐험은 선택적이다. |
| 이벤트·목표 | 이벤트는 조건에 따른 장면·반응, 목표는 지금 할 일을 알려 주는 짧은 문장이다. 반복 숙제형 체크리스트를 기본으로 삼지 않는다. |
| 대화·선택 | 모든 대화에 선택지가 필요한 것은 아니다. 중요한 선택은 이후 인물·대화·룬·환경에 영향을 줄 수 있으며 도덕적 정답을 강요하지 않는다. |
| 탐험·조사 | 같은 아르카디아 장소를 직접 이동하며 관찰·조사·채집·상호작용한다. 인물이 플레이어가 발견할 답을 먼저 말하지 않는다. |
| 지식·단서 | 알아낸 사실. `아이템=가진 것`, `지식=알게 된 것`으로 구별하며 새 대화·행동·길에 영향을 준다. |
| 아이템 | 재료, 도구, 이야기 물건, 수집품. 이야기 물건을 임의로 판매·소모하는 자원처럼 다루지 않는다. |
| 조우·퍼즐 | 존재·환경·룬 이상·인물의 문제를 이해하고 해결한다. 독립 전투·체력·죽음·게임 오버·점수 벌점을 기본 체계로 삼지 않는다. 실패는 정보 또는 다른 방법을 제공한다. |
| 세계 변화 | 식물·장소·NPC·룬이 선택에 반응하는 주요 성취 표현. 별도 점수보다 변화를 직접 보게 한다. |
| 마이룸·기록 | 베른과 휴식하고 오늘의 선택을 돌아보는 개인적이고 안전한 공간. |
| 주간 일정 | 월~금 5회의 행동을 계획한다. 체력이 낮으면 성장 효율이 떨어지며 무리하면 강제 휴식 상태에 들어갈 수 있다. 강제 휴식 후에는 체력 70% 이상 회복이 필요하다. |

보이는 육성 요소는 `체력 / 지식 / 표현 / 기량 / 탐구 / 룬`이다. 체력은 소모·회복되는 현재 자원이고 나머지는 회차 내 성장 스탯이다. 화면에 숫자로 표시하지 않는 성향은 `공감 / 책임 / 호기심 / 용기 / 협력 / 독립성 / 신중함 / 솔직함`이며 도덕적 선악 점수가 아니라 이벤트·대화·엔딩 조건에 사용하는 플레이 성향 기록이다.

NPC는 모험 맵에 1~2명이 등장할 수 있으며 균등 랜덤보다 `기본 출현률 + 장소 + 주차/시기 + 관계·스토리 + 메인 진행 + 최근 미등장 보정`을 이용한 가중 랜덤을 사용한다. 엔딩은 최소 10종 이상의 미래 직업을 목표로 하며 `보이는 스탯 + 숨은 성향 + 특정 이벤트 + NPC 관계/스토리 + 플레이 행동·선택`을 조합해 결정한다.

수집 배지는 약 200개를 목표로 하고 20~25개 이상의 작은 카테고리로 나눈다. 카테고리 완성으로 캐릭터·펫·배경·작은 영구 체력/스탯 보너스 등을 해금할 수 있다. 최초 캐릭터는 남녀 각 3~4명 정도, 최종 플레이 가능 캐릭터는 32명이며 펫은 기본 1마리에서 추가 해금한다. 배경은 미니게임 기록으로 퍼즐 조각을 모아 완성·해금한다.

저장은 여러 슬롯을 두고 언제든 이어할 수 있게 한다. 회차 종료 후 배지, 캐릭터·펫·배경 해금, 엔딩 기록, 카테고리 영구 보너스는 계승하며 일반 회차 스탯·현재 체력·NPC 관계·스토리 진행·주차 일정은 초기화한다. 세이브 슬롯 간 메타 진행 공유 여부는 미정이다.

새 에피소드에서는 경험 목표, 시작·종료 상태, 중심 갈등, 단서, 필요한 상호작용, 중요한 선택, 세계 변화와 돌아보기를 연결해 검토한다. 필요 없는 요소를 억지로 넣지 않는다. 후속 장소별 탐험 범위, 질문 풀·서버 연결, 제작·수리 범위, 보호자 피드백 형식은 **미정**이다.
