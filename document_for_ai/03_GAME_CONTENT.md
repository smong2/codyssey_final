# 게임 콘텐츠의 기본 구조

AI 엔딩 구현 상태: 엔진의 최종 이벤트·엔딩 프레임은 직업/편지 준비·실패·3개 섹션 표시와 조회 adapter 연결 지점을 제공한다. 현재 엔진 개발 시안의 `전체 흐름 보기`에서는 짧은 사용자 승인 예시를 볼 수 있지만, WBS 4.1 최종 메뉴 계약에서는 이 개발용 진입점을 제거한다. 실제 엔딩 판정·AI 생성·회차 완료·보상은 아직 처리하지 않는다. API·정식 직업 조건·대표 기록 선별·안전 검증·fallback 생성·결과 저장은 후속이다. [엔진 프레임 안내](../engine/ENDING_FRAME.md)를 따른다.

이 문서는 **기획상 콘텐츠 유형**을 설명한다. 모든 유형의 제작·구현·검수가 끝났다는 의미는 아니다.

현재 기본 흐름: `주인공 선택 → MS01 입학·온보딩 → 52주 주간 육성 → 12월 24일 MS06 최종 위기 해결 → 마지막 자유 플레이 주간 → 12월 31일 마지막 주간 요약 → 무엇을 지켰니? → 미래 직업 엔딩·개인화 편지 → 다음 회차`. 한 주에는 월~금 5회의 직접 행동이 있으며 `수업(1~3분 이내 미니게임) / 모험(숨은 목표 아이템 탐색) / 휴식(마이룸에서 휴식 선택)` 중에서 계획한다. **일정 시작 뒤 월~금 활동은 각 결과 저장 성공 후 다음 일정으로 자동 진행하고, 정상 평일 진행에서 휴식만 마이룸을 활동 공간으로 사용한다.** 토·일은 별도 일정과 체력 자동 회복 없이 지나가며 날짜가 자유로운 메인 외 이벤트의 우선적인 표시 구간으로 활용할 수 있다. 메인·서브·NPC·지역 이벤트는 일반 일정 슬롯을 소비하지 않는다. 메인 스토리 배치는 `1/1, 3/5, 6/4, 9/3, 12/3, 12/24`의 해당 주 일반 일정 시작 전으로 확정한다.

| 요소 | 의미와 경계 |
|---|---|
| 에피소드 | 하나의 갈등을 발견하고 변화와 돌아보기까지 경험하는 이야기 단위. 직접 탐험은 선택적이다. |
| 이벤트·목표 | 이벤트는 조건에 따른 장면·반응, 목표는 지금 할 일을 알려 주는 짧은 문장이다. 반복 숙제형 체크리스트를 기본으로 삼지 않는다. |
| 대화·선택 | 모든 대화에 선택지가 필요한 것은 아니다. 중요한 선택은 이후 인물·대화·룬·환경에 영향을 줄 수 있으며 도덕적 정답을 강요하지 않는다. |
| 탐험·조사 | 유리 온실·대서고·별빛 천문대에서 직접 이동하며 모든 목표의 방향 단서와 조사 피드백을 사용해 보이지 않는 아이템을 제한시간 안에 찾는다. |
| 지식·단서 | 알아낸 사실. `아이템=가진 것`, `지식=알게 된 것`으로 구별하며 새 대화·행동·길에 영향을 준다. |
| 아이템 | 재료, 도구, 이야기 물건, 수집품. 이야기 물건을 임의로 판매·소모하는 자원처럼 다루지 않는다. |
| 조우·퍼즐 | 존재·환경·룬 이상·인물의 문제를 이해하고 해결한다. 독립 전투·체력·죽음·게임 오버·점수 벌점을 기본 체계로 삼지 않는다. 실패는 정보 또는 다른 방법을 제공한다. |
| 세계 변화 | 식물·장소·NPC·룬이 선택에 반응하는 주요 성취 표현. 별도 점수보다 변화를 직접 보게 한다. |
| 마이룸·기록 | 오늘의 선택을 돌아보고 수집·기록을 확인하는 개인적이고 안전한 공간. |
| 주간 일정 | 활동 카드를 월~금 5칸에 모두 등록한 뒤 시작한다. 날짜 미지정 선택은 가장 이른 빈 평일에 순차 배치하고 특정 날짜를 먼저 지정할 수도 있다. 시작 전 삭제·재배치 가능, 시작 후 일반 일정 수정 불가다. 모험은 계획 단계에서 장소까지 지정한다. 월요일부터 금요일까지 한 활동 결과 저장이 성공하면 마이룸을 경유하지 않고 다음 예정 활동 화면으로 자동 전환하며 휴식 일정만 마이룸에서 무엇을 하며 쉴지 선택한다. 일정은 `수업 / 모험 / 휴식 / 특수 활동`을 사용한다. 수업은 체력 10, 모험은 15를 활동 시작 시 소비하고 기숙사 `요정의 거래`는 주 1회·체력 0이다. 휴식은 40/50/70 중 하나를 무작위 회복한다. 체력 10~30은 저체력이며, 하루 시작 시 0~9이면 그날부터 또는 활동 시작 비용으로 0~9가 됐다면 다음 평일부터 평일 3일의 기존 일정을 잠긴 강제휴식으로 교체한 뒤 체력 100으로 복귀한다. |

보이는 육성 요소는 `체력 / 지식 / 표현력 / 솜씨 / 탐험 / 마법`이다. 체력은 `0~100`, 시작값은 100이며 소모·회복되는 현재 자원이다. 나머지 5개 성장 스탯은 `0~500`, 기본 시작값은 50으로 두고 캐릭터 초기 보정과 수집 영구 보너스를 회차 시작값에 반영한다. 미니게임 난이도는 해당 `run.stats`가 `0~100 / 101~200 / 201~350 / 351~500`일 때 각각 쉬움/보통/어려움/매우 어려움으로 정하고, 실패는 `+0/+1/+2/+3`, 성공은 `+5/+6/+7/+8`, 대성공은 난이도와 무관하게 `+10`을 준다. 체력 10~30에서는 펫 보정까지 500 상한을 적용한 최종 유효 성장 스탯을 70%로 사용하고 획득 성장량은 50%로 줄이며 저장 원본은 깎지 않는다. 보이지 않는 스탯은 `공감 / 책임 / 호기심 / 용기 / 협력 / 독립성 / 신중함 / 솔직함`의 8종, 각 `0~300`, 시작값 0이다. 대화·이벤트 선택을 주 성장 수단으로 하며 일반 선택 `+3`, 중요 선택 `+5`, 핵심 이벤트 `+8`, 명시적으로 관련된 미니게임 성공은 `+1`만 적용하고 감점하지 않는다. 보이지 않는 스탯은 도덕적 선악 점수가 아니라 이벤트·대화·엔딩 조건에 사용하는 플레이 스타일 기록이다.

본편 7개 공간 콘텐츠는 **6개 미니게임 + 기숙사 특수 활동 1개**로 확정한다. `OBS 별빛 천문대 → 거울 마법 → 탐험`, `CLK 시계탑 야외무대 → 별빛 무대 → 표현력`, `GH 유리 온실 → 정령 화분 정리 → 지식`, `DRM 기숙사 공용 공간 → 요정의 거래 → 성장 스탯 최대 5포인트 1:1 이전`, `LIB 대서고 → 봉인 서가 → 지식`, `WRK 마도 공방 → 룬 회로 → 마법`, `TRN 수련장 → 룬 핀 훈련 → 솜씨`를 사용한다. 거울 마법과 룬 회로만 기존 독립 데모의 핵심 조작을 본편에 재채택하고 나머지 데모 게임은 본편 기준으로 사용하지 않는다. 교육 문제를 직접 출제하기보다 게임 행위 자체에서 기억·분류·추론·선택적 주의·표현을 사용하게 하는 것을 원칙으로 한다.

6개 본편 미니게임은 `FAIL / SUCCESS / GREAT`를 반환하고 결과 화면에서 즉시 다시 하기를 제공하지 않는다. 사용자가 `포기하기`를 누르면 `FAIL`로 확정한다. 같은 게임 2회 연속 실패 시 다음 플레이 난이도를 1단계, 4회 이상이면 최대 2단계 낮추지만 성장 보상은 원래 `run.stats`로 정한 `rewardDifficulty`를 유지한다. 성공/대성공 시 해당 게임 연속 실패 횟수를 0으로 초기화한다. 비정상 종료 `INTERRUPTED`는 FAIL에 포함하지 않는다. `engine/minigame-demo/`는 독립 참고 구현이며 본편 세부 규칙은 `document/content/06_01_LOCATION_ACTIVITIES.md`를 우선한다.

NPC는 모험 맵에 1~2명이 등장할 수 있으며 균등 랜덤보다 `기본 100 + 장소 일치 50 + 진행 중 스토리 80 + 메인 연관 40 + 최근 미등장 주당 10(최대 60)`의 가중치를 사용한다. 숫자형 친밀도·호감도는 사용하지 않고 `encounterCount / lastEncounterWeek / storyProgress / eventFlags`로 조우와 이야기를 관리한다. NPC·서브·공간 스토리 이벤트는 합쳐 주당 최대 2회, 하루 최대 1회이며 동일 NPC 스토리는 주당 1단계만 진행한다. 선택지는 `선택별 짧은 반응 → 중립 공통 대화`로 합류해 어떤 답을 골라도 다음 대사가 앞선 답과 모순되지 않게 한다. 향후 대사에 필요한 선택만 플래그로, 엔딩 편지에 의미 있는 중요 선택만 대표 선택으로 저장한다. 엔딩은 작가 `story/ending/ENDING_STORY.md`의 **룬 연구자 / 아르카디아 탐험가 / 마도 장인 / 약초 정원사 / 아카데미 수호 기사 / 아카데미 교사 / 아카이브 기록관 / 마법 공연가 / 마법 생물 돌봄이 / 아카데미 행사 기획자**를 정규 직업 10종으로 채택하고, fallback `별길 개척자` 1종을 별도로 둔다. 작가 원문의 직업명·부제·직업 의미·미래 첫걸음 방향은 고정 원고로 보존하되, 판정 조건은 현재 시스템의 단순 규칙에 맞춰 대표 성장 스탯 `300 이상`을 필수 조건으로 하고 보조 스탯·보이지 않는 스탯·관련 활동의 선택 조건 3개 중 충족 개수를 적합도로 사용한다. 여러 정규 후보가 있으면 미노출 우선 → 적합도 → 직업별 대표 기록 → 대표 성장 스탯 → 랜덤 순으로 판정하고, 만족한 후보가 모두 이미 본 엔딩이면 정규 후보 전체에서 랜덤으로 결정한다. 정규 필수 조건을 하나도 만족하지 못하면 준비된 직업을 억지 배정하지 않고 `ENDING_STARPATH_PIONEER / 별길 개척자`를 확정하며, 이 횟수는 `endingViewCounts`에 누적하되 정규 엔딩 해금 수에는 포함하지 않는다. **직업 엔딩 판정은 게임 규칙이 수행하고 생성형 AI는 판정 결과를 바꾸지 않는다.** 12월 31일에는 마지막 주간 요약 뒤 작가의 고정 질문 `무엇을 지켰니?`를 먼저 보여 준다. 이 질문의 답을 AI가 대신 정하지 않는다. 대표 사건 목록은 AI 입력에서 제외하고 백엔드가 선별한 실제 횟수형 플레이 기록 4~6개와 중요 선택 최대 2개만 개인화 입력에 사용한다. `아르카디아에서의 기록` 라벨·숫자는 UI가 직접 표시하고 AI는 작가 원문의 직업 의미와 미래 장면 범위 안에서 성장 회고와 응원 문장만 생성한다. 편지는 어린이의 실제 성격·심리·진로를 진단하는 표현을 사용하지 않는다. 상세 기준은 [AI 핵심 기능](../document/09_AI_ENDING_LETTER.md)을 확인한다.

직접 모험은 `유리 온실·약초원 / 대서고 / 별빛 천문대` 3곳을 사용한다. 난이도에 따라 보이지 않는 목표 아이템 `1/2/3~4/5개`를 시작점에서 실제로 도달 가능한 충돌 영역 안에 배치한다. 시작 전 모든 아이템의 입구 기준 시계 방향 단서를 공개하고 하나를 추적할 수 있으며, 추적하지 않은 아이템을 우연히 정확히 조사해도 발견으로 인정한다. 조사 횟수는 제한하지 않는다. 제한시간은 탐험 50 이하 120초, 50~500에서 120~240초 선형 증가, 500 이상 240초이며 활성 펫 탐험 보정을 포함하고 저체력 감소로 시간까지 줄이지 않는다. 단서 읽기·1~2초 조사 연출·NPC/Location Story·로딩 중에는 타이머를 멈춘다. 전부 찾으면 `MISSION_COMPLETE`, 시간 초과면 `TIMEOUT`이다. TIMEOUT에서는 이번 판의 발견 아이템을 실제 획득으로 남기지 않아 다음 도전에서 다시 찾으며, 한 개 이상 찾았다면 발견 비율에 따라 성공보다 작은 탐험 성장 일부만 남긴다. 비정상 종료 `INTERRUPTED`는 목표 아이템과 부분 성장을 남기지 않는다. 세부 계약은 `document/content/10_COMMON_ENGINE_FRAME.md`를 따른다.

수집 배지는 `5개 대분류 × 5개 소분류 × 소분류당 8개 = 총 200개`로 확정한다. 대분류는 `탐험과 발견 / 배움과 성장 / 활동과 성취 / 관계와 공감 / 각성과 선택`이며 기존 5개 프레임과 25개 심볼을 그대로 사용한다. 소분류별 8개 조건은 모험·수업·NPC·발견·행동 태그·퍼즐·캐릭터·펫·엔딩 같은 계정 누적 기록의 단계값으로 정의한다. 각 소분류는 `2/8 → 5/8 → 8/8`에서 해당 대분류 성장 스탯을 영구 `+1`씩 지급해 한 소분류 최대 `+3`, 한 성장 스탯의 배지 영구 보너스 상한은 `+15`다. 체력 영구 보너스는 사용하지 않으며 영구 보너스는 현재 회차에 소급 적용하지 않고 다음 회차 생성 시 반영한다. 대분류 40/40 완성은 추가 수치 없이 골드 강조와 완료 알림만 제공한다. 디자인은 `대분류 프레임 5종 + 소분류 심볼 25종 + 공용 장식 8종 + 상태 표현 3종`의 조립형 구조를 사용하며 미획득 배지는 공통 잠금 아이콘을 쓴다. 최초 캐릭터는 남 3명 `카엘 / 로빈 / 니코`, 여 3명 `세라 / 아이리스 / 티아`의 총 6명이며 성장 스탯 보정 없이 시작한다. 추가 26명은 각자 `+10/-10` 초기 보정을 가지며, 23명은 지정 배지 소분류 `5/8`, `CH13`은 첫 52주 완료, `CH14`는 서로 다른 엔딩 3개, `CH32`는 서로 다른 엔딩 10개로 해금한다. `펫과 함께`와 `새로운 얼굴!` 배지는 순환 의존을 피하기 위해 캐릭터 해금 조건으로 사용하지 않는다. 조건은 플레이 중 달성할 수 있지만 실제 캐릭터 해금은 회차 종료 시 일괄 확정하며 한 회차에 여러 조건을 만족하면 모두 해금한다. 본편 펫은 `PET01~PET10`의 서로 다른 10마리이며 `PET01`을 기본 해금하고 나머지 9마리를 순차 해금한다. 데모의 단일 펫 캐릭터 베른 설정은 사용하지 않지만 `asset/bern/` 내부의 부엉이·여우·토끼·수달·강아지·고양이·레서판다·다람쥐·고슴도치·아기사슴 10개 이미지는 번호 순서대로 `PET01~PET10`의 실제 본편 자원으로 사용한다. 이름은 `에든 / 루엔 / 포포 / 마린 / 토비 / 니브 / 로코 / 피핀 / 브램 / 세렌`으로 확정한다. 해금된 펫은 마이룸의 가방 → 펫 탭에서 언제든 활성 펫 1마리를 선택할 수 있으며 잠긴 펫은 선택할 수 없다. `PET01~PET07`은 주 `+5`·부 `+3`, 후반 수집 보상 `PET08~PET10`은 두 성장 스탯을 각각 `+5` 보정한다. 보정은 저장 성장 스탯을 직접 바꾸지 않는 임시 효과다. 해금 조건은 `첫 엔딩 / 캐릭터 10명 / 모험 100회 / NPC 스토리 5개 / 서로 다른 엔딩 3개 / 캐릭터 18명 / 배지 소분류 1개 8/8 완성 / 수업 150회+모험 150회+NPC 만남 30회 / 캐릭터 25명`을 `PET02~PET10`에 차례로 적용한다. 마이룸 배경은 기본 기숙사방 외에 추가 기숙사방 3종을 두고 각 12조각, 총 36개의 고유 퍼즐로 해금한다. 미니게임·모험·NPC 만남·계열별 수업의 최초/누적 조건을 달성할 때 전체 미획득 조각 중 하나를 균등 랜덤으로 지급하며 중복·특정 배경 우선·천장 보정은 사용하지 않는다.

저장은 계정 단위 Global Meta Progress + 5개 세이브 슬롯 구조를 사용한다. `이어서 하기`에서는 항상 5개 카드를 보여 주며 빈 슬롯은 `저장 기록 없음`으로 표시한다. 특정 슬롯 로드 실패는 저장 상태가 아닌 UI `LOAD_ERROR`로 취급해 `다시 시도 / 삭제`를 제공하고 EMPTY로 추정하거나 자동 덮어쓰지 않는다. 5개 슬롯이 모두 사용 중이면 `새로 시작하기`를 비활성화하고 삭제가 필요하다는 이유를 직접 표시한다. `새로 시작하기`는 빈 슬롯이 있을 때만 가능하고, 캐릭터 확정 후 첫 빈 슬롯에 초기 회차 저장이 성공해야 MS01과 실제 플레이를 시작한다. 자동 저장은 `새 회차 생성 / 주간 일정 확정 / 각 활동 시작 체크포인트 / 각 활동 결과 확정 / 주간 종료 / 엔딩 확정`을 안정 경계로 사용한다. 활동 시작 때 `IN_PROGRESS`와 체력 선차감 상태를 저장한 뒤 콘텐츠를 실행한다. 활동 결과 저장 성공 뒤에는 다음 일정으로 자동 진행하며 저장 실패 시 전환을 멈추고 재시도한다. 비정상 종료 후 `IN_PROGRESS`가 남으면 해당 활동을 `INTERRUPTED`로 소비하고 성장량·연속 실패 카운트는 바꾸지 않은 채 복구 저장 후 다음 평일 일정으로 자동 진행한다. 정상 흐름과 복구 흐름 모두 휴식 일정일 때만 마이룸을 활동 공간으로 사용한다. 미니게임 보드와 모험의 숨은 좌표·남은 시간·임시 발견 목록 같은 활동 중간 상태는 저장하지 않는다. 캐릭터·펫·배지·배경·엔딩·영구 보너스와 장기 누적 기록은 Global Meta로 유지된다.

계정 UI는 Email/Password + 이메일 인증을 사용하며 **로그인 페이지 영역이 회원가입과 이메일 인증 완료 확인까지 담당**한다. 인증된 현재 브라우저 세션은 명시적 로그아웃 전까지 유지한다. 현재 게임에는 계정 외 별도 설정 카테고리가 없으므로 `환경설정` 상위 뎁스를 만들지 않고 마이룸 게임 메뉴에 `계정`을 직접 둔다. 계정 화면은 연결 이메일·최초 가입일을 읽기 전용으로 보여 주고 `비밀번호 변경 / 다른 기기에서 모두 로그아웃 / 이 기기에서 로그아웃 / 계정 탈퇴`를 제공한다. 현재 비밀번호를 아는 경우 재인증 후 게임 내부에서 새 비밀번호를 직접 설정하며, 현재 비밀번호를 잊은 복구 상황에서만 이메일의 외부 재설정 링크를 사용한다. `다른 기기에서 모두 로그아웃`은 기존 원격 인증 세션을 폐기한 뒤 현재 기기를 새 세션으로 재인증해 유지하는 일회성 보안 동작이다.

최신 타이틀 UI 결정: 저장된 슬롯이 없으면 `시작하기`만, 하나 이상 있으면 `새로 시작하기 / 이어서 하기`를 표시한다. 두 시작 버튼은 첫 빈 슬롯 자동 배정 → 캐릭터 선택이며 별도 빈 슬롯 선택 화면을 표시하지 않는다. 빈 슬롯이 없으면 안내하고 덮어쓰지 않는다. `이어서 하기`는 타이틀 위 한 열 슬롯 프레임으로 열리며 실제 최근 저장 슬롯의 바로가기를 맨 위에 추가한다. 캐릭터 선택 확정 전에는 회차를 생성하지 않고 새 게임 뒤로가기는 타이틀, 다음 회차 뒤로가기는 슬롯 프레임으로 돌아간다.

최신 사용자 결정: 펫 선택 진입점은 별도 환경설정이 아니라 마이룸의 **가방 → 펫 탭**이다. 해금·`activePetId`·임시 보정·슬롯 공유 규칙은 기존 펫 기획을 그대로 유지한다. 같은 문서의 이전 `환경설정` 표기는 이 결정으로 대체한다.

현재 본편 기획의 일정 UI 규칙: 계획 중에는 활동 선택 시 가장 이른 빈 평일에 순차 등록하거나 특정 날짜를 먼저 선택해 넣을 수 있고, 등록 날짜를 눌러 상세 확인·삭제 후 재등록할 수 있다. 5칸이 모두 채워져야 시작하며 시작 후에는 일반 일정 수정이 불가하다. 모험은 일정 작성 때 3개 장소 중 하나까지 정한다. `요정의 거래`는 `SPECIAL` 일정으로 주 1회만 등록할 수 있다. 엔진의 현재 구현 상태가 이 기획을 모두 충족하는지는 별도 검수 대상이다. 지난 활동 이미지는 흑백이며 원본 일별 완료 기록을 다이어리에서 주별로 묶어 표시한다. 현재 엔진의 온실 SD 이동·흑백 충돌 마스크는 모험 구현의 출발점이며, 본편 최종 계약은 숨은 아이템 배치·단서·조사·120~240초 타이머·성공/TIMEOUT·부분 성장까지 포함한다. 대서고·별빛 천문대 맵 자원과 이 탐색 로직의 실제 구현은 후속이다. 본편의 기획과 구현 완료를 구분한다.

새 에피소드에서는 경험 목표, 시작·종료 상태, 중심 갈등, 단서, 필요한 상호작용, 중요한 선택, 세계 변화와 돌아보기를 연결해 검토한다. 필요 없는 요소를 억지로 넣지 않는다. 모험 목표 아이템의 최종 카탈로그·사용처, 질문 풀·서버 연결, 제작·수리 범위, 보호자 피드백 형식은 **미정**이다.
