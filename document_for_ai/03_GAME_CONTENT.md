# 게임 콘텐츠의 기본 구조

이 문서는 **기획상 콘텐츠 유형**을 설명한다. 모든 유형의 제작·구현·검수가 끝났다는 의미는 아니다.

기본 흐름: `캐릭터 선택·입학 → 아르카디아 생활 → 사건·대화·조사 → 필요한 경우 같은 장소를 직접 탐험 → 선택과 해결 → 세계 변화 → 마이룸·기록 → 다음 이야기/하루`.

| 요소 | 의미와 경계 |
|---|---|
| 에피소드 | 하나의 갈등을 발견하고 변화와 돌아보기까지 경험하는 이야기 단위. 직접 탐험은 선택적이다. |
| 이벤트·목표 | 이벤트는 조건에 따른 장면·반응, 목표는 지금 할 일을 알려 주는 짧은 문장이다. 반복 숙제형 체크리스트를 기본으로 삼지 않는다. |
| 대화·선택 | 모든 대화에 선택지가 필요한 것은 아니다. 중요한 선택은 이후 인물·대화·룬·환경에 영향을 줄 수 있으며 도덕적 정답을 강요하지 않는다. |
| 탐험·조사 | 같은 아르카디아 장소를 직접 이동하며 관찰·조사·채집·상호작용한다. 인물이 플레이어가 발견할 답을 먼저 말하지 않는다. |
| 지식·단서 | 알아낸 사실. `아이템=가진 것`, `지식=알게 된 것`으로 구별하며 새 대화·행동·길에 영향을 준다. |
| 아이템 | 재료, 도구, 이야기 물건, 수집품. 이야기 물건을 임의로 판매·소모하는 자원처럼 다루지 않는다. |
| 조우·퍼즐 | 존재·환경·룬 이상·인물의 문제를 이해하고 해결한다. 독립 전투·체력·죽음·게임 오버·점수 벌점을 기본 체계로 삼지 않는다. 실패는 정보 또는 다른 방법을 제공한다. |
| 세계 변화 | 식물·장소·NPC·룬이 선택에 반응하는 주요 성취 표현. 별도 점수보다 변화를 직접 보게 한다. |
| 마이룸·기록 | 베른과 휴식하고 오늘의 선택을 돌아보는 개인적이고 안전한 공간. |
| 하루의 흐름 | 아침·낮·저녁은 실제 시계나 방치 시간이 아니라 의미 있는 이야기 행동으로 진행한다. |

새 에피소드에서는 경험 목표, 시작·종료 상태, 중심 갈등, 단서, 필요한 상호작용, 중요한 선택, 세계 변화와 돌아보기를 연결해 검토한다. 필요 없는 요소를 억지로 넣지 않는다. 후속 장소별 탐험 범위, 질문 풀·서버 연결, 제작·수리 범위, 보호자 피드백 형식은 **미정**이다.
