# 팀 역할·협업 경계

현재 제공된 문서에는 팀원별 실명 담당자·최종 승인권자 명단이 없다. 이름이나 배정을 만들어 내지 않는다. 확인된 영역과 참고 브랜치는 아래와 같다.

| 영역 | 디렉터리 | 참고 브랜치·관리 |
|---|---|---|
| 엔진 | `engine/` | `dev-ds` |
| 스토리 | `story/` | `dev-hs` |
| 디자인 | `asset/` | `dev-jw` |
| 백엔드 | `backend/` | 사용자 직접 관리; 브랜치 미기재 |

`prototype/`은 보존 영역이고 `lumia/`는 최종 통합 영역이다. 기획·제품, 검수·운영의 개인별 배정은 미정이다. 브랜치는 참고 정보일 뿐 AI가 임의로 전환하지 않는다. 기획 결정이 바뀌면 관련 팀 문서를 먼저 확인하고 이 폴더의 요약을 동기화한다. 이미지 교체 시에는 파일, 사용 상태, 문서 링크를 함께 확인한다. 사람에게 의사결정이 필요한 항목을 AI가 임의로 확정하지 않는다.

`engine/minigame-demo/`는 엔진 작업 영역의 **독립 실행형 7종 미니게임 데모**이며 통합 게임이 아니다. 엔진 담당자가 이식할 때는 해당 폴더의 README와 통합 프롬프트를 확인하고, Scene의 결과를 수업·성장 시스템에 연결한다. 데모의 수업 제안명과 점수는 최종 확정값이 아니다.
