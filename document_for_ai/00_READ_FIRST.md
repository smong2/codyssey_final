이 폴더는 LUMIA 관련 작업을 시작하는 AI에게 제공할 **간결한 기준 정보**입니다. 이 문서와 아래 파일을 먼저 읽고, 필요한 상세 내용만 `../document_new/`에서 확인하세요. 파일을 읽지 않은 상태에서 과거 대화의 기억만으로 결정하지 마세요.

## 출처와 충돌 처리

1. `document_new/`가 팀원용 현재 공유 기준입니다. 이 폴더는 그 요약본입니다. 두 곳이 충돌하면 최신 상세 문서를 확인하고 차이를 사용자에게 알려 주세요.
2. `asset/`은 작업용 이미지 집합입니다. 파일 존재를 최종 승인이나 적용 검수 완료로 해석하지 마세요.
3. `lagacy/`는 기존 자료의 출처 보관소입니다. 새 문서와 충돌하는 오래된 제안·시안은 현재 결정으로 승격하지 마세요.
4. 근거가 없는 일정, 개인별 담당, 기술 선택, 자원 최종 선정은 `미정`으로 표시하고 필요한 결정을 요청하세요.

## 변경 확인·반영

새 작업을 시작하거나 여러 턴에 걸쳐 작업하는 중 관련 파일이 바뀌었을 때:

1. `node tools/check-doc-sync.mjs`를 실행하여 상세 문서와 이 요약본 사이의 변경 여부를 확인합니다. 실행할 수 없다면 관련 파일의 변경 시각이나 `git diff`를 확인하고 직접 다시 읽습니다.
2. 변경된 상세 문서와 연결된 AI 요약을 다시 읽습니다. 최신 사실을 현재 작업에 적용하고, 다른 문서와 모순이 있으면 먼저 차이를 보고합니다.
3. **문서 갱신 작업을 요청받은 경우** 상세 문서와 AI 요약을 함께 수정한 뒤, 변경 확인 기록을 갱신합니다. 단순 열람·답변 요청이라면 사용자의 파일을 임의로 고치지 않습니다.
4. 판단이 필요한 미정 항목은 추론만으로 확정하지 않습니다.

변경 확인 도구는 문서 내용을 대신 해석하지 않습니다. 변경을 알려 주는 안전장치이며, AI가 실제 파일을 다시 읽어야 합니다.
