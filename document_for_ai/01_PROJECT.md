# 프로젝트 핵심

- LUMIA는 약 9~11세 어린이가 아르카디아의 학생이 되어 관계를 맺고 사건을 탐색하는 웹 기반 판타지 생활 어드벤처 게임이다.
- 핵심 순환: `사건 발견 → 관찰·경청·탐색 → 선택 → 인물·룬·환경의 반응 → 마이룸에서 돌아보기`.
- 교육을 전면에 내세우거나 선택을 정답/오답·성격 점수로 채점하지 않는다. 실패는 정보와 새 방법을 얻는 과정이다.
- 생활 화면과 직접 탐험 화면은 같은 아르카디아 장소를 다른 방식으로 표현한다.
- 데스크톱·모바일의 읽기·선택·조작을 고려한다. 엔진, 서버, DB, 로그인과 배포 선택은 미정이다.
- 보호자 맥락은 아이의 감시·평가가 아니라 대화의 계기다. 아이의 개인 기록 원문 공개는 전제하지 않는다.
