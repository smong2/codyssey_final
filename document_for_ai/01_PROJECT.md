# 프로젝트 개요·환경

## 제품 정의

LUMIA는 약 9~11세 어린이가 룬 학원 **아르카디아**의 학생이 되어 친구와 관계를 맺고, 사건을 탐색하며, 자신의 선택이 세계에 남기는 변화를 경험하는 **웹 기반 판타지 생활 어드벤처 게임**이다. 10대 학생 캐릭터 32명이 설정되어 있다. 목표 경험은 `사건 발견 → 관찰·경청·탐색 → 선택 → 인물·룬·환경의 반응 → 마이룸에서 돌아보기`이다.

## 변하지 않는 설계 원칙

- 재미와 몰입을 앞세운다. 교육적 메시지나 도덕적 정답을 설명·채점하는 게임이 아니다.
- 선택은 `착함/나쁨`이나 성격 점수 대신 대화, 관계, 룬, 환경의 변화로 표현한다.
- 실패는 종료·벌점이 아니라 새 정보, 힌트 또는 다른 방법을 얻는 과정이다.
- 어린이의 개인적인 돌아보기는 안전한 맥락에 둔다. 보호자 경험은 감시·평가가 아니라 대화의 계기를 지향하며, 개인 기록 원문 공개를 전제하지 않는다.

## 제품·기술 경계

- 데스크톱·모바일에서 읽기·선택·조작 가능한 웹 게임을 지향한다.
- 생활 화면과 직접 탐험 화면은 **같은 아르카디아 장소**를 서로 다른 방식으로 표현한다. 별개의 세계나 단계형 맵으로 단정하지 않는다.
- 콘텐츠에는 안정적인 ID와 교체 가능한 데이터·이미지 연결을 지향한다.
- 엔진, 서버·DB, 로그인, 배포 플랫폼, 실제 저장 계약과 담당자는 **미정**이다. 특정 라이브러리나 서비스를 이미 채택한 것으로 쓰지 않는다.
- 이 문서는 제품 방향의 요약이다. 구현 여부·현재 기술 환경을 묻는 작업에서는 실제 코드와 설정 파일을 직접 확인한다.
