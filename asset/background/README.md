## 파일 이력과 사용 기준

- 게임용 마이룸 구도 1의 낮·노을·밤은 같은 가구 배치를 유지합니다. 구도 2도 시간대 3장을 별도 세트로 유지합니다.
- 루트의 테마 파일명은 `BG11_myroom3_rune`, `BG11_myroom4_cosmos`, `BG11_myroom5_princess`, `BG11_myroom6_botanical`입니다. 복원한 창가 독서실은 과거 `myroom/myroom3_reading_*` 경로를 유지하므로 `myroom3` 번호만으로 두 테마를 동일시하지 않습니다.
- 공주방·식물방의 낮은 기존 시안을 재사용했고, 우주방은 창밖을 아르카디아 호수·학원 풍경으로 조정했다는 제작 이력이 있습니다. 과거 콘셉트 파일은 현재 폴더에 없어 링크를 달지 않았습니다.
- 이전 생성 원본과 구도 검토 자료는 이 폴더 밖의 작업 이력 또는 Git 기록을 확인해야 합니다. 현재 `asset/background/` 하위의 30개 PNG를 미리보기와 경로 검증 기준으로 삼습니다.
