# Audio Assets

게임에서 사용하는 음악과 효과음의 위치와 연결 상태를 정리합니다.

## 폴더 구성

- `bgm/`: 배경 음악 트랙
- `sfx/`: 버튼·화면 조작 효과음

파일명과 확장자는 역할을 알 수 있는 영문 소문자 및 `.mp3`로 통일합니다. 엔진에서 경로와 파일명을 명시적으로 연결하므로, 이름을 바꾸면 `engine/src/core/title-audio.mjs`와 `engine/server.mjs`의 오디오 목록도 함께 갱신해야 합니다. 확장자의 대소문자만 바꾼 경우에도 Git에 이름 변경을 기록해야 다른 운영체제에서 같은 경로로 재생됩니다.

## 배경 음악

| 파일 | 용도 | 재생 방식 |
| --- | --- | --- |
| `bgm_title_intro.mp3` | 인트로 영상 | 1회 재생. 영상이 먼저 끝나도 트랙은 계속 재생 |
| `bgm_title_main.mp3` | 타이틀·캐릭터 선택·슬롯 선택 | 반복 재생. 인트로 트랙이 끝나기 약 6초 전 교차 페이드 시작 |
| `bgm_admission_invitation.mp3` | 입학 초대장부터 시계탑 광장 장면까지 | 해당 흐름에서 사용하는 1회성 트랙 |
| `bgm_myroom.mp3` | 마이룸 | 반복 재생 |
| `bgm_clocktower_plaza.mp3` | 시계탑 광장 | 파일은 준비되어 있으나 현재 엔진 흐름에는 별도 트랙으로 연결되지 않음 |

## 효과음

| 파일 | 용도 |
| --- | --- |
| `sfx_button_click.mp3` | 활성화된 버튼의 기본 클릭 효과음 |
| `sfx_diary_open.mp3` | 다이어리 열기 버튼 전용 효과음 |

마이룸 메뉴의 소리 설정에서 BGM과 효과음을 따로 켜고 끌 수 있습니다. 화면의 스피커 버튼은 BGM만 제어합니다.

## 추가·교체 방법

1. 음악은 `bgm/`, 효과음은 `sfx/`에 둡니다.
2. 기존 파일을 교체할 때는 연결된 파일명을 유지하면 경로 변경이 필요 없습니다.
3. 새 트랙을 연결할 때는 엔진 오디오 매니저에 파일 경로를 등록하고, 로컬 서버 허용 목록에도 추가합니다. 효과음은 필요한 트리거에 연결합니다.
4. 엔진 테스트에서 트랙 전환과 오디오 경로 응답을 확인합니다. 실제 브라우저 재생·음량 검수는 게임 미리보기에서 진행합니다.

엔진 미리보기 서버는 허용 목록에 등록된 오디오 파일만 제공합니다. 새 파일을 폴더에 복사하는 것만으로는 게임에서 재생되지 않습니다.
