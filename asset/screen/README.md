# screen 이미지

화면 흐름·레이아웃 참고 PNG/JPG 40장입니다. 합쳐진 화면 시안이며 개별 UI 부품이나 실행 화면이 아닙니다. 흐름 번호는 현재 게임의 확정 진행 순서를 의미하지 않습니다. 이미지 존재가 최종 게임 적용 승인을 의미하지 않습니다.

| 식별명 | 명칭·참고 용도 |
|---|---|
| SC02~SC04 | 게임 시작·캐릭터 선택·온실 어드벤처 |
| ADV01 / LIFE01 | 확장 탐험맵 / 마이룸 측면 대화 구성 원본 |
| FLOW01~FLOW05 | 타이틀·캐릭터 선택·입학 초대장·광장 대화·온실 생활 |
| FLOW06~FLOW11 | 탐험 진입·회랑 이동·식물 발견·발견 기록·약초 발견·획득 |
| FLOW12~FLOW18 | 가방·단서 영역·룬 발견·퍼즐·힌트·환경 회복·생활 복귀 |
| FLOW19 | 이야기 선택; bust는 상반신 배치, proportion_revision은 비율 수정 |
| FLOW20 | 마이룸과 상반신 배치 변형 |
| FLOW21~FLOW22 | 마음 돌아보기·마음 일기 |
| ROOM01 | 중앙 일기 테이블 / 기존 배치 |
| ROOM02 | 창가 작업대 / 창가 수집품 |
| ROOM03 | 서고 연결 / 중앙 일기 |
| ROOM04 | 전경 작업대 / 전경 일기 |
| ROOM05 | 일기·수집품 분리 / 일기·수집품 코너 |

파일명을 풀어 쓴 안내입니다. 같은 번호의 변형을 최종 채택본으로 임의 확정하지 않습니다. 개별 미리보기는 아래에 모두 유지합니다. 게임용 전체맵은 [map](../map/README.md), 개별 UI 재료는 [ui](../ui/README.md)를 확인합니다.
