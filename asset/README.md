# 이미지 자원 안내

이 폴더는 게임 제작에 활용할 수 있는 이미지의 작업용 모음입니다. 이미지가 이 폴더에 있다고 해서 최종 미술 승인 또는 화면 적용 검수가 끝났다는 뜻은 아닙니다. 과거 원본·후보·검토 기록은 현재 저장소에 포함되어 있지 않습니다.

| 폴더 | 내용 | 현재 구분 |
|---|---|---|
| [character/](character/README.md) | 학생 32명 전신, 엘리아 보정 변형, 베른 기존 이미지 | 학생 전신은 후속 가장자리 검수 필요; 베른 최종 외형 미정 |
| [item/](item/README.md) | 아이템 20종, 조사 오브젝트와 상태 변형 | 개별 사용 장면·상태 확인 필요 |
| [background/](background/README.md) | 아르카디아 장소 배경 10종(1920×1080) | 장소별 화면 적용 검수 필요 |
| [environment/](environment/README.md) | 바닥·식물·구조물 등 환경 요소 | 배치·경계·가림 검수 필요 |
| [puzzle/](puzzle/README.md) | 타일 바탕과 연결/회전 상태 그림 | 규칙·시각 상태 연결 검수 필요 |
| [ui/](ui/README.md) | 카드·초대장·가방·기록·힌트·대화창·로고 등 | 로고 변형 선택, 화면 합성 검수 필요 |
| [effect/](effect/README.md) | 룬 빛, 달빛 광휘 | 합성·동작 검수 필요 |

지도 콘셉트, 화면 시안, 상태창, 생성 원본과 채택되지 않은 후보는 현재 이 폴더에 없습니다. 파일명은 기존 자원 ID를 유지했습니다. 자세한 연결과 사용 시 주의는 [이미지 자원 문서](../document/04_ASSETS.md)를 참고하세요.

디자인 작업 영역의 참고 브랜치는 `dev-jw`입니다. 브랜치를 임의로 전환하지 않습니다. 이미지를 추가·삭제·교체하면 해당 카테고리 README의 파일 목록, 설명, 미리보기를 같은 작업에서 갱신합니다.
