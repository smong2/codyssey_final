현재 폴더의 파일 구성이 기준입니다. 기존 펫은 bern에서 확인하며 character·item과 구분합니다. 타이포그래피는 폰트 분류에 포함되지만 파일은 기존 typography 경로에 유지합니다. source·화면 시안·변형은 각 README의 설명으로 구분하며 최종 채택을 임의로 정하지 않습니다. 원본·이전 버전의 로컬 보관은 각 폴더 기록을 따릅니다. 관련 기획은 [이미지 자원 문서](../document/04_ASSETS.md)를 참고하되 현재 자원 구성과 최신 사용자 결정을 우선합니다.

디자인 작업 영역의 참고 브랜치는 `dev-jw`입니다. 브랜치를 임의로 전환하지 않습니다. 이미지를 추가·삭제·교체하면 해당 카테고리 README의 파일 목록, 설명, 미리보기를 같은 작업에서 갱신합니다.
