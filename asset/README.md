# 이미지 자원 안내

현재 저장소의 에셋 구성을 기준으로 합니다. 각 폴더 README에서 파일 목록과 미리보기를 확인합니다. 이미지 저장, 디자인 선택, 게임 구현·화면 검수는 서로 다른 상태입니다.

| 폴더 | 내용 | 현재 구분 |
|---|---|---|

현재 폴더의 파일 구성이 기준입니다. 본편 펫 이미지는 `asset/pet/PT01~PT10`이며 게임의 `PET01~PET10`과 번호 순서대로 대응합니다. 타이포그래피 시안은 `asset/font_files/typography/`에 있습니다. source·화면 시안·변형은 각 README의 설명으로 구분하며 최종 채택을 임의로 정하지 않습니다. 원본·이전 버전의 로컬 보관은 각 폴더 기록을 따릅니다. 관련 기획은 [이미지 자원 문서](../document/04_ASSETS.md)를 참고하되 현재 자원 구성과 최신 사용자 결정을 우선합니다.

디자인 작업 영역의 참고 브랜치는 `dev-jw`입니다. 브랜치를 임의로 전환하지 않습니다. 이미지를 추가·삭제·교체하면 해당 카테고리 README의 파일 목록, 설명, 미리보기를 같은 작업에서 갱신합니다.
