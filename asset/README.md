# 이미지 자원 안내

이 폴더는 게임 제작에 활용할 수 있는 이미지의 작업용 모음입니다. 이미지가 이 폴더에 있다고 해서 최종 미술 승인 또는 화면 적용 검수가 끝났다는 뜻은 아닙니다. 원본·후보·검토 기록은 `../lagacy/document/03_characters/`에 보존했습니다.

| 폴더 | 내용 | 현재 구분 |
|---|---|---|
| `character/` | 학생 32명 전신, 엘리아 보정 변형, 베른 기존 이미지 | 학생 전신은 후속 가장자리 검수 필요; 베른 최종 외형 미정 |
| `item/` | 아이템 20종, 조사 오브젝트와 상태 변형 | 개별 사용 장면·상태 확인 필요 |
| `background/` | 아르카디아 장소 배경 10종(1920×1080) | 장소별 화면 적용 검수 필요 |
| `environment/` | 바닥·식물·구조물 등 환경 요소 | 배치·경계·가림 검수 필요 |
| `puzzle/` | 타일 바탕과 연결/회전 상태 그림 | 규칙·시각 상태 연결 검수 필요 |
| `ui/` | 카드·초대장·가방·기록·힌트·대화창·로고 등 | 로고 변형 선택, 화면 합성 검수 필요 |
| `effect/` | 룬 빛, 달빛 광휘 | 합성·동작 검수 필요 |

지도 콘셉트, 화면 시안, 상태창, 생성 원본과 채택되지 않은 후보는 여기로 옮기지 않았습니다. 해당 자료는 보관소에서 확인할 수 있습니다. 파일명은 기존 자원 ID와 추적 가능성을 위해 유지했습니다. 자세한 연결과 사용 시 주의는 [이미지 자원 문서](../document_new/04_ASSETS.md)를 참고하세요.
