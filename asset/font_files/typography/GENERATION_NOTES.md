# 타이포그래피 시안 재생성 메모

이 문서는 이전 디자인 작업 보관 폴더를 정리해도 타이포그래피 5안의 제작 방향을 다시 재현할 수 있도록 핵심 생성 조건을 남긴 기록입니다. 현재 PNG 5장은 `asset/font_files/typography/`에 있으며, 이 메모는 새 폰트를 확정하거나 기존 이미지를 자동 승인하는 문서가 아닙니다.

## 공통 방향

- LUMIA의 따뜻한 아카데믹 클래식 판타지 분위기
- 어린이용 게임이지만 유치한 모바일 게임풍, 둥근 버블 레터링, 과한 장식은 피함
- 비교용 보드 기준 1536×1024 가로형
- 따뜻한 아이보리 바탕 `#f7f2e6`, 짙은 에버그린 계열 글자 `#293b34`
- 골드 장식은 작은 구분선 정도로만 제한
- 사진 질감, 책 목업, 만화풍, 가짜 룬 치환, 3D 금속 효과, 별·광휘·그라데이션으로 글자를 꾸미는 방식은 사용하지 않음
- 한글은 실제 읽을 수 있는 정상적인 음절 블록으로 표현하고 장식용 가짜 동아시아 문자처럼 만들지 않음
- 비교 문구는 `마음의 기록 / LUMIA / 오늘의 이야기 / 카엘 · 하젤`
- 이미지 레터링 시안이며 완성 한글 웹폰트가 아님

## 5개 방향

### 1. 학술형 세리프

- 한국어 학술 서적 제목 계열
- 약간의 캘리그래피성 획 굵기 변화
- 절제된 유기적 삼각형 진입부
- 가로:세로 획 대비 약 1:3
- 안정적인 네모틀과 충분한 속공간
- 라틴은 부드럽게 연결된 세리프의 고전 휴머니스트 로만
- 학원·도서관의 품위와 따뜻함을 목표

### 2. 비문형 세리프

- 곧고 단단한 획, 넓고 안정적인 비례
- 획 대비 약 1:1.8
- 짧고 각진 쐐기형 세리프
- 단단한 네모틀과 기념비적 균형
- 라틴은 석각 대문자 계열
- 과도하게 흐르는 꼬리 획은 사용하지 않음

### 3. 문학형 세리프

- 유기적인 한국어 명조 계열
- 획 대비 약 1:2
- 여유로운 속공간과 작고 부드럽게 연결된 세리프
- 자연스러운 둥근 `ㅇ` 형태
- 라틴은 르네상스 서적 로만 계열
- 지나치게 날카롭거나 검처럼 긴 끝획은 피함

### 4. 달빛형 세리프

- 세로로 길고 좁은 음절 비례
- 매우 가는 가로획과 긴 세로획, 대비 약 1:5
- 작은 세리프 포인트와 절제된 타원형 구조
- 라틴 대문자 높이는 일정하게 유지
- 넓은 자간과 높은 획 대비로 신비감을 표현하고 별·광휘 효과는 사용하지 않음

### 5. 필사본형 세리프

- 단단한 네모틀을 유지하면서 약한 오른쪽 필기 움직임
- 넓은 펜촉 느낌의 점진적인 굵기 변화
- 절제된 붓 진입부와 자연스러운 곡선
- 성숙한 문학적 필사본 인상
- 귀엽거나 마커펜 같은 글씨, 큰 장식 스와시는 피함

## 후속 판단 기준

- 제목·이름용 개성 있는 글자와 긴 본문용 가독성 글꼴을 분리합니다.
- 큰 제목 시안을 축소했다고 본문용 폰트가 완성된 것으로 보지 않습니다.
- 최종 방향을 선택한 뒤에만 고정 문구 확장, 인물명 확장, 작은 크기 획 보정, 벡터화와 실제 코드 포인트 범위를 결정합니다.
- 비교 단계에서 참고한 방향은 Cormorant의 제목용 대비·세리프 구조, EB Garamond의 고전 서적 비례와 읽기 리듬, Noto Serif KR의 한국어 명조 가독성입니다. 특정 글꼴의 윤곽을 복제하는 근거로 사용하지 않습니다.
