# 맵 에셋

이 폴더의 이미지 22개를 아래에 모두 표시합니다. 미리보기와 파일 링크는 같은 폴더의 실제 파일을 가리킵니다. 크기는 이미지 자체의 픽셀 기준입니다. `MP01`은 온실, `MP02`는 대서고, `MP03`은 별빛 천문대의 **이동용 전체맵·가림 전경·충돌 마스크**입니다. 스토리 대화의 화면 배경은 [background/README.md](../background/README.md)에서 찾습니다. 맵 파일 보유와 엔진 연결 완료는 구분합니다. MP02·MP03의 새 마스터 PNG는 이전보다 파일 용량이 크고 구도도 달라졌지만, 현재 엔진이 읽는 월드·썸네일 WebP는 기존 파일을 유지합니다.

## MP02·MP03 마스터 갱신 기록

| 장소 | 이전 마스터(브랜치 이력) | 현재 마스터 | 적용 상태 |
|---|---:|---:|---|
| MP02 대서고 | 3840×2161 · 13,369,241바이트 | 3840×2161 · 14,149,644바이트 | 같은 픽셀 크기의 새 구도. 게임용 WebP는 기존판 유지 |
| MP03 별빛 천문대 | 3840×2161 · 13,932,037바이트 | 3840×2162 · 14,020,750바이트 | 세로 1px 증가한 새 구도. 게임용 WebP는 기존판 유지 |

새 마스터는 파일 용량이 커졌지만 픽셀 해상도는 MP02가 동일하고 MP03은 세로로 1px만 늘었습니다. 전경·충돌 마스크와 새 구도의 위치 정합을 확인하기 전에는 마스터를 기존 게임용 WebP 경로에 덮어쓰지 않습니다. 현재 엔진은 기존 3840×2160 월드 WebP·1920×1080 썸네일 WebP·전경·충돌 마스크를 사용합니다. 원본 PNG는 `MP번호_장소_역할_실제해상도` 규칙으로 표시합니다. 이 README의 파일 보유는 새 마스터의 엔진 적용 완료를 뜻하지 않습니다.
