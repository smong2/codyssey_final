# 루미아 프레임 전체화면 시안 21장

캐릭터 선택, 스탯, 백팩, 다이어리, 일정, 캐릭터 카드, 마이룸을 1920×1080 PNG로 내보낸 **화면 검토용 시안**입니다. 이 폴더의 [`screen/`](./screen/README.md)에 있는 과거 흐름 참고 이미지나 분리된 게임 UI 에셋과 구분합니다. 각 그림은 UI와 배경을 합친 이미지이며, 조작 가능한 구현 화면이나 최종 채택본으로 간주하지 않습니다.
