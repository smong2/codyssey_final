# UI 이미지 목록 (`asset/ui/`)

이 폴더에는 이미지 **84개**(PNG 64개, SVG 18개, JPG 2개)와 이 README만 있습니다. 로컬과 GitHub `dev-jw`의 이미지 파일을 대조했고, 동명 파일의 내용은 일치했습니다. 검토용 실행 코드와 별도 작업 문서는 로컬 `asset/ui_review_local/`에 보존합니다.

`lumia_logo_final_034.png`가 확정 로고이며 기존 신비 로고 1안·5안은 시안입니다. 다이어리·백팩·메뉴의 녹색/아이보리 버튼 6개는 각각 실제 투명 PNG입니다. 나머지 화면·프레임·버튼 변형은 제작·비교 자료이며 이미지가 있다는 사실만으로 게임 적용이나 동작 검수가 끝난 것은 아닙니다. 버튼 속 고정 문구 시안과 동적 UI 텍스트는 구분합니다.

목록의 파일명을 누르면 원본을 열 수 있습니다. 미리보기는 같은 파일을 축소 표시합니다. 크기는 원본 픽셀 기준이고 SVG는 `viewBox`를 표기합니다.

## 제작 이력

- UI01~UI04와 UI07의 `source` 파일은 출력본과 구분한 생성 원본입니다.
- `journal_button_icon_019~023.svg`는 대화 기록 버튼 아이콘 검토안입니다. `title_layout_*` 10개는 대화 제목 5안과 참조 카드 제목 5안으로, 실제 텍스트는 UI에서 별도로 배치하는 방향의 시안입니다.
- 다이어리 5안은 책·시간순 기록·북마크·편지함·서고 기록함 구조를 비교합니다. 날짜 표시 및 주간 플래너의 내용은 검토용 예시이며 실제 게임 데이터가 아닙니다.
- 검토용 HTML·JavaScript·CSS와 작업 기록은 로컬 보존본에 있습니다. GitHub `asset/ui/`에는 이미지와 이 README만 둡니다.
