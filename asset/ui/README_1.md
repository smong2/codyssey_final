# 루미아 UI 검수 시안 v05

이 폴더는 UI 검토 이미지와 조작 가능한 화면을 함께 보관한다. 1920×1080 전체화면 시안은 [`screens.html`](screens.html)에서 순서대로 볼 수 있고, 마이룸 시간대 비교는 [`myroom-times.html`](myroom-times.html)에서 볼 수 있다. 빈 프레임과 UI 없는 배경은 [`assets.html`](assets.html), 클릭 가능한 시연 화면은 [`index.html`](index.html)에 있다. 수치와 기록은 예시이며 게임 저장과 연결되어 있지 않다. 창가 독서실의 낮·노을·밤 원본 3장은 Git 이력에서 복원해 공용 자원으로 다시 연결했다.

이전 28장에 관한 기록은 과거 로컬 경로를 가리킵니다. 현재 저장소의 새 검토 시안 21장은 `../Full screen/FS01.png`~`FS21.png`에 중복 없이 보관합니다.

## 화면 규칙

- 보이는 스탯: 체력 0–100, 지식·표현력·솜씨·탐험·마법 각 0–500.
- 캐릭터: 32명 한 프레임, 기본 6명만 선택 가능. 전체/남자/여자 필터.
- 배지: 대분류 5개 × 소분류 5개 × 단계 8개. 배지 보상은 다음 회차 성장 능력에 적용하며 각 능력의 상한은 +15.
- 이 폴더의 자료는 검토용이며, 현재 저장소의 전체화면 시안 21장은 `asset/Full screen/`에 보관합니다. GitHub 반영·최종 채택 여부는 현재 브랜치와 별도 승인 기록으로 확인합니다.

## 중복 없는 자원 참조

조작 화면은 이미 `asset/`의 다른 폴더에 있는 동일 이미지 75개를 서버의 `/shared/` 경로로 불러옵니다. 전체화면 PNG 21장은 `../Full screen/`을, 버튼 완성본 6개는 `../ui/`를 참조합니다. 이 폴더에는 고유 프레임·시안과 실행 코드만 추가했습니다.
