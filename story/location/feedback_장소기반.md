# 장소 기반 시나리오 구조화 — 작가 검토용

> **문서 상태:** 작가 검토 필요  
> **원본 기준:** `story/location/LOCATION_BASED_STORIES.md`  
> **목적:** 작가가 작성한 장소 기반 시나리오를 실제 게임에서 사용할 순서와 시점에 맞춰 정리한다.  
> **시스템 규칙:** 발생 확률, 주간 제한, DB 및 백엔드 판정 로직은 [`장소기반_규칙.md`](장소기반_규칙.md)에서 별도로 관리한다.  
> **대화:** 실제 대사와 선택 대사는 별도 시나리오 데이터에서 정의한다.

---

## 1. 작가가 알아야 할 최소 전제

장소 기반 시나리오는 메인 스토리처럼 특정 날짜에 자동으로 실행되지 않는다.

- 플레이어가 **해당 장소를 방문했을 때** 발생할 수 있다.
- 각 시나리오에는 **노출 시작일**이 있으며, 그 날짜 이전에는 발생하지 않는다.
- 노출 시작일 이후 실제로 언제 발생하는지는 랜덤하다.
- 같은 장소의 이야기는 표의 **순서대로** 진행한다.
- 이전 이야기가 끝나기 전에 다음 이야기가 먼저 나오지 않는다.
- 천문대와 다른 장소도 같은 방식으로 사용한다. 천문대만 이야기 수가 4개일 뿐이다.
- 메인 스토리보다 먼저 또는 나중에 보더라도 내용이 어색하지 않아야 한다.
- 메인 스토리를 이해하는 데 반드시 필요한 정보나 단서는 장소 기반 시나리오에 넣지 않는다.

즉 작가 입장에서는 다음처럼 이해하면 된다.

```text
장소를 방문한다
→ 어느 방문에서 이야기가 나타날지는 알 수 없다
→ 하지만 나타나는 이야기의 순서는 정해져 있다
```

## 4. 장소별 진행 순서

### 별빛 천문대

```text
LOC_OBS_01 틀린 별자리
→ LOC_OBS_02 늦은 관측
→ LOC_OBS_03 자리 맡아 주기
→ LOC_OBS_04 빈 관측 칸
```

천문대는 네 이야기가 하나의 짧은 연속 이야기로 이어진다. 과거 학생의 정체나 아카데미의 비밀을 밝혀내는 방향으로 확장하지 않는다.

### 시계탑 광장

```text
LOC_CLK_01 축제 리본 묶기
→ LOC_CLK_02 종이 조각 줍기
```

메인 스토리의 수호 룬, 소문, 정보 공유와 연결하지 않는다.

### 유리 온실·약초원

```text
LOC_GH_01 작은 허브에 물 주기
→ LOC_GH_02 이름표 돌려놓기
```

메인 스토리의 희귀 식물 갈등과 분리한다.

### 기숙사 공용 공간

```text
LOC_DRM_01 창가 쿠션 놓기
→ LOC_DRM_02 공용 컵 정리
```

사적인 방이나 개인 물건을 조사하는 내용으로 확장하지 않는다.

### 대서고

```text
LOC_LIB_01 책 한 권 제자리 찾기
→ LOC_LIB_02 떨어진 책갈피
```

메인 스토리의 룬 기록이나 비밀 문서를 발견하는 방향으로 확장하지 않는다.

### 마도 공방

```text
LOC_WRK_01 부품을 모양별로 놓기
→ LOC_WRK_02 도구 닦아 두기
```

메인 스토리의 결계 수리, 위험, 학생의 실수를 다루지 않는다.

### 수련장

```text
LOC_TRN_01 연습 깃발 정리
→ LOC_TRN_02 표적 위치 바로잡기
```

메인 스토리의 안전 결계 문제와 분리한다.

## 5. 작가 검토가 필요한 부분

원본 시나리오의 방향은 대부분 그대로 사용할 수 있다. 아래 사항만 확인이 필요하다.

1. 각 장소의 시나리오가 표의 순서대로 이어져도 이야기상 자연스러운가.
2. 노출 시작일 이후 어느 시점에 보더라도 계절·시기상 어색한 표현이 없는가.
3. 메인 스토리보다 먼저 또는 나중에 보더라도 내용상 모순이 없는가.
4. 메인 스토리 진행에 필요한 핵심 정보나 단서가 Location Story 안에 들어가 있지 않은가.
5. 각 장면의 `발견 → 행동 또는 선택 → 짧은 반응` 구조가 실제 대사로 자연스럽게 풀리는가.
6. 천문대 4편은 하나의 연속 이야기로 읽히되, 다른 장소와 동일한 게임 시스템으로 실행해도 문제가 없는가.
7. 실제 대사와 선택 문구는 별도 작업으로 작성한다.

## 6. 시나리오 측 미확정 항목

다음은 작가 또는 기획에서 추가로 정할 수 있다.

- 천문대 과거 학생의 실제 일기 문구
- `LOC_OBS_04`에서 선택할 수 있는 별·표식 종류
- 각 이벤트에 등장하는 주변 학생 또는 짧은 반응 대사의 화자
- 행동하지 않고 지나가는 선택이 필요한 이벤트와 그때의 짧은 반응
- 작은 기념품이나 수집품을 시나리오상 제공할 필요가 있는지 여부

확률, 주간 발생 제한, 데이터 저장 방식 등 시스템 구현 사항은 [`장소기반_규칙.md`](장소기반_규칙.md)에서 관리한다.
