# 장소 기반 스토리

아르카디아의 장소에서 발생하는 이야기와 환경 변화를 보관합니다. 장소·에피소드별 파일로 나눕니다. [세계관 문서](../../document/02_WORLDVIEW.md)의 장소 역할을 확인하세요. [예시 템플릿](예시_장소_스토리.md)은 확정 시나리오가 아닙니다.

현재 제작 기준은 [LOCATION_STORY_PRODUCTION.md](LOCATION_STORY_PRODUCTION.md)입니다. 본편 제작 범위는 별빛 천문대 4회, 유리 온실 1회, 대서고 1회로 축소했으며 실제 대화·이미지 제작은 이 문서를 우선합니다.
