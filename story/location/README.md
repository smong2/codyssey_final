# 장소 기반 스토리

아르카디아의 장소에서 발생하는 이야기와 환경 변화를 보관합니다. 장소·에피소드별 파일로 나눕니다. [세계관 문서](../../document/02_WORLDVIEW.md)의 장소 역할을 확인하세요. [예시 템플릿](예시_장소_스토리.md)은 확정 시나리오가 아닙니다.

현재 제작 기준은 [LOCATION_STORY_PRODUCTION.md](LOCATION_STORY_PRODUCTION.md)입니다. 본편 제작 범위는 별빛 천문대 4회, 유리 온실 1회, 대서고 1회로 축소했습니다. 실제 공통 대화는 [`document/dialogue/location/`](../../document/dialogue/location/README.md), CH01~CH32 실제 PLAYER/THOUGHT·선택·reaction은 [`document/dialogue/location/character_sets/`](../../document/dialogue/location/character_sets/README.md)에 작성되어 있으며 `32명 / 192 choiceNode / 416 실제 선택 문구`를 검산했습니다. `seed_location_story_master.py`의 32인 DB 변환 및 실제 적재도 완료됐고, **2026-10-18 사용자 로컬 SQLite 실행에서 `192 sequences / 416 options / validation: OK` 정상 결과를 확인했습니다.**
