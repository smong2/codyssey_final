# NPC 반복 조우·교류 이벤트 설계

> **문서 상태: 본편 3개 NPC Story 체인 확정 / 최종 대사 원고 후속**  
> 본편에서는 `GUIDE / WORK / LULU` 3개 체인만 사용한다. 과거 검토했던 `TBD1 / TBD2` 추가 체인은 스펙 아웃하며 제작하지 않는다. 구체적인 노출 시작일은 [`feedback_npc.md`](feedback_npc.md)의 확정 일정을 따른다.

## 1. 설계 목적

NPC와의 만남을 긴 개인 서사나 갈등 해결 퀘스트로 만들지 않는다. 짧은 대화와 작은 행동이 여러 번 이어지면서 플레이어가 인물을 알아가고, 인물도 플레이어를 기억하는 흐름을 만든다.

- 한 번의 만남은 `상황 발견 → 작은 행동 → 짧은 반응`으로 끝낸다.
- 플레이어가 누구를 주인공으로 선택해도 같은 교류 이벤트를 경험할 수 있게 한다.
- 이미 설정된 플레이어블 캐릭터를 NPC 역할에 활용해 전용 인물과 추가 캐릭터 제작 부담을 줄인다.
- 숫자형 친밀도, 퀘스트 실패, 거절 불이익, 별도 일정 소모를 두지 않는다.
- 일반 아이템 인벤토리는 본편에서 사용하지 않는다. 교류의 기억은 아이템 지급보다 다음 만남의 대사·배경 반응으로 표현한다.
- 주인공 캐릭터는 해당 조우의 NPC 역할로 등장하지 않는다.

## 2. 공통 등장 규칙

각 이벤트에 `주 역할 캐릭터`와 `대체 캐릭터`를 지정한다.

1. 주인공 캐릭터가 주 역할 캐릭터가 아니면 주 역할 캐릭터가 등장한다.
2. 주인공이 주 역할 캐릭터라면 지정된 대체 캐릭터 한 명이 같은 역할로 등장한다.
3. 등장인물은 달라질 수 있지만, 만남의 상황·행동·이벤트 진행 단계·결과는 동일하게 유지한다.
4. 캐릭터별 차이는 인사, 짧은 반응, 말투에만 반영한다. 대체 인물마다 별도의 스토리 분기나 전용 행동을 만들지 않는다.
5. 플레이어는 한 명만 선택하므로 각 이벤트의 대체 캐릭터는 한 명이면 충분하다.
6. 조우 이벤트는 해당 주차나 활동에서 만날 기회가 제공되는 방식으로 운영한다. 무작위 출현 때문에 이벤트가 영구 누락되거나 관계 진행이 막히지 않도록 한다.

### 대체 배정표

| 이벤트 역할                        | 주 역할     | 대체 캐릭터 | 캐릭터 선택 시 처리                                          |
| ---------------------------------- | ----------- | ----------- | ------------------------------------------------------------ |
| 안내 준비를 함께하는 활기찬 친구   | 티아 (CH16) | 로빈 (CH15) | 티아를 주인공으로 고르면 로빈이 같은 안내 준비 이벤트를 맡음 |
| 공방의 작은 물건을 정리하는 실천가 | 렌 (CH25)   | 다나 (CH26) | 렌을 주인공으로 고르면 다나가 같은 정리 이벤트를 맡음        |
| 발견물을 모으는 다람쥐             | 루루        | 대체 없음   | 플레이어 캐릭터 선택과 관계없이 등장 가능                    |

> GUIDE의 로빈, WORK의 다나 대체 배정은 본편 시나리오 규칙으로 유지한다. 대체 캐릭터는 해당 회차에서 플레이 가능 상태인지와 무관하게 NPC 역할로 등장할 수 있으며, 별도 NPC Story 체인을 만들지 않는다.

## 3. NPC 교류 이벤트

### 3.1 티아 — 안내 준비를 함께하는 친구

**주 역할:** 티아 (CH16)  
**대체 후보:** 로빈 (CH15)  
**성격 기준:** 티아의 천진난만하고 활기찬 분위기를 중심으로 하되, 대체 캐릭터는 기존 설정의 말투로 짧게 반응한다.  
**장소 제안:** 시계탑 광장 또는 기존 생활 장면의 공용 공간. 새로운 맵은 필요하지 않다.

| 만남              | 상황과 작은 행동                                                                                | 다음 만남에 남는 흔적                                                                                                      |
| ----------------- | ----------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------- |
| 1. 안내지 줍기    | 안내지를 나르던 티아가 몇 장을 떨어뜨린다. 플레이어가 가까운 안내지를 주워 함께 정리한다.       | 티아가 플레이어의 얼굴을 기억한다. 이벤트는 안내지 정리로 끝난다.                                                          |
| 2. 안내지 놓기    | 티아가 지난번 함께 정리한 일을 알아보고, 안내지를 사람들이 보기 쉬운 곳에 놓아 달라고 부탁한다. | 다음에 티아가 안내지를 보고 모임에 온 학생이 있었다고 짧게 알려 준다.                                                      |
| 3. 색 리본 고르기 | 작은 모임 장식에 쓸 리본 두세 가지 중 하나를 고르거나, 원하는 것을 티아에게 건넨다.             | 다음 만남에서 선택한 색이 장식에 사용된 것을 볼 수 있다.                                                                   |
| 4. 남은 준비 돕기 | 티아가 남은 장식이나 안내물을 정리한다. 플레이어는 물건을 건네거나 같은 종류끼리 모은다.        | 네 번의 준비가 자연스럽게 마무리되고, 처음보다 편해진 관계가 장면 안에서 드러난다. 이 단계가 GUIDE 체인의 마지막 만남이다. |

**대체 연출 원칙:** 로빈이 등장하면 모임 준비를 새로운 경험처럼 반기는 반응으로 조정한다. 네 번의 행동과 결과 구조는 그대로 유지한다.

#### 로빈 대체 말투·반응 확정

로빈은 `document/03_CHARACTERS.md`의 `바람을 쫓는 자유 유랑자 / 빠른 친화력` 설정을 기준으로 한다. 티아와 같은 ENFP 계열의 밝은 분위기는 유지하되, 티아의 사랑스럽고 요정 같은 표현을 복제하지 않는다. 로빈은 처음 보는 상황에도 빠르게 끼어들고, 가벼운 감탄이나 짧은 농담을 섞으며, 고민보다 먼저 움직여 보는 쪽으로 말한다.

- 말이 길지 않고 상대와 금방 친해진다.
- 부탁을 무겁게 만들지 않고 `같이 해보자`는 식으로 자연스럽게 끌어들인다.
- 바람·여행 이미지는 캐릭터의 배경으로만 사용하고 모든 문장을 비유로 만들지 않는다.
- 4단계로 갈수록 별도의 친밀도 고백 대신 먼저 말을 걸고 호흡이 맞는 모습을 보여 준다.

| GUIDE 단계                    | 로빈 대체 대사·반응 기준                                                            |
| ----------------------------- | ----------------------------------------------------------------------------------- |
| `NPC_GUIDE_01` 안내지 줍기    | `오, 딱 좋은 타이밍. 저쪽 한 장만 잡아줄래? 바람이 오늘 꽤 장난치네.`               |
| `NPC_GUIDE_02` 안내지 놓기    | `지난번에 손 빠르던 거 기억나. 이번엔 사람들이 바로 볼 만한 데를 같이 골라보자.`    |
| `NPC_GUIDE_03` 색 리본 고르기 | `고민하다 보면 다 예뻐 보여. 네 눈에 제일 먼저 들어온 걸로 가자.`                   |
| `NPC_GUIDE_04` 남은 준비 돕기 | `이제 거의 끝났네. 혼자 했으면 중간에 딴 데로 샜을 텐데, 덕분에 제대로 마무리했다.` |

위 문장은 GUIDE 체인의 로빈 버전에서 사용할 수 있는 기준 대사다. 실제 선택 직후 반응이 필요한 경우에도 같은 말투를 유지하되, 사건의 선택 구조와 결과는 티아 버전과 동일하게 둔다.

### 3.2 렌 — 공방의 물건을 살피는 실천가

**주 역할:** 렌 (CH25)  
**대체 후보:** 다나 (CH26)  
**성격 기준:** 손으로 직접 확인하고 정리하는 실용적인 인물. 렌은 과묵하고 건조한 편이며, 다나는 룬 기계에 익숙하고 간결하게 말한다.  
**장소 제안:** 기존 공방 생활 장면 또는 공방 수업 전후. 장소가 아직 확정되지 않았다면 신규 탐험 맵의 전제 없이 배치한다.

| 만남                | 상황과 작은 행동                                                                                                   | 다음 만남에 남는 흔적                                                                                                   |
| ------------------- | ------------------------------------------------------------------------------------------------------------------ | ----------------------------------------------------------------------------------------------------------------------- |
| 1. 부품 모으기      | 작업대에 크기가 다른 부품이 놓여 있다. 플레이어가 눈에 띄게 같은 모양의 부품을 함께 모은다.                        | 렌이 플레이어가 물건을 잘 살펴본다는 점을 기억한다.                                                                     |
| 2. 필요한 부품 찾기 | 렌이 간단한 모양 설명을 해 주고, 플레이어가 상자에서 맞는 부품을 찾아 건넨다.                                      | 다음 만남에 렌은 부품을 찾는 위치를 짧게 알려 주며 대화를 먼저 시작한다.                                                |
| 3. 도구 정돈하기    | 작은 도구를 닦거나 제자리에 놓는다. 플레이어가 원하는 순서로 정리해도 이벤트는 완료된다.                           | 정리된 작업대가 다음 장면의 배경으로 남는다.                                                                            |
| 4. 작업대 살펴보기  | 렌 또는 다나가 정돈된 작업대를 확인한다. 플레이어에게 도구 하나를 건네 달라고 부탁하거나 작업대에서 함께 찾아본다. | 반복해서 함께 정리한 흐름이 작업대 상태와 대화에 드러나며 자연스럽게 마무리된다. 이 단계가 WORK 체인의 마지막 만남이다. |

**대체 연출 원칙:** 다나가 렌을 대신하더라도 복잡한 기계 제작으로 이벤트를 확장하지 않는다. 작은 부품을 찾고 정리하는 공통 행동을 유지하며, 반응과 설명 방식만 다르게 한다.

#### 다나 대체 말투·반응 확정

다나는 `document/03_CHARACTERS.md`의 `룬 메커니즘 엔지니어 / 기계적 직관` 설정을 기준으로 한다. 렌과 마찬가지로 실용적이고 말수가 적지만, 렌의 공방 장인·수리 감각을 그대로 복제하지 않고 규격·구조·위치·작동 상태를 빠르게 읽는 엔지니어 성향으로 구분한다.

- 문장은 짧고 명확하다.
- 감정을 길게 설명하기보다 작업 상태나 결과로 긍정적인 반응을 표현한다.
- `잘했어`보다 `이제 바로 찾겠네`, `시간이 줄었어`처럼 결과를 관찰해 말한다.
- 홈, 규격, 위치, 정렬, 작동 상태 같은 단어는 자연스럽게 사용할 수 있지만 전문용어를 과도하게 늘리지 않는다.
- 4단계의 관계 변화도 감정 고백보다 서로 설명을 줄여도 작업이 맞아 들어가는 모습으로 표현한다.

| WORK 단계                      | 다나 대체 대사·반응 기준                                                  |
| ------------------------------ | ------------------------------------------------------------------------- |
| `NPC_WORK_01` 부품 모으기      | `형태별로 나누면 돼. 홈이 같은 것끼리. 내가 이쪽 볼 테니 넌 저쪽.`        |
| `NPC_WORK_02` 필요한 부품 찾기 | `이 규격이 필요해. 가장자리 홈이 두 개야. 비슷해 보여도 하나는 안 맞아.`  |
| `NPC_WORK_03` 도구 정돈하기    | `먼지 닦고 원래 위치에 놓자. 순서는 상관없어. 나중에 찾기만 쉬우면 돼.`   |
| `NPC_WORK_04` 작업대 살펴보기  | `정돈 상태 괜찮네. 지난번보다 찾는 시간이 줄었어. 저 도구 하나만 건네줘.` |

위 문장은 WORK 체인의 다나 버전에서 사용할 수 있는 기준 대사다. 실제 선택 직후 반응이 필요한 경우에도 같은 말투를 유지하되, 사건의 선택 구조와 결과는 렌 버전과 동일하게 둔다.

### 3.3 루루 — 작은 발견을 모으는 다람쥐

**등장 형태:** 반복 조우에 등장하는 말하는 동물 NPC로 본편 사용을 확정한다. 플레이어블 캐릭터가 아니며 캐릭터 선택에 따른 대체가 필요 없다.  
**성격:** 호기심이 많고 재빠르다. 반짝이거나 바스락거리는 작은 물건에 관심을 보이며, 발견한 것을 볼 주머니에 소중히 넣어 둔다. 익살스럽고 생기 있지만, 플레이어에게 물건을 억지로 가져오게 하지는 않는다.  
**장소 제안:** 시계탑 광장 주변이나 첫 Adventure 프로토타입 장소인 온실의 가장자리. 새 장소를 추가하지 않는다.

| 만남                 | 상황과 작은 행동                                                                                                                         | 다음 만남에 남는 흔적                                                                                                       |
| -------------------- | ---------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------- |
| 1. 단추 발견         | 루루가 바닥에서 작은 단추를 발견해 굴려 본다. 플레이어와 함께 무늬나 색을 살핀다.                                                        | 루루가 플레이어를 기억하고 다음 조우에서 먼저 다가온다.                                                                     |
| 2. 단추 보관하기     | 루루는 단추 주인이 있을지도 모른다고 생각한다. 플레이어는 가까운 물건을 살펴보거나, 루루가 마련한 작은 보관 장소에 단추를 두도록 돕는다. | 주인을 반드시 찾아야 하는 목표를 만들지 않는다. 루루가 안전하게 두었다는 사실만 남는다.                                     |
| 3. 발견물 나누기     | 루루가 모아 둔 작은 물건을 보여 준다. 플레이어는 비슷한 색이나 모양끼리 모아 볼 수 있다.                                                 | 루루가 자기만의 발견 장소를 플레이어에게 보여 준다.                                                                         |
| 4. 새 발견 함께 보기 | 루루가 새로 찾은 깃털, 단풍 씨앗, 작은 단추 등 하나를 보여 준다. 플레이어는 가까이에서 살펴보거나 다른 물건과 비교한다.                  | 루루가 플레이어를 자기 발견을 함께 봐주는 친구처럼 대하며 네 번의 만남을 마무리한다. 이 단계가 LULU 체인의 마지막 만남이다. |

**시각 제작 고려:** 루루의 이름과 NPC 역할은 확정한다. 실제 자산은 한 장의 기본 스프라이트와 재사용 가능한 표정·짧은 움직임을 우선하고 전용 배경이나 복잡한 애니메이션을 전제로 삼지 않는다. 최종 외형·자산 제작 완료 여부는 디자인/구현 단계에서 별도로 확인한다.

## 4. 이벤트 운영 및 플레이어 선택

- NPC Story는 일반 아이템·수집품을 지급하지 않는다. 기억해야 할 결과는 선택 플래그, 다음 만남의 대사, 짧은 배경 반응으로 표현한다.
- 선택 행동은 정답/오답이나 보상 획득 조건으로 사용하지 않는다. 부탁을 거절하거나 다른 행동을 선택해도 이벤트 흐름과 이후 조우는 이어진다.
- 각 만남은 짧은 장면이며 별도의 퀘스트 수락·완료창을 요구하지 않는다.
- 작은 부탁을 수행하지 않거나 다른 선택을 해도 해당 인물과의 교류가 막히지 않는다. 장면을 정상적으로 끝냈다면 선택의 긍정/부정 여부와 관계없이 다음 만남 단계로 이어질 수 있다.
- 선택지가 있는 장면은 선택에 맞는 짧은 반응을 먼저 보여 준 뒤, 이전 답변을 긍정·부정 어느 쪽으로도 단정하지 않는 공통 대화로 합류한다. 후속 장면에서 반드시 기억해야 하는 선택만 이벤트 플래그로 남긴다.
- 만남 단계는 내부 이벤트 진행 정보로만 기록한다. 친밀도·호감도 같은 숫자형 관계 수치는 사용하지 않는다.
- 완료된 NPC Story 단계는 다시 발생시키지 않는다. 이전 행동을 기억하는 짧은 인사나 반응은 **다음 단계 안에서만** 사용한다. GUIDE / WORK / LULU는 4단계 완료 후 다시 만나는 콘텐츠가 없으므로 체인 완료 후 별도 후속 대사를 제작하지 않는다.
- NPC 만남은 기존 모험·생활 장면에 포함한다. 이를 위해 주간 일정의 별도 행동 칸을 추가하지 않는다.
- 일반 NPC 대화와 개별 교류 이벤트는 보호자 리포트의 성격·심리 분석 자료로 사용하지 않는다.
