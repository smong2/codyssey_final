# LUMIA NPC 교류 — 회차별 대화·이미지 제작 명세
> **제작용 구조화 초안** · 기준: `NPC_INTERACTION_STORIES.md` · 추가 NPC 없음 (`GUIDE / WORK / LULU`만 사용)

## 1. 공통 제작 규칙

- 본편은 **3체인 × 4회 = 12회**. `TBD1`·`TBD2`·연장자·요정 신규 체인은 제작하지 않는다. 기존 이름과 배역(티아/로빈, 렌/다나, 루루)만 사용한다.
- 한 번의 교류는 **기존 장소/수업 화면에서 시작 → NPC와 대화 → 플레이어의 발화 선택 → 대사상 행동이 처리되었다고 알림 → 짧은 다음 만남의 기대**로 끝난다. 드래그·아이템 조작·퀘스트 체크는 없다.
- 매 회차 **선택지 노드 1개, 기본 2가지 발화**. 호감도·게임 오버·거절 불이익이 없다. 긍정/소극적 표현을 택해도 같은 회차는 완료된다.
- `대화 왕복 1회 = NPC(또는 대화 상대) 1발화 + 플레이어 1발화`로 계산한다. 제작량은 기본 경로 수치이며 대체 캐릭터가 등장해도 동일하다. **선택 직후 분기 반응 1말풍선은 이 기본 왕복 수에 포함하지 않는 별도 텍스트 변형**으로 예산을 검토한다.
- 노출 시작 주차는 **최신 `NPC_INTERACTION_STORIES.md` 하단 확정 수치**를 우선 채택하고, 날짜는 `1월 1일 월요일 / 비윤년` 가상 달력에서 해당 월요일을 산출한 값이다. 현재 `feedback_npc.md`의 일정도 GUIDE `4/15/29/41`, WORK `8/20/32/44`, LULU `12/25/35/48`과 같은 날짜로 동기화되어 있다.
- 장소/수업 조건이 맞는 때에만 후보가 되며, 1→2→3→4의 순서 유지. 실제 출현은 이벤트 엔진의 확정 정책(랜덤/보장)을 따른다. 특정 회차를 못 봤다고 메인 스토리가 막히지 않는다.
- 기존 배경·스프라이트와 대화 UI를 재사용하며, 각 행의 신규 이미지 수는 이 문서에 처음 등장하는 소품 그림 수다.

## 4. 교류 대화의 짧은 진행 템플릿

| 순서 | 소요 대화 | 시각 요소 | 진행 조건 |
|---|---|---|---|
| `N1` 마주침 | 1왕복 | 기존 NPC 스프라이트 + 기존 장소 | 지난 만남을 기억하는 인사(2회차 이상) |
| `N2` 오늘의 작은 상황 | 1왕복 | 필요한 경우 소품 이미지 | 이유와 부탁을 짧게 설명 |
| `N3` 말로 선택하고 반응 | 1왕복 | 선택 결과 화면; 드래그/퀘스트 없음 | 2개 발화 중 하나 선택, 어느 쪽도 진행 가능 |
| `N4` 추가 여운(일부) | 1왕복 | 동일 이미지 재사용 | 개성이 필요한 GUIDE3/LULU3만 추가 |

선택지 문구는 **실제 확정 대사 아님**. 위 표의 선택 주제에 맞추어 플레이어 발화 2항목을 나중에 쓰고, 뒤의 결과 대사는 공통 흐름으로 합류시킨다. `WORK2`는 정답을 맞히는 퀴즈가 아니라 **특징을 바로 말하기 / 다시 비교하기**의 관찰 방식 선택으로 사용한다.

## 5. 분기·범위 검수

- GUIDE: 티아 버전 4회와 로빈 대체 버전 4회의 **말풍선 개수·신규 이미지 수 동일**. 첫 인사와 반응 톤만 조정한다. 로빈은 빠르고 장난스러운 말투.
- WORK: 렌과 다나의 공통 행동 구조 고정. 다나 버전은 규격·위치 설명 중심으로 간결하게 수정한다.
- LULU: 신규 체인이 아닌 기존 확정 동물 NPC. **루루 기본 스프라이트 제작 여부는 별도 확인**이 필요하며, 미제작일 때 추가 1개 캐릭터 이미지가 발생할 수 있다.
- 대화와 기존 이미지로 정리·분류·보관·선물받기 등을 표현한다. 새 수집 아이템, 영구 인벤토리, 보상 팝업, 5회차 이후 별도 인사 이벤트는 제작하지 않는다.
- `NPC_...` 노출 시작 주차와 날짜는 현재 `feedback_npc.md`와 일치한다. 이후 일정을 변경하면 두 문서를 함께 갱신한다.

## 6. 회차별 왕복 대화의 실제 흐름안

> **집필 전 윤곽:** `R1`은 NPC 1발화→주인공 1발화로 1왕복이다. `R2`·`R3`도 동일하며, **3왕복 장면은 `R3`, 4왕복 장면은 `R3`에서 주인공이 2지 대사 선택을 한다.** 4왕복 장면의 `R4`는 선택 후 여운 대화다. 선택 직후 NPC의 짧은 분기 응답 말풍선(공통 또는 선택별 1줄)은 별도 추가될 수 있다. **실제 확정 대사는 아니고**, 왕복마다 말해야 할 정보의 순서와 반응을 지정한다.

| 회차 | 왕복별 대화 내용·흐름(각 R = NPC 발화 → 플레이어 발화) | 선택 직후 NPC 반응과 연결 |
|---|---|---|

| 회차 | 사용할 이미지 | 새로 묘사할 내용 |

### NPC 대화와 이미지가 함께 진행되는 예시 — `NPC_GUIDE_03`

`기존 광장 배경 + 티아(또는 로빈)` → `R1 인사(2말풍선)` → `R2 리본 고민(2말풍선)` → `ART-N02 리본 그림 표시` → `R3 색 선호 대사 선택(2말풍선 상당)` → `분기 반응 1말풍선` → `R4 꾸민 뒤 감상(2말풍선)` → `다음 만남 색상 언급 플래그만 저장`.

**주의:** 메인 에피소드의 주요 갈등·해법을 NPC 교류에서 먼저 설명하지 않는다. `TBD1`·`TBD2`는 제작하지 않으며, 선택이 긍정/소극적이어도 장면 완료·다음 만남 가능 상태를 유지한다.

## 8. 선택지별 보이는·보이지 않는 스탯 결과

NPC Story의 일반 대화 선택은 장면 종료 시 **보이는 성장 스탯 `+1` + 보이지 않는 스탯 `+3`**을 함께 준다. 특정 선택이 더 좋은 보상을 주는 정답 구조는 만들지 않는다. 이 값은 일회성 스토리 보상이므로 관리자 반복 성장 보상 배율을 적용하지 않는다.
