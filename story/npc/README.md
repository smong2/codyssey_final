# NPC별 스토리

인물별 관계·대화·개별 사건을 보관합니다. 학생 32명과 안내 인물의 설정은 [캐릭터 문서](../../document/03_CHARACTERS.md)를 기준으로 확인합니다. 인물·에피소드별 파일로 분리합니다. [예시 템플릿](예시_NPC_스토리.md)은 확정 시나리오가 아닙니다.

본편 NPC Story는 **GUIDE / WORK / LULU 3개 체인만 사용**합니다. GUIDE는 티아(주인공이 티아면 로빈), WORK는 렌(주인공이 렌이면 다나), LULU는 루루가 담당합니다. 과거 검토했던 `TBD1 / TBD2` 추가 체인은 스펙 아웃되었습니다. 구조와 노출 일정은 [feedback_npc.md](feedback_npc.md)를 기준으로 합니다.
