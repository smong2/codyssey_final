# NPC 교류 시나리오 구조화 — 본편 3체인 기준

> **문서 상태:** 본편 NPC 3체인·노출 일정 확정 / 최종 대화·선택 원고 인계 필요  
> **원본 기준:** `story/npc/NPC_INTERACTION_STORIES.md`  
> **목적:** NPC 교류 시나리오를 실제 게임에서 사용할 순서·노출 시작일·만남 조건에 맞춰 정리한다.  
> **발생 방식:** Location Story와 동일한 랜덤 발생 구조를 사용한다. 단, Location Story가 `장소 방문`을 기준으로 한다면 NPC Story는 `장소 / 수업 / 장소+수업` 조건을 기준으로 후보가 된다.  
> **대화:** 실제 대사와 선택 대사는 별도 시나리오 데이터에서 정의한다.  
> **NPC 수:** 본편 NPC Story는 **GUIDE / WORK / LULU의 3개 체인만 운영**한다. 기존 `TBD1 / TBD2` 2개 체인은 스펙 아웃한다. GUIDE와 WORK의 대체 캐릭터는 주인공 중복을 피하기 위한 동일 체인 대체 출연이며 별도 NPC Story 체인으로 세지 않는다.
> **실행 경계:** 수업 미니게임·직접 모험 플레이 내부에는 NPC를 배치하거나 대화를 실행하지 않는다. 조건은 활동 결과 저장 뒤 판정하며, 선정된 NPC Story는 분리된 이야기 장면에서 실행한다.

---

## 1. 작가가 알아야 할 최소 전제

NPC 교류 시나리오는 특정 날짜에 자동으로 실행되지 않는다.

- 각 시나리오에는 **노출 시작일**이 있다.
- 노출 시작일 이후 지정된 `장소 / 수업 / 장소+수업` 조건을 만족했을 때 발생할 수 있다.
- 실제로 어느 방문·수업의 완료 뒤 별도 이야기 장면으로 발생할지는 랜덤하다.
- 같은 NPC Story 체인의 이야기는 표의 **순서대로** 진행한다.
- 이벤트가 실제 발생해 장면이 진행되면 해당 sequence는 완료되고, 같은 단계가 다시 나오지 않는다.
- 시나리오 내부에 선택지가 있더라도 성공/실패로 나누지 않고 장면 종료 후 다음 sequence로 진행한다.
- 주 역할 캐릭터가 현재 플레이어 캐릭터라면 지정된 대체 캐릭터가 같은 역할을 맡는다.
- 등장 캐릭터가 바뀌어도 사건·행동·결과 구조는 동일하게 유지하고, 말투와 짧은 반응만 캐릭터에 맞게 조정한다.

즉 작가 입장에서는 다음처럼 이해하면 된다.

```text
조건에 맞는 장소 방문 또는 수업 진행
→ 어느 시점에 NPC 이야기가 나타날지는 랜덤
→ 나타나는 이야기는 1 → 2 → 3 → 4 순서
→ 한 번 발생한 단계는 완료되고 다시 나오지 않음
```

## 2. NPC Story 발생 조건 타입

| 조건 타입 | 의미 | 예시 |
|---|---|---|
| `LOCATION` | 특정 장소를 방문하면 후보가 됨 | 시계탑 광장 방문 |
| `CLASS` | 특정 수업을 진행하면 후보가 됨 | 검술훈련 진행 |
| `ALL` | 지정된 장소와 수업 조건을 모두 만족해야 후보가 됨 | 별빛 천문대에서 마법훈련 진행 |

노출 시작일 이전에는 조건을 만족해도 시나리오가 발생하지 않는다.

## 3. NPC Story 체인 및 등장 캐릭터

| 체인 코드 | 역할 / 스토리 축 | 주 역할 캐릭터 | 대체 캐릭터 | 조건 타입 | 만남 조건 |
|---|---|---|---|---|---|
| `GUIDE` | 안내 준비를 함께하는 활기찬 친구 | 티아 (CH16) | 로빈 (CH15) | `LOCATION` | 시계탑 광장 방문 |
| `WORK` | 공방의 작은 물건을 정리하는 실천가 | 렌 (CH25) | 다나 (CH26) | `ALL` | 마도 공방에서 마법훈련 진행 |
| `LULU` | 작은 발견을 모으는 다람쥐 | 루루 | 없음 | `LOCATION` | 유리 온실·약초원 방문 |

`TBD1`과 `TBD2`는 본편에서 사용하지 않으며 신규 캐릭터·대체 인물·4회분 시나리오를 제작하지 않는다.

### 주인공 선택에 따른 대체 원칙

```text
주인공 != 주 역할 캐릭터
→ 주 역할 캐릭터가 NPC로 등장

주인공 == 주 역할 캐릭터
→ 대체 캐릭터가 같은 NPC Story 역할을 수행
```

예:

```text
티아가 주인공이 아님
→ GUIDE 체인에 티아 등장

티아가 주인공
→ GUIDE 체인에 로빈 등장
```

스토리 ID와 sequence 진행은 등장 캐릭터가 바뀌어도 동일하게 유지한다.

## 5. NPC별 진행 순서

### GUIDE — 티아 / 로빈

**발생 조건:** 시계탑 광장 방문 (`LOCATION`)

```text
NPC_GUIDE_01 안내지 줍기
→ NPC_GUIDE_02 안내지 놓기
→ NPC_GUIDE_03 색 리본 고르기
→ NPC_GUIDE_04 남은 준비 돕기
```

- 티아가 주인공이면 로빈이 대신 등장한다.
- 등장 캐릭터가 달라도 네 단계의 사건과 결과는 유지한다.
- 로빈은 빠른 친화력과 자유로운 행동성을 살려 짧은 농담·가벼운 감탄·`같이 해보자`는 식의 말투를 사용한다. 구체적인 4단계 대체 대사 기준은 `NPC_INTERACTION_STORIES.md`를 따른다.
- 최신 메인 시나리오 `MS05`의 별빛 축제·시계탑 수호 룬 최종 해결과 연결하지 않는다. GUIDE 체인의 완료 여부가 12월 3일 메인 해결의 조건이 되어서는 안 된다.

### WORK — 렌 / 다나

**발생 조건:** 마도 공방에서 마법훈련 진행 (`ALL`)

```text
NPC_WORK_01 부품 모으기
→ NPC_WORK_02 필요한 부품 찾기
→ NPC_WORK_03 도구 정돈하기
→ NPC_WORK_04 작업대 살펴보기
```

- 렌이 주인공이면 다나가 대신 등장한다.
- 다나는 짧고 명확하게 말하며 규격·구조·위치·작동 상태를 빠르게 읽는 엔지니어 말투를 사용한다. 감정 표현은 작업 결과에 대한 관찰로 드러내며, 구체적인 4단계 대체 대사 기준은 `NPC_INTERACTION_STORIES.md`를 따른다.
- 메인 스토리의 안전 결계 고장이나 대형 수리를 해결하는 내용으로 확장하지 않는다.
- 작은 부품·도구·정리와 반복 만남을 중심으로 유지한다.

### LULU — 루루

**발생 조건:** 유리 온실·약초원 방문 (`LOCATION`)

```text
NPC_LULU_01 단추 발견
→ NPC_LULU_02 단추 보관하기
→ NPC_LULU_03 발견물 나누기
→ NPC_LULU_04 새 발견 함께 보기
```

- 플레이어 캐릭터와 관계없이 루루가 등장한다.
- `루루` 이름과 NPC 역할은 본편 기준으로 확정한다. 최종 외형·캐릭터 자산 제작 상태는 시나리오 확정과 별도로 관리한다.
- 온실 메인 스토리의 희귀 식물 문제와 연결하지 않는다.

## 6. 노출 일정 배치 의도

현재 Main Story, Location Story, NPC Story의 **신규 노출 시작 주차가 겹치지 않도록** NPC 12개 시나리오를 빈 주차에 배치한다. 서브스토리는 스펙 아웃되어 별도 슬롯을 예약하지 않는다.

NPC Story 배치 주차:

```text
4, 8, 12,
15, 20, 25,
29, 32, 35,
41, 44, 48주차
```

각 NPC 체인은 1년 전체에 걸쳐 분산된다.

| NPC 체인 | 1단계 | 2단계 | 3단계 | 4단계 |
|---|---|---|---|---|
| GUIDE | 1월 22일 | 4월 9일 | 7월 16일 | 10월 8일 |
| WORK | 2월 19일 | 5월 14일 | 8월 6일 | 10월 29일 |
| LULU | 3월 19일 | 6월 18일 | 8월 27일 | 11월 26일 |

노출 시작일 이후 실제 발생일은 플레이어의 일정 선택과 랜덤 발생 판정에 따라 달라진다.

## 7. 작가 검토가 필요한 부분

1. GUIDE 4단계가 시계탑 광장을 반복 방문하면서 자연스럽게 이어지는가.
2. WORK 4단계가 `마도 공방 + 마법훈련` 상황에서 자연스럽게 발생할 수 있는가.
3. LULU 4단계가 온실 방문 중 반복 조우로 자연스럽게 이어지는가.
4. 각 체인의 마지막 단계는 거대한 사건 해결보다 `처음보다 편해진 관계`가 느껴지는 작은 마무리를 우선한다.
5. 실제 대사와 선택 문구는 별도 작업으로 작성한다. 로빈/다나 대체 말투·반응 기준은 확정되었다.

## 8. 시나리오 측 미확정 항목

- 루루의 최종 외형·자산 제작 여부

일반 아이템 인벤토리 스펙 아웃에 따라 GUIDE/WORK/LULU 장면은 기념 아이템을 영구 지급하지 않는다. 선택한 리본 색, 정돈된 작업대, 루루가 보여 준 발견물처럼 **대화·다음 장면의 기억 표현만 유지**한다.

GUIDE / WORK / LULU는 4단계 완료 후 해당 NPC를 다시 만나는 콘텐츠가 없다. 따라서 체인 완료 후 일반 조우 변형 대사는 제작하지 않으며, 관계 변화와 마무리는 각 4단계 장면 안에서 끝낸다. 공통 시스템의 일반 NPC 조우 규칙 자체는 유지하며, 이는 1단계 이전 선행 조우와 다른 NPC 콘텐츠에 사용할 수 있다.

NPC Story의 확률 계산과 주간 제한은 Location Story와 같은 구조를 재사용하는 것을 전제로 하며, 실제 공통 백엔드 로직은 시스템 문서에서 관리한다.
