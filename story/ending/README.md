# 엔딩 스토리

이야기의 결말과 상태별 마무리를 보관합니다. **직업명·부제·직업의 의미·미래 장면 방향의 원본은 작가 문서 `ENDING_STORY.md`** 이며, 현재 게임은 이 10개 직업을 정규 엔딩으로 채택합니다. 수치 조건과 복수 후보 판정 같은 시스템 규칙은 `document/content/02_STATS_EVENTS_ENDINGS/03_ENDINGS.md`에서 관리합니다.

- 정규 직업 엔딩: 10종
- 정규 후보가 없을 때의 fallback: `별길 개척자`
- `무엇을 지켰니?`: AI가 생성하지 않는 고정 작가 문구
- 정규 직업명·부제·`careerAnchor`·`futureSceneGuide`: `ENDING_STORY.md`의 작가 원문을 구조화한 고정 원고
- 개인화 편지 본문: 실제 플레이 기록과 중요 선택을 이용한 AI 생성
- AI 최종 실패: 직업명·careerAnchor·실제 기록을 유지하는 고정 fallback 템플릿

직업별 긴 고정 편지 원고 10종을 새로 만들지는 않습니다. 작가가 이미 작성한 직업별 의미와 첫걸음 장면을 AI 편지의 서사 기준으로 재사용하고, 실제 52주 플레이 기록만 개인화합니다. 추가 상세 대사나 화면 연출이 필요할 때만 이 폴더에서 후속 원고를 작성합니다. [예시 템플릿](예시_엔딩_스토리.md)은 결말을 확정하지 않습니다.
