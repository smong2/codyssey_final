# 엔딩 종류 및 분기 스토리 설계

> **문서 상태: 기획 제안**  
> 첨부된 「엔딩 스토리 작성 템플릿」의 형식에 맞춰 52주 플레이 이후의 엔딩 종류를 구성한 초안이다. 직업별 세부 조건과 판정 우선순위는 플레이 시스템과 함께 확정해야 한다.

## 엔딩 구조

메인 스토리는 인트로와 네 개의 에피소드로 이루어진 한 해의 서사다. 네 에피소드는 52주 일정과 함께 진행되며, 에피소드 4가 끝났다고 별도 엔딩이 나오지 않는다. 플레이어가 52주 일정을 마치고 마지막 메인 이벤트를 완료하면, 네 에피소드의 선택과 결과, 한 해 동안의 수업·모험·휴식, NPC·공간 이벤트를 종합해 **하나의 진로 엔딩**을 경험한다.

엔딩의 갈래는 플레이어의 우열이나 도덕성을 평가하는 등급이 아니다. 서로 다른 활동과 선택이 서로 다른 미래의 가능성으로 이어지는 결과다. 아래의 10개 유형은 기존 기획의 ‘최소 10종 이상의 미래 직업 엔딩’ 목표를 구체화한 제안이다.

## 공통 엔딩 템플릿

| 항목 | 공통 내용 |
|---|---|
| 대상 | 52주 일정과 마지막 메인 이벤트를 완료한 플레이어 |
| 주요 등장인물 | 선택한 주인공, 베른, 발렌티누스, 해당 엔딩과 관련해 플레이 중 만난 인물 |
| 시작 조건 | 52주 완료 및 마지막 메인 이벤트 완료. 메인 에피소드 4개의 선택·결과와 전체 플레이 기록을 반영 |
| 종료 조건 | 한 해의 경험이 이어진 진로 장면을 확인하고, 선택형 개인 회고를 마치거나 건너뜀 |
| 전체 개요 | 공통 마무리 장면 뒤에 플레이 기록으로 선정된 진로를 보여준다. 해당 진로에서 주인공이 하게 될 작은 일을 구체적으로 보여주고, 한 해 동안의 선택·관계·발견을 장면이나 주변 인물의 반응으로 회수한다. |
| 상태 | 엔딩 종류: 제안 / 판정 기준·상세 대사·화면 연출: 미정 |

## 공통 회차별 스토리 골격

> ‘회차’는 첨부 템플릿을 따르는 장면 순서다. 실제 주차나 별도 플레이 회차가 아니다. 정확한 대사 원고는 후속 작업으로 남긴다.

| 회차 | 제목 | 대상 명 | 상태 | 개요 | 스토리 내용 | 비고 |
|---|---|---|---|---|---|---|
| 1 | 한 해의 마지막 날 | 모든 엔딩 대상 | 제안 | 마지막 메인 이벤트를 마치고 아카데미 생활의 한 해를 정리한다. | 주인공과 아카데미 구성원들이 마지막 사건을 마무리한다. 네 에피소드의 주요 결과는 이미 변화한 인물과 장소를 통해 자연스럽게 확인한다. 에피소드 4 뒤에 별도 엔딩이 있었던 것처럼 연출하지 않는다. | 마지막 메인 이벤트의 구체 내용·시점은 메인 스토리 구성에 맞춰 확정한다. |
| 2 | 한 해의 흔적 | 모든 엔딩 대상 | 제안 | 선택과 활동의 기억을 짧게 되짚는다. | 이야기에서 중요했던 선택, 자주 해 온 활동, NPC와 장소에서 쌓인 경험 중 일부가 회고 장면에 반영된다. 플레이어에게 기억력 시험을 하거나 모든 일정을 나열하지 않는다. | 각 플레이어가 실제로 경험한 내용만 간결하게 회수한다. |
| 3 | 앞으로의 길 | 조건에 해당하는 엔딩 대상 | 제안 | 플레이 기록에 맞는 미래 진로가 드러난다. | 공통 연출 뒤, 아래 엔딩 유형 중 한 갈래의 진로 장면을 보여준다. 엔딩 화면에는 숨은 수치나 점수표를 노출하지 않는다. | 여러 엔딩 조건을 동시에 만족할 때의 처리 방식은 미정. |
| 4 | 그 길의 첫 걸음 | 선택된 진로의 주인공 | 제안 | 직업의 이름보다 실제로 하게 될 일을 보여준다. | 주인공이 진로와 관련된 작은 일을 맡고, 그 과정에서 자신이 아카데미에서 쌓은 경험을 활용한다. 친숙한 인물이 등장할 수 있지만 필수 등장은 아니다. | 기존 배경·캐릭터 자산을 우선 재사용한다. |
| 5 | 내가 기억하고 싶은 것 | 주인공, 베른 | 제안 | 플레이어가 한 해를 개인적으로 돌아본다. | 베른이 기억하고 싶은 순간을 떠올릴 기회를 준다. 응답을 건너뛰거나 선택해도 진로와 엔딩 결과가 바뀌지 않는다. | 하트 레코드·개인 회고 원문은 비공개이며 보호자 리포트에서 제외한다. |

## 엔딩 유형 제안

각 유형의 조건은 특정 활동 하나나 단일 능력치로 결정하지 않는다. **관련 활동이 반복된 정도 + 관련 사건·선택 + 플레이 중 남은 관계나 발견의 흔적**을 함께 고려한다. 아래 조건은 방향을 보여주는 서술형 기준이며, 수치와 가중치는 미정이다.

### 1. 룬 연구자 — 《새로운 문양을 읽는 사람》

| 항목 | 내용 |
|---|---|
| 대상 명 | 룬 현상과 원리를 알아가는 활동이 두드러진 플레이어 |
| 시작 조건 | 룬 관련 수업·조사·퍼즐 참여가 누적되고, 메인 에피소드에서 현상을 관찰하거나 근거를 살피는 선택이 의미 있게 나타남 |
| 종료 조건 | 룬을 연구하는 주인공의 첫 탐구 장면과 앞으로의 연구 방향을 보여줌 |
| 전체 개요 | 아카데미에서 발견한 질문을 바탕으로, 주인공이 룬을 연구하고 다른 사람과 이해를 나누는 길을 시작한다. 모든 룬의 답을 이미 아는 결말은 아니다. |
| 상태 | 제안 |

**회차별 스토리:** 공통 1~2회차 후, 주인공이 낯선 룬 흔적을 관찰하고 기록한다. 마지막에는 발렌티누스나 관련 친구와 질문을 나누며 다음 연구 과제를 정한다. 룬의 모든 비밀을 푸는 최종 해답은 제시하지 않는다.

### 2. 아르카디아 탐험가 — 《아직 가보지 않은 길》

| 항목 | 내용 |
|---|---|
| 대상 명 | 모험과 장소 조사·발견을 꾸준히 선택한 플레이어 |
| 시작 조건 | 모험 일정과 환경 조사·발견 행동이 반복되고, 탐험을 통해 인물이나 장소에 반응한 기록이 있음 |
| 종료 조건 | 주인공이 새로운 답사 계획을 세우고 첫 탐험을 시작하는 장면을 보여줌 |
| 전체 개요 | 주인공은 아르카디아의 장소와 사람들을 더 알아가는 탐험가의 길을 택한다. 모험은 위험을 이기는 성과보다, 관찰하고 질문하며 길을 알아가는 일로 묘사한다. |
| 상태 | 제안 |

**회차별 스토리:** 공통 1~2회차 후, 주인공이 익숙한 장소의 지도를 펼쳐 다음에 살펴볼 곳을 표시한다. 이전 모험에서 만난 NPC가 방향이나 관찰할 점을 알려주고, 주인공은 준비물을 챙겨 출발한다.

### 3. 마도 장인 — 《손으로 완성하는 마법 도구》

| 항목 | 내용 |
|---|---|
| 대상 명 | 공방·도구·제작 활동을 자주 선택하고 실습 경험을 쌓은 플레이어 |
| 시작 조건 | 실습형 수업과 공방 관련 활동이 반복되고, 재료·도구를 살피거나 만들고 고치는 경험이 있음 |
| 종료 조건 | 주인공이 완성한 작은 마도 도구가 실제로 사용되는 장면을 보여줌 |
| 전체 개요 | 주인공은 마법과 손기술을 함께 쓰는 장인의 길을 시작한다. 특별한 전설의 물건을 단번에 만드는 것이 아니라, 누군가에게 쓸모 있는 작은 도구를 만들며 배워간다. |
| 상태 | 제안 |

**회차별 스토리:** 공통 1~2회차 후, 주인공이 익숙한 도구와 재료를 골라 간단한 마도 보조 도구를 만든다. 친구가 일상에서 그것을 사용해보고, 주인공은 다음 개선점을 기록한다.

### 4. 약초 정원사 — 《자라는 것을 돌보는 사람》

| 항목 | 내용 |
|---|---|
| 대상 명 | 약초·식물·돌봄 관련 수업과 온실 활동에 꾸준히 참여한 플레이어 |
| 시작 조건 | 온실·약초 활동과 생명 돌봄 경험이 반복되고, 메인 에피소드 1에서 식물에 관한 선택과 결과가 기록되어 있음 |
| 종료 조건 | 주인공이 작은 정원이나 약초 구역의 일상을 맡는 미래 장면을 보여줌 |
| 전체 개요 | 주인공은 식물의 변화를 살피고 필요한 돌봄을 배우는 약초 정원사의 길을 시작한다. 메인 에피소드 1의 특정 선택을 정답으로 판정하지 않고, 그 선택의 결과와 배운 점을 장면에 반영한다. |
| 상태 | 제안 |

**회차별 스토리:** 공통 1~2회차 후, 주인공이 새싹의 상태를 살피고 물·빛·자리 중 필요한 돌봄을 선택한다. 이전에 온실에서 만난 인물이 함께 관찰하고, 주인공은 식물이 변하는 모습을 이어서 지켜보기로 한다.

### 5. 아카데미 수호 기사 — 《안전한 길을 지키는 사람》

| 항목 | 내용 |
|---|---|
| 대상 명 | 수련·기량 활동과 안전·보호 역할에 꾸준히 참여한 플레이어 |
| 시작 조건 | 신체·도구 활용 수업과 안전을 살피는 행동이 이어지고, 협력 상황에서 보호나 점검 역할을 맡은 기록이 있음 |
| 종료 조건 | 주인공이 학생과 교직원의 안전을 돕는 첫 임무를 맡는 장면을 보여줌 |
| 전체 개요 | 주인공은 싸움에서 이기는 전사가 아니라, 주변을 살피고 안전한 길을 만드는 수호 기사의 길을 시작한다. 위험을 키우거나 적을 처치하는 장면은 필요하지 않다. |
| 상태 | 제안 |

**회차별 스토리:** 공통 1~2회차 후, 주인공이 수련장의 도구와 안전 구역을 확인하고 동료들이 안심하고 연습할 수 있도록 준비한다. 작은 훈련이 끝나면 함께 사용한 장비를 정리하며 첫 역할을 마친다.

### 6. 아카데미 교사 — 《다음 학생과 나누는 배움》

| 항목 | 내용 |
|---|---|
| 대상 명 | 수업 참여와 지식 공유·동료 도움의 경험이 꾸준히 나타난 플레이어 |
| 시작 조건 | 여러 수업에 지속적으로 참여하고, 알게 된 내용을 다른 학생에게 설명하거나 함께 연습한 기록이 있음 |
| 종료 조건 | 주인공이 후배 학생의 질문을 듣고 함께 배워가는 장면을 보여줌 |
| 전체 개요 | 주인공은 모든 것을 아는 완벽한 선생님이 아니라, 배운 내용을 쉽게 나누고 학생과 함께 답을 찾아가는 교사의 길을 선택한다. |
| 상태 | 제안 |

**회차별 스토리:** 공통 1~2회차 후, 후배가 수업 내용을 어려워하자 주인공은 자신이 이해했던 방식으로 간단히 설명한다. 후배의 질문으로 새로운 점을 함께 발견하며, 배움이 서로 오가는 장면으로 마무리한다.

### 7. 아카이브 기록관 — 《사라지지 않게 남기는 이야기》

| 항목 | 내용 |
|---|---|
| 대상 명 | 독서·기록·자료 정리와 관찰한 사실을 남기는 활동이 두드러진 플레이어 |
| 시작 조건 | 대서고 및 기록 관련 활동이 반복되고, 서로 다른 정보를 비교·정리하거나 발견을 보존한 경험이 있음 |
| 종료 조건 | 주인공이 사람과 장소의 이야기를 정리해 다음 학생이 읽을 수 있도록 남기는 장면을 보여줌 |
| 전체 개요 | 주인공은 자료를 보관하는 데서 그치지 않고, 기록의 맥락과 사람들의 경험을 함께 남기는 기록관의 길을 시작한다. 메인 에피소드 2에서 특정 기록을 선택한 것을 정답으로 만들지 않는다. |
| 상태 | 제안 |

**회차별 스토리:** 공통 1~2회차 후, 주인공은 한 해 동안 모인 기록 중 다음 학생에게 도움이 될 자료를 골라 정리한다. 빠진 부분이나 아직 모르는 점도 그대로 표시하고, 기록을 대서고에 보관한다.

| 시작 조건 | 표현 중심 수업이나 공연 준비에 반복 참여하고, 자신의 방식으로 생각이나 분위기를 나눈 경험이 있음 |
| 종료 조건 | 주인공의 짧은 공연 또는 창작 발표로 주변 사람들과 순간을 나누는 장면을 보여줌 |
| 전체 개요 | 주인공은 관객에게 완벽함을 증명하는 스타가 아니라, 마법과 예술로 이야기를 전하고 사람들을 한자리에 모으는 공연가의 길을 시작한다. |
| 상태 | 제안 |

**회차별 스토리:** 공통 1~2회차 후, 주인공은 한 해 동안 만난 장면에서 영감을 얻어 짧은 마법 공연을 준비한다. 무대의 세부 모양은 기존 공연·표현 자산을 재사용하고, 관객의 반응은 다양하고 따뜻하게 보여준다.

### 9. 마법 생물 돌봄이 — 《함께 살아가는 법을 배우다》

| 항목 | 내용 |
|---|---|
| 대상 명 | 동물·마법 생물과의 만남, 돌봄·관찰 활동이 꾸준히 기록된 플레이어 |
| 시작 조건 | 동물 NPC·펫·생명체 관련 활동에 반복 참여하고, 생명체의 행동을 살피거나 편안한 환경을 마련한 경험이 있음 |
| 종료 조건 | 주인공이 마법 생물의 생활을 돕는 첫 역할을 맡는 장면을 보여줌 |
| 전체 개요 | 주인공은 생물을 소유하거나 명령하는 사람이 아니라, 생김새와 습성을 알아가며 함께 지내는 돌봄이의 길을 시작한다. 루루 등 동물 NPC의 존재 여부와 무관하게 성립하도록 구성한다. |
| 상태 | 제안 |

**회차별 스토리:** 공통 1~2회차 후, 주인공은 낯선 마법 생물이 머물 곳을 살피고 먹이·쉼터·거리 중 필요한 것을 관찰한다. 생물이 편안하게 다가오거나 자기 방식으로 주변을 탐색하는 모습을 보며 이야기를 마친다.

### 10. 아카데미 행사 기획자 — 《모두가 함께하는 하루》

| 항목 | 내용 |
|---|---|
| 대상 명 | 행사·협력·공동 활동을 준비하고 여러 사람의 의견을 조율한 경험이 두드러진 플레이어 |
| 시작 조건 | 공동체 활동이나 행사 관련 이벤트 참여가 누적되고, 서로 다른 역할·선호를 함께 고려한 기록이 있음 |
| 종료 조건 | 주인공이 다양한 학생의 참여 방식이 반영된 작은 행사를 여는 장면을 보여줌 |
| 전체 개요 | 주인공은 모두가 똑같이 참여하게 하는 기획자가 아니라, 각자 편한 방식으로 함께할 수 있는 자리를 준비하는 행사 기획자의 길을 시작한다. |
| 상태 | 제안 |

**회차별 스토리:** 공통 1~2회차 후, 주인공은 학생들과 함께 작은 행사의 순서와 역할을 준비한다. 무대에 서고 싶은 학생, 조용히 돕고 싶은 학생, 잠깐 구경하고 싶은 학생 등 서로 다른 참여를 받아들인다. 행사가 끝나면 함께 만든 장면을 기억하며 마무리한다.

## 판정 및 분기 원칙

- 위 10개는 엔딩의 **서로 다른 결과 유형**이며, 각기 더 높은 단계나 더 좋은 성적을 뜻하지 않는다.
- 특정 엔딩은 관련된 플레이 기록의 조합으로 판정한다. 단일 수치, 단일 메인 선택, 플레이어의 도덕적 성향 하나만으로 엔딩을 결정하지 않는다.
- 메인 에피소드 4개의 결과는 각 엔딩의 주변 인물 반응과 회상에 반영할 수 있다. 특정 선택 하나 때문에 희망한 진로에 도달하지 못하게 하지 않는다.
- NPC 교류·공간 이벤트를 전부 완료해야 특정 진로를 볼 수 있는 구조로 만들지 않는다. 선택적 콘텐츠를 놓쳐도 유사한 플레이 경험으로 진로 조건을 충족할 수 있어야 한다.
- 여러 엔딩의 조건이 함께 맞을 경우 하나를 자동으로 선정할지, 후보 중 플레이어가 선택하게 할지는 미정이다. 플레이어가 선택한다면 조건과 의미를 이해할 수 있게 설명하되 점수표로 순위를 매기지 않는다.
- 기본 진행으로 도달할 수 있는 공통·균형형 진로가 필요한지는 테스트 후 결정한다. 엔딩은 실패/성공 등급으로 나뉘지 않는다.
- 직업명과 장면은 제안 상태다. 아카데미 세계관·수업 목록·기존 캐릭터 설정과 맞춰 조정할 수 있다.

## 미확정 항목

- 10개 진로의 이름과 세계관 적합성 최종 검토
- 진로별 내부 조건, 관찰 기간, 가중치와 최소 충족 기준
- 여러 조건 동시 충족 시의 판정 방식 또는 플레이어 선택 허용 여부
- 네 에피소드의 발생 주차 및 마지막 에피소드와 52주 마지막 메인 이벤트의 순서
- 직업 엔딩마다 등장할 인물, 배경, 필요한 최소 제작물
- 엔딩 이후 이어하기·계승 화면과의 연결 방식

이 문서는 공통 엔딩 장면을 늘리는 문서가 아니라, **52주 플레이와 네 에피소드의 경험을 종합해 도달하는 엔딩 유형 10가지**를 제안하는 문서다. 모든 유형은 기획 제안이며 조건·수치·분기 순위는 확정되지 않았다.
