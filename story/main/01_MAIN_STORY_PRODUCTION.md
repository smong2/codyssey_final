# LUMIA 메인 스토리 — 대화·이미지 연출 분해표
> **제작용 구조화 초안 / MS03는 사용자 요청에 따라 사건·연출 변경 / 날짜 유지** · 기준: `main_final.md` 및 `03_ENDINGS(1).md`
> 대사의 실제 문구를 쓰지 않고 **한 장면에서 오가는 말풍선, 대사 선택지, 그림 전환**을 미리 배치한다. 이미지 외 별도 행동·퀘스트·미니게임은 넣지 않는다.

## 1. 고정 원칙

- `MS01`~`MS06`을 사용한다. `MS02`~`MS05`는 각 에피소드 안에서 위기를 해결하며, `MS05`에서 수호 룬까지 완전히 회복된다. `MS06`은 후일담만 제공한다.
- 한 장면은 **NPC 대화 → 플레이어 발화 선택(2~3지) → NPC 반응 → 정지 이미지 변경**으로 진행한다. 이미지의 물건은 조작하지 않으며, 해당 행위는 이야기 속 인물이 대사 후 수행한 것으로 묘사한다.
- `왕복 1회`는 두 발화 묶음(상대/기록 1 + 플레이어 1)이다. 아래 횟수는 **기본 경로의 목표 대화량**이며 추가 힌트나 화자 변경에 따라 ±1왕복 정도 조정 가능하다.
- `선택 1회`는 **대사 선택 화면이 한 번 등장**하는 것을 뜻한다. 보기 2~3개를 한 번에 보여도 선택 횟수는 1회다. 모든 메인 이야기(`MS01`~`MS06`)에 최소 1회 이상 있다.
- 신규 이미지 수는 **공통 UI·기존 배경·기존 캐릭터 스프라이트를 제외한 고유 정적 그림 파일** 수이며, 아래 `ART-...`는 최초 사용 장면에서만 집계한다. 기존 보유 여부는 아트팀 확인이 필요하다.
- 메인 사건의 정보·해법은 메인 장면 안에서만 제공한다. 랜덤 NPC/장소 이야기의 완료 여부와 무관하게 진행된다.
