# 메인 스토리

전체 게임의 중심 이야기와 에피소드 연결을 보관합니다. 실제 이야기는 에피소드별 파일로 나누고, 현재 문서의 세계관·캐릭터와 충돌하지 않는지 확인합니다. [예시 템플릿](예시_메인_스토리.md)은 확정 시나리오가 아닙니다.

## 현재 기준 원본

- **최신 제작 기준:** [MAIN_STORY_PRODUCTION.md](MAIN_STORY_PRODUCTION.md)
- **서사 원본:** [main_final.md](main_final.md)
- 두 문서가 충돌하면 **실제 대화·이미지·장면 제작에서는 `MAIN_STORY_PRODUCTION.md`를 우선**하고, `main_final.md`는 제작본의 확정 변경을 따라 동기화합니다.
- `MS05`는 **12월 3일 별빛 축제에서 시계탑 수호 룬 문제까지 최종 해결**합니다.
- `MS06`은 **12월 24일 새로운 위기 없이 진행하는 따뜻한 겨울 놀이회·후일담**입니다.
- `09_MAIN_STORY_SCENARIO.md`, `09_feedback_시나리오_검토.md`, `MAIN_STORY_REVISED.md`는 개편 과정과 변경 이력을 확인하기 위한 자료이며, 이 과거 문서들이 현재 제작 기준과 충돌하면 `MAIN_STORY_PRODUCTION.md` → `main_final.md` 순으로 우선합니다.
