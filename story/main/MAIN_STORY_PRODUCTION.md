# LUMIA 메인 스토리 — 대화·이미지 연출 분해표
> **메인 스토리 최신 제작 기준 / 사용자 편집본의 대화·선택 횟수 유지 / 이미지 예산 축소 및 번호 재배열** · 서사 원본은 `main_final.md`이지만 두 문서가 충돌할 경우 실제 제작은 이 문서를 우선하고 `main_final.md`를 동기화한다.
> 대사의 실제 문구를 쓰지 않고 **한 장면에서 오가는 말풍선, 대사 선택지, 그림 전환**을 미리 배치한다. 이미지 외 별도 행동·퀘스트·미니게임은 넣지 않는다.

## 1. 고정 원칙

- `MS01`~`MS06`을 사용한다. `MS02`~`MS05`는 각 에피소드 안에서 위기를 해결하며, `MS05`에서 수호 룬까지 완전히 회복된다. `MS06`은 후일담만 제공한다.
- 한 장면은 **NPC 대화 → 플레이어 발화 선택(2~3지) → NPC 반응 → 정지 이미지 변경**으로 진행한다. 이미지의 물건은 조작하지 않으며, 해당 행위는 이야기 속 인물이 대사 후 수행한 것으로 묘사한다.
- `왕복 1회`는 두 발화 묶음(상대/기록 1 + 플레이어 1)이다. 아래 횟수는 **기본 경로의 목표 대화량**이며 추가 힌트나 화자 변경에 따라 ±1왕복 정도 조정 가능하다.
- `선택 1회`는 **대사 선택 화면이 한 번 등장**하는 것을 뜻한다. 보기 2~3개를 한 번에 보여도 선택 횟수는 1회다. 모든 메인 이야기(`MS01`~`MS06`)에 최소 1회 이상 있다.
- 신규 이미지 수는 **공통 UI·기존 배경·기존 캐릭터 스프라이트를 제외한 고유 정적 그림 파일** 수이며, 아래 `ART-...`는 최초 사용 장면에서만 집계한다. 한 장의 이미지를 같은 에피소드 안에서 여러 번 보여도 **신규 1장**으로 센다. 각 에피소드(`MS02`~`MS05`)는 신규 이미지를 최대 2장 사용한다. 실제 보유 여부는 아트팀 확인이 필요하다.
- 메인 사건의 정보·해법은 메인 장면 안에서만 제공한다. 랜덤 NPC/장소 이야기의 완료 여부와 무관하게 진행된다.
- 메인 장면의 학생 역할은 **주인공 선택 직후 회차 단위로 한 번 확정**한다. 주인공과 같은 학생은 해당 역할 후보에서 제외하고 다음 우선순위 학생을 배정한다. 확정 결과는 회차 동안 바꾸지 않는다.
- 조력 학생의 NPC 출연 가능 여부는 캐릭터의 주인공 해금 여부와 분리한다. 잠긴 캐릭터도 이야기 속 학생으로는 등장할 수 있다.

## 2. 주인공 선택 후 역할 캐스팅

### 2.1 회차 시작 시 캐스팅 규칙

주인공 `characterId`가 확정된 뒤 아래 순서로 `storyCast`를 만든다.

```text
주인공 선택
→ 역할별 후보 목록을 위에서부터 확인
→ 현재 주인공 제외
→ 이미 다른 핵심 역할에 배정된 학생 제외
→ 첫 번째 사용 가능한 학생을 역할에 확정
→ activeRun.storyCast에 저장
→ 같은 회차의 모든 메인·Location Story에서 동일 캐스팅 재사용
```

- 핵심 학생 역할은 한 회차 안에서 가능한 한 서로 다른 학생을 사용한다.
- 후보가 겹치는 경우 먼저 확정된 역할을 유지하고 다음 후보를 선택한다.
- 후보 8명이 모두 사용할 수 없는 예외 상황에서는 아래 32인 역할 적합표에서 같은 역할 태그를 가진 다른 학생을 찾는다. 그래도 없을 때만 이미 다른 역할에 배정된 학생의 재사용을 허용한다.
- 현재 후보 순서로 **32명 각각을 주인공으로 가정해 검산했을 때**, 메인 7개 학생 역할과 `LOC_GREENHOUSE_STUDENT`까지 총 8개 역할을 주인공과 겹치지 않고 서로 다른 학생으로 모두 배정할 수 있다.
- `MAIN_TEACHER`는 학생 32명이 아니라 기존 조력 인물 **발렌티누스**로 고정한다. 주인공 충돌이 없으므로 대체 캐스팅이 필요하지 않다.
- `MS05`와 `MS06`의 친구 그룹은 새 인물을 다시 뽑지 않고 **MS02 온실 학생 + MS03 광장 학생 + MS04 수련 학생**을 재사용한다. 한 해 동안 만났던 인물이 마지막 사건과 후일담에 다시 등장하도록 한다.
