# UI 수정 요청 기록

## 최신 일괄 수정 — 2026-10-14

현재 반영 상태: 펫 선택 진입점은 별도 환경설정이 아니라 마이룸의 가방 → 펫 탭이다. `PET01~PET10` 카드에서 해금/잠금·현재 선택·설명·보정을 표시하고, 선택한 펫은 마이룸에서 캐릭터 뒤에 나타난다. 세라의 경우 펫을 왼쪽으로 더 분리한다. 모험맵은 신규 4K WebP 배경·전경과 축소 충돌 마스크를 사용하고, 전경은 임시로 항상 캐릭터 앞에 둔다. 카메라 확대율은 0.7이며 충돌 보기 버튼은 제거하되 충돌 판정은 유지한다.

타이틀 최신 결정: 배경 전체 암전 제거, 로고 주변 국소 부드러운 음영/크림색 부제 빛무리. 검정 구간 광량 25% → 기존 배경 페이드 시간에 맞춰 100%. 로고 이동·영상 타이밍 유지. ‘다시 보기’는 테두리 없는 작은 버튼으로 왼쪽 상단, 뒤로가기도 왼쪽/건너뛰기는 오른쪽 상단이며 X는 기존 오른쪽.

최종 추가 결정: 가방의 미해금 캐릭터도 완전 단색 실루엣으로 표시한다. 이전의 가방 컬러 공개를 대체하며, 해금된 카드만 컬러다. 펫 미해금은 회색조 유지.

후속 보완: 카드 +는 기하학적 중앙 정렬, 선택/정보 프레임은 동일한 뷰포트 내 높이·내부 스크롤이며 뒤로가기는 왼쪽 상단이다. 뒤로가기·건너뛰기·대화기록 등 보조 버튼 테두리는 제거한다. 시작 선택 화면의 미해금 캐릭터 이미지는 디테일 없는 완전 단색 실루엣으로 덮고 회색 프레임/잠금/+ 없음은 유지한다. 가방 캐릭터 컬러 공개는 유지한다.

추가 최신 결정: 코랄은 선택된 카드 테두리와 + 버튼만 사용한다. 미선택 +는 크림색이며 카드 배경·이름표는 선택 시에도 색을 바꾸지 않는다.

아래 10/12 기록보다 이 결정이 우선한다. 최종 로고/부제 뒤 강한 빛무리와 더 낮은 타이틀 고정 위치, 원본 비율 초대장, 프로토타입 구성의 중앙 대화/임시 입학 대사, 가방 5개 탭과 32명 공개, 왼쪽 베른, 흰 X 닫기, 메뉴 열기 때 오른쪽으로 함께 밀림을 반영한다. 메뉴 패널도 같은 방향으로 들어오도록 왼쪽에 둔다. 원본·저장·정식 콘텐츠 상태는 보존한다.

최신 화면 피드백: 카드에서는 얼굴·상체를 확대하며 + 확대는 전신 전체를 표시한다. +는 PC 28px/모바일 24px로 줄인다. 미해금 카드는 프레임·이름표까지 전체 흑백이며 +가 없다. 가방 캐릭터 32명은 모두 컬러로 공개하고 미해금 상태만 표기한다. 가방 펫 미해금은 카드 전체 흑백이다. 공통 텍스트 조작은 테두리 버튼/타이트한 세로 여백, 밑줄·hover 변화 없이 클릭 scale만 적용한다. X는 흰 글자만 표시하는 예외다.

입학 대사는 게임 흐름 확인용 임시 배열이며 정식 작가 대사/캐스팅·보상/완료 기록과 분리한다. 정보용 서브 고딕은 기존 Pretendard를 시안 연결하며 기본 고운바탕은 유지한다. 후속 해금·퍼즐 연결·정식 프로필 원고와 실기기 검수는 미완료다. 상세 범위·검증은 engine README 최신 절을 따른다.

2026-10-12 사용자와 정리한 수정 목록. **요청한 UI 및 입학 연결을 엔진 시안에 반영했다.** 실제 대사·전용 책 애셋·수집품 데이터는 미등록 프레임이며 콘텐츠 완성 상태가 아니다.
이 목록은 기존 engine README의 현재 구현 설명과 구별한다. 최신 사용자 결정이 이전 계획보다 우선한다.

## 1. 타이틀·저장 슬롯

- 시작하기/새로 시작하기는 슬롯 선택 화면 없이 캐릭터 선택으로 진행한다.
- 슬롯 번호 순서상 첫 빈 슬롯에 자동 배정하며, 새 회차 생성 시 기존 저장 경계에 따라 저장한다. 기존 슬롯을 덮어쓰지 않는다.
- 빈 슬롯이 없으면 새 게임을 시작하지 않고 안내 메시지를 띄운다. 단순 비활성화만으로 끝내지 않는다.
- 이어서 하기는 타이틀을 유지한 채 그 위에 프레임을 띄운다. 전체 화면으로 교체하지 않는다.
- 프레임 안에는 슬롯 1~5를 1열 세로 목록으로 배치한다.
- 가장 위에 최근 저장 슬롯을 바로가기 카드로 중복 표시한다. 아래 슬롯 1~5에도 그대로 남는다.
- 최근 저장 기준은 마지막 플레이가 아니라 마지막으로 실제 저장에 성공한 슬롯이다. 게임 종료 때 별도 저장을 추가한다는 뜻은 아니다.

## 2. 알림·텍스트형 버튼·대화 조작

- 안내 메시지는 다시 하단으로 이동하고 잠시 나타난 뒤 자동으로 사라지게 한다. 하단 버튼을 가리지 않도록 배치한다.
- 시간 제안(아직 최종 확정 아님): 일반 안내 3초, 긴 안내 5초 후 페이드아웃. 새 알림으로 교체하면 시간 재시작.
- 저장 실패 등 조치가 필요한 문제는 알림이 사라져도 화면의 오류·재시도 진입점을 유지한다.
- 인트로 다시 보기 같은 텍스트형 버튼의 hover 흰 배경이 글자를 가리는 문제를 수정한다. 배경 없이 글자색·밑줄 변화 및 키보드 포커스 표시를 제안했다.
- 인트로 건너뛰기와 NPC 대화 건너뛰기는 오른쪽 상단, 대화기록 보기는 왼쪽 상단에 둔다.
- NPC 대화 데이터·화면이 미연결이면 실제 기록이나 완료 상태를 임의 생성하지 않는다.

## 3. 마이룸 캐릭터·프로필

- 캐릭터별 크기와 세로 위치를 조정한다. 키가 큰 남성 캐릭터는 조금 확대하고 아래로 내려 상대적으로 작아 보이는 문제를 줄인다.
- 성별 일괄 적용 대신 문서의 실제 키 정보(있을 경우)와 이미지 여백을 비교한다. 확인하지 못한 키는 추정하지 않는다. 정확한 보정값은 화면 비교 후 조정한다.
- 오른쪽 상단 프로필 버튼을 제거하고 왼쪽 상단 달력/날짜 UI 위에 클릭 가능한 프로필 UI를 배치한다.
- BT04_button_green.png를 프로필 배경으로 재사용하고 동그란 영역에 현재 캐릭터 얼굴을 넣는다.
- 클릭 시 지금과 같은 프로필 화면을 연다. 참고 이미지의 레벨·경험치·재화 등 미정 항목은 추가하지 않는다.

## 4. 메뉴 패널

- 버튼 바로 아래 펼치는 기존 메뉴 대신 오른쪽에서 왼쪽으로 들어오는 패널로 변경한다.
- 메뉴가 열릴 때 마이룸 화면도 왼쪽으로 조금 밀리고, 닫으면 복귀한다.
- 캐릭터가 패널에 최대한 가려지지 않도록 메뉴 폭과 마이룸 이동량을 함께 조정한다. 좁은 화면도 검증한다.

## 5. 스케줄·활동 카드·달력

- 활동 카드 1열 유지. 활동 카드 프레임 높이는 달력 높이에 맞추고 넘치는 카드는 프레임 내부 세로 스크롤로 본다.
- 활동 카드 앞에 대표 이미지 자리를 마련한다. 날짜에 등록하면 같은 이미지를 달력 칸에도 표시한다. 지난 일정도 같은 연결을 유지한다.
- 날짜 숫자는 더 크고 선명하게 표시한다.
- 활동 이미지가 있는 달력 칸에는 활동명 텍스트를 생략한다. 마우스/키보드 접근과 접근성 이름으로 활동명을 확인할 수 있게 한다.
- 활동 이미지가 없으면 공통 임시 아이콘과 활동명으로 표시한다. 새 이미지 생성·최종 애셋 선택은 별도 작업이다.
- 참조: 사용자 첨부 images.jpg의 카드 앞 이미지 및 달력 활동 이미지 구도. 게임 내용·수치까지 복제하지 않는다.

## 6. 다이어리

- 펼쳐진 책 형태: 왼쪽 바깥 분류 탭, 왼쪽 페이지 기록 목록, 오른쪽 페이지 상세 기록.
- 따뜻한 스크랩북 느낌의 사진·메모 카드, 테이프·책갈피·작은 장식을 참고한다.
- 목록 영역 내부 스크롤, 제목·닫기 진입점, 데이터가 없으면 빈 페이지 안내.
- 분류명은 참고 이미지 그대로 확정하지 않고 LUMIA 다이어리 역할과 최신 팀 문서로 확인한다.
- 페이지 넘김 모션을 엔진으로 구현할 계획이다. 오른쪽 페이지 접힘/펼침과 그림자, 전환 중 연속 클릭 방지를 제안했다.
- 필요한 신규 애셋: 책 배경, 왼쪽/오른쪽 페이지·책등, 분류 탭, 기록 카드/선택 테두리, 종이 장식. **아직 제작하지 않았다.**
- 참고 이미지의 제작·합성·상점 기능은 도입하지 않는다.

## 7. 가방

- 책/페이지 넘김 연출을 사용하지 않는다.
- 수집품을 카드형 목록으로 보여준다. 다이어리와 별개의 프레임으로 구분한다.

## 작업 경계

### 추가 승인·반영 내용

- 캐릭터 선택은 프로토타입 실제 코드의 카드/상세/+ 구도를 참고하며 기본 오픈 6명·남녀 탭·상세 선택·시작으로 구성했다.
- 시작 후 기존 초대장 문구(copy.admission)를 복원하고 사용자 이름을 대입했다.
- 입학 이야기 5개 장면을 작가 개요 순서대로 연결했다. 대사 없는 장면은 미등록으로 표시하고 스토리 완료/선택/보상은 생성하지 않았다.
- 날짜는 임시 아르카디아력 327년 1월 1일 월요일, 52주 종료 12월 30일, 마지막 1일 12월 31일이다.
- 인트로 영상·8초 페이드와 뒤 로고 달리 아웃·10초 영상 제거·타이틀 애니메이션은 변경하지 않았다.
- 검증: 자동 테스트 45개와 데스크톱/390×844 브라우저 시안을 확인했다. 상세 적용·미정 항목은 engine README의 최신 UI 절을 따른다.

### 남아 있는 제작 항목

실제 대사·NPC 배역/입학 동기, 책·페이지·책등/장식 애셋, 최종 활동 전용 썸네일, 아이템/이야기 기록 데이터, 공식 신장 수치와 최종 캐릭터 보정 검수. 현재 프레임/개발 설정을 최종 자원·완성 콘텐츠로 취급하지 않는다.

다음 구현 요청 시 전체 변경 계획을 먼저 알리고 관련 최신 문서·실제 자원을 다시 확인한다.
최신 사용자 요청으로 전체 UI와 캐릭터 선택(+ 전신 확대), 기존 초대장, 입학 장면 프레임을 함께 반영했다. 인트로~타이틀 연출은 유지했다. 이미지 생성·원본 애셋 교체·커밋·브랜치 전환은 하지 않았다.
engine 밖 변경, prototype/·lumia/ 수정, 데이터 삭제·대규모 이동, 근거 없는 최종 선택은 별도 결정이 필요하다.
