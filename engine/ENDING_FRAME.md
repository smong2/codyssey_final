# 엔딩 화면·결과 연결

기준: `document/09_AI_ENDING_LETTER.md`와 엔딩 시스템. 직업 판정·실제 플레이 기록 4~6개 및 중요 선택 최대 2개 선별·Gemini 호출·응답 안전 검증·회차 완료/저장은 백엔드/게임 규칙의 책임이며 이 화면은 결과를 표시합니다.

## 실제 52주 종료 경로

마지막 주간 요약 확인 → 준비 직업 저장 → `무엇을 지켰니?` → 미래 직업·작가 부제 → 편지+실제 기록 → 신규 해금이 있을 때만 요약 → `타이틀로` 저장 → RUN_COMPLETE 슬롯에서 다음 회차 선택.

실제 엔딩에는 `X → 마이룸`이 없습니다. 재접속하면 준비 저장된 같은 편지로 질문부터 시작하며 ready 편지를 다시 조회·생성하지 않습니다. 메뉴의 `전체 흐름 보기` 개발 진입점은 제거했습니다. 기존 예시 편지 함수는 테스트용이며 실제 결과 검증을 통과하지 못하고 회차 완료에 사용할 수 없습니다.

## 엔진 내부 adapter 제안 — 실제 API 계약 미확정

부팅 전에 `globalThis.lumiaEngineServices.loadEnding({slotId, runNumber})` 조회 함수를 제공합니다. 기본 실행에는 주입되지 않아 편지 단계는 연결 대기입니다. HTTP endpoint, 인증 방식, 실제 응답 필드명은 백엔드 담당 adapter가 변환해야 합니다. Gemini 키나 프롬프트를 브라우저에 두지 않습니다.

엔진 표시 모델:

```js
{
  slotId, runNumber,
  career: {id, name}, // 이미 준비된 직업과 일치해야 함
  playRecords: [], // 선택적 수신: 실제 횟수 기록 4~6개 {key, value}
  newUnlocks: [], // 선택적 수신: 이미 판정한 신규 표시 목록 {kind, id}
  letter: {
    status: 'pending' | 'ready' | 'failed',
    source: 'ai' | 'fallback',
    validated: true, // ready 응답은 백엔드 검증 완료 필요
    careerId,
    sections: {future, reflection, encouragement}
  }
}
```

ready 편지는 같은 슬롯·회차·확정 직업, 3개 필수 섹션, 검증 완료를 확인한 뒤 준비 저장하고 표시합니다. 콘텐츠 안전성·사실 근거 검증은 백엔드 책임입니다. 응답은 HTML로 해석하지 않습니다. pending/failed 상태에서도 확정 직업은 표시하며 조회 실패 시 일반적인 오류와 재시도를 제공합니다. 화면 이탈 뒤 도착한 응답은 무시합니다. fallback은 검증해 전달된 템플릿만 정상 편지와 동일하게 표시합니다.

기록 key는 `ENDING_RECORD_LABELS`의 수업/모험/NPC 만남/미니게임 클리어/NPC 스토리 완료/장소 발견/특별 발견/중요 선택을 사용합니다. 실제 전달 시 `playRecords`는 4~6개이며 비음수 정수·중복 key 금지를 검사합니다. 미제공이면 확인 가능한 로컬 기록만 표시하고 선별 연결 대기를 명시합니다. 모르는 수치를 0으로 채우지 않습니다.

신규 종류는 `character/pet/badge/background`입니다. 실제 신규 항목이 없으면 요약을 생략하고, 있으면 종류별 개수를 한 번에 표시합니다. 이 표시 목록을 읽는 것만으로 메타에 지급하지 않습니다. 실제 계정 메타 갱신과 운영 엔딩 저장의 원자성은 백엔드 통합 때 확정해야 합니다.

편지가 준비되지 않았거나 준비 저장에 실패하면 최종 완료를 막습니다. 실패한 준비 저장은 같은 응답으로 재시도하고, 마지막 완료 저장도 같은 스냅샷으로 재시도합니다. 저장 성공 전 타이틀로 나가지 않으며 열람 수·회차 완료를 중복 증가시키지 않습니다.

## 남은 연결

- 실제 기록 4~6개 및 중요 선택 선별, 계정 신규 해금 결과
- FastAPI endpoint/request/response와 Firebase 인증 adapter
- Gemini 생성·검증·재시도·fallback·결과 저장
- 운영 Ending Record·계정 메타의 원자적 저장과 실제 브라우저 검수

직업 10종+별길 개척자의 규칙 판정, 편지 수신과 로컬 최종 완료 경계는 엔진에 있습니다. 위 운영 기능과 AI 호출이 완료됐다는 뜻은 아닙니다. 상세 인계는 [연결·인계 안내](DATA_HANDOFF.md)를 참고하세요.
