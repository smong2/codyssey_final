# 게임 엔진 작업 영역

이 디렉터리는 게임 엔진 담당자가 코드를 작성하는 작업 공간입니다. 내부 구조와 기술 스택은 엔진 담당자가 결정·관리하며, 이 안내 문서는 특정 엔진이나 프레임워크를 확정하지 않습니다.

`minigame-demo/`에는 7종 미니게임을 시험하는 [독립 실행형 Phaser 3 데모](minigame-demo/README.md)가 있습니다. 이는 최종 통합 엔진이 아니라 Scene·로직·결과 계약을 검증하기 위한 자료입니다. 엔진 담당자에게는 [통합 작업 프롬프트](minigame-demo/ENGINE_INTEGRATION_PROMPT.md)를 전달할 수 있습니다.

- 담당 영역 참고 브랜치: `dev-ds` (AI가 임의로 전환하지 않음)
- 실행·설치·테스트 방식이 변경되면 [공식 실행방법](../document/실행방법.md)을 함께 갱신합니다.
- 다른 담당 영역의 변경이 필요하면 먼저 사용자 또는 해당 담당자와 조율합니다.
