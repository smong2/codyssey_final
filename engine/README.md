## 모험 지도 교체와 이야기 연결

지도 설정은 `src/core/adventure-mission.mjs` 한곳에서 관리합니다. 새 애셋이 준비되면 다음 순서로 교체합니다.

1. `ADVENTURE_MAPS`에 새 지도 ID를 만들고 `world / mask / foreground / thumbnail` 파일 경로를 지정합니다. 파일은 기존 `asset/map/`의 런타임 자원을 사용합니다.
2. 같은 월드 좌표 기준으로 `spawn` 시작점과 `zoom`을 설정합니다. `placement.forbiddenZones`에는 배치 금지 사각형 `{x, y, width, height}`를 넣습니다. 현재 온실의 금지 영역 데이터는 미제공이므로 빈 배열이며, 임의의 연출 영역을 금지 영역으로 추정하지 않습니다.
3. 교체할 장소의 `ADVENTURE_LOCATIONS.mapId`를 새 지도 ID로 지정합니다. 플레이 맵과 활동 카드·달력·다이어리 썸네일이 같은 설정을 읽습니다. 미등록 지도 ID는 온실로 몰래 대체하지 않고 오류로 처리합니다.

## 모험 이동 시안 — 2026-10-12

스케줄 → 모험 탭 → 유리 온실 모험 카드 → 평일 날짜 지정 → 이번 주 일정 시작 → 해당 날짜의 모험 시작으로 진입합니다. 방향키/WASD, 화면 클릭·터치 또는 좌하단 방향 버튼으로 이동합니다. 클릭은 목적지 방향으로 이동하며 자동 경로 찾기는 하지 않습니다. 검은 경계에 막히면 멈춥니다.

이 절의 초기 충돌 자원 기록은 현재 `asset/map/` 구성으로 대체되었습니다. 현재 월드는 3840×2160 WebP, 충돌 마스크는 1920×1080 흑백 PNG이며 좌상단 원점과 정규화 좌표로 대응합니다. 발 한 점이 불투명 순백색 픽셀에 있을 때만 이동을 허용하고 검정·회색·반투명·범위 밖은 차단합니다. 이동 중간 지점을 검사해 벽 관통을 방지합니다. 현재 시작점은 월드 좌표 1920,2000인 개발 시안 위치이며 최종 입장 위치가 아닙니다.

충돌 보기 버튼은 제거했지만 내부 충돌 판정은 유지합니다. 투명 전경 WebP는 사용자 승인에 따라 정렬 기준선·영역 데이터가 제공되기 전까지 항상 캐릭터 앞에 표시합니다. 이동 자원은 사용자 첨부 LUMIA_ADVENTURE_MAP_SPEC.md를 참고하고, 조사·종료·성장·임시 목표 처리 규칙은 최신 `document/content/10_COMMON_ENGINE_FRAME.md`를 따릅니다. 기본 6명의 SD는 `asset/sd_character/`에서 읽으며 선택한 학생과 NPC별로 구분합니다. 이전 `prototype/assets/SD03_*_strip.png` 공용 경로는 이전 시안 호환용이며 현재 모험의 실제 로더는 사용하지 않습니다.

## 저장의 한계와 안전장치

현재 저장은 **계정 저장을 대신하는 개발용 localStorage adapter**입니다. 키는 `lumia.engine.dev.v1`입니다. 로그인·서버·DB와 연동하지 않았으며 같은 브라우저와 주소에서만 유지됩니다. 개발판은 한 탭에서 사용하세요. 여러 탭의 동시 진행·충돌 병합은 아직 지원하지 않습니다.

- 주중 일정과 미니게임 중간은 저장하지 않습니다. 새로고침·종료 후 마지막 회차 생성/주말 저장 상태에서 다시 시작합니다.
- 다른 슬롯으로 이동하려면 현재 주 일정과 주말 저장을 마쳐야 합니다. 주중 결과가 다른 슬롯 저장에 섞이지 않게 하는 개발판 제한입니다.
- 저장 실패 시 다음 행동을 멈추고 재시도 버튼을 제공합니다. 재시도는 실패 당시의 경계 스냅샷만 저장합니다.
- 손상된 JSON이나 지원하지 않는 버전은 자동 초기화·덮어쓰기하지 않고 진행을 중단합니다. 자동 복구·버전 이관은 후속 작업입니다.
- 전체 메타 초기화 기능을 제공하지 않습니다.

정식 메인/NPC/지역 시나리오 원고·캐스팅, 대서고·별빛 천문대 전용 애셋, 최종 미션 데이터·밸런스·금지 영역, 수집·해금 판정과 메타 API, 개인화 엔딩 편지·계정/서버 저장·AI 기능은 후속입니다. 엔딩 직업 판정·회차별 결과 준비와 최종 확인 후 로컬 회차 완료는 엔진에 연결되어 있습니다. 현재 모험의 NPC 인사·활동 후 이야기·선택·다이어리는 임시 콘텐츠를 사용하는 엔진 연결이며 정식 콘텐츠 전체 완료를 뜻하지 않습니다.

후속 작업은 정식 스토리 원고/캐스팅·선택 효과, 관리자 설정 전달 경로, 전용 지도·미션 마스터, 백엔드 계정/엔딩 편지 API 연결입니다. 확정되지 않은 보상·밸런스·스토리 선택 효과는 엔진에서 임의로 만들지 않습니다.
