# 엔진 자산 인계 메모

기준일: 2026-10-14  
관련 작업: GitHub #142 — WBS 5.4.2 파일 ID·규격·사용 화면 인계

이 문서는 엔진 코드가 현재 참조하는 이미지와 화면 용도를 디자인 담당자와 대조하기 위한 메모입니다. **코드 참조 확인은 시각 디자인 승인이나 최종 검수를 뜻하지 않습니다.** 자원 파일의 원본·이름·내용은 이 문서 작업에서 변경하지 않았습니다.

## 현재 참조 경로

엔진 정적 서버는 화면 코드의 다음 경로를 저장소 자원으로 연결합니다.

| 화면 코드 경로 | 저장소 경로 |
|---|---|
| `world-assets/{파일}` | `asset/background/{파일}` |
| `character-assets/{파일}` | `asset/character/{파일}` |
| `design-assets/{분류}/{파일}` | `asset/{분류}/{파일}` |
| `sd-assets/SD03_{방향}_strip.png` | `prototype/assets/SD03_{방향}_strip.png` (읽기 전용 참조) |

## 디자인 담당자 확인 요청

- 규격이 카테고리 문서에 없는 UI 프레임과 학생 이미지의 실제 캔버스 크기·투명 여백·안전 크롭 기준을 확인합니다.
- 코드에 연결된 파일이 각 화면에서 사용할 최종 선택본인지, 아니면 시안/대체 이미지인지 표시합니다. 이 문서는 파일 존재만으로 최종 채택을 판정하지 않습니다.
- 활동 카드의 장소 배경 썸네일을 임시 연결로 유지할지, 활동 전용 썸네일을 별도로 전달할지 확인합니다.
- SD03의 현재 엔진 연결 범위와 모션 검수 상태를 확인합니다. 다른 SD 캐릭터 세트로 변경하거나 `prototype/` 파일을 수정하지 않습니다.
- 마이룸 퍼즐 탭은 배경별 조각 진행도와 지급 연결이 미등록입니다. 룬 회로 퍼즐 9개를 배경 퍼즐에 재사용한다고 가정하지 않습니다.
- 온실 배경·전경·충돌 파일의 좌표/규격은 [온실 맵 README](../asset/map/README.md)의 런타임 기준을 따릅니다. 전경 정렬 데이터가 추가되기 전까지 현재 임시 표시 규칙을 유지합니다.

## 범위와 미실시 검수

이번 메모는 엔진 코드의 자원 참조와 카테고리 README의 규격을 대조한 인계 자료입니다. 새 이미지 선택·수정, 디자인 승인, 크롬 시각 검수, GitHub 이슈/프로젝트 상태 변경, 커밋·푸시는 포함하지 않습니다. 규격이 문서에 없는 항목은 추측하지 않고 확인 대상으로 남깁니다.
