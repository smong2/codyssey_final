## 기준과 변경 방법

- 이 문서들은 기존 자료를 재구성한 현재 공유본입니다. 충돌 시 이 디렉터리를 우선하고, 판단 근거는 각 문서의 `출처`에서 확인합니다.
- 보관소의 기록에는 현재 방향과 다른 예전 안, 단순 시안, 미승인 후보가 함께 있습니다. 출처로 인용할 때는 채택 여부를 확인하세요.
- 결정되지 않은 기술, 일정, 담당자, 자원 선택은 추측으로 채우지 않고 `미정` 또는 `검토 필요`로 남깁니다.
- 이 디렉터리의 내용이 바뀌면 관련 [AI 기준 문서](../document_for_ai/00_READ_FIRST.md)도 함께 확인·갱신합니다.
