# 팀원 역할과 협업 경계

현재 자료에서 **개인별 공식 담당자와 최종 승인권자 명단은 확인되지 않았습니다.** 아래는 작업을 나눌 때 사용할 역할 구분입니다. 특정 팀원에게 임의로 배정한 표가 아닙니다.

| 작업 영역 | 주 책임 | 함께 확인할 문서·결과 | 담당자 |
|---|---|---|---|
| 기획·제품 | 목표, 플레이 흐름, 우선순위, 미정 항목 결정 | [개요](01_PROJECT_OVERVIEW.md), [콘텐츠](06_GAME_CONTENT.md) | 미정 |
| 세계관·서사 | 룬 법칙, 장소, 캐릭터 일관성, 대사 톤 | [세계관](02_WORLDVIEW.md), [캐릭터](03_CHARACTERS.md) | 미정 |
| 게임 콘텐츠 | 에피소드, 사건, 선택, 단서, 퍼즐, 세계 변화 정의 | [콘텐츠](06_GAME_CONTENT.md) | 미정 |
| 아트·UI | 이미지 제작·선정, 파일 ID, 상태별 자원, 화면 가독성 | [이미지 자원](04_ASSETS.md), [자원 폴더](../asset/) | 미정 |
| 클라이언트 개발 | 웹 화면, 입력, 상태 연결, 접근성·반응형 구현 | [개요](01_PROJECT_OVERVIEW.md), [콘텐츠](06_GAME_CONTENT.md) | 미정 |
| 데이터·서비스 | 콘텐츠 데이터 계약, 저장·서버·개인정보 경계 | 확정 사양이 필요한 영역; 현재 기술 선택 미정 | 미정 |
| 검수·운영 | 문서·이미지 링크, 실제 화면 품질, 미정/충돌 기록 | [문서 안내](00_README.md), [자원 상태](04_ASSETS.md) | 미정 |

## 변경 시 인계 규칙

1. 세계관·캐릭터·콘텐츠의 결정이 바뀌면 관련 상세 문서를 먼저 수정합니다.
2. 이미지가 추가·교체되면 `asset/` 파일과 [이미지 자원 문서](04_ASSETS.md)의 상태·링크를 함께 확인합니다.
3. 상세 문서가 달라지면 [AI 시작 문서](../document_for_ai/00_READ_FIRST.md)의 갱신 절차에 따라 짧은 기준 문서도 동기화합니다.
4. 담당자 배정·승인권·일정은 팀이 정한 뒤 이 표에 기록합니다. 변경 기록에는 날짜와 결정 근거를 남깁니다.

참고: [과거 문서 역할 정리](../lagacy/docs/LUMIA_DOCUMENT_AUDIT_2026-10-05.md), [디자인 제작 가이드](../lagacy/docs/LUMIA_DESIGNER_GUIDE.md). 이 자료들은 개인별 담당 배정을 확정하지 않습니다.
