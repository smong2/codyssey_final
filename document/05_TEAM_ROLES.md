# 팀원 역할과 협업 경계

이 문서는 현재 **작업 영역과 참고 브랜치**를 설명합니다. 개인별 실명 담당자와 최종 승인권자는 별도로 확정되지 않았습니다. 브랜치 표기는 책임 영역의 참고 정보이며 AI가 임의로 생성·전환하지 않습니다.

| 영역 | 주 작업 디렉터리 | 참고 브랜치·관리 | 주요 책임 |
|---|---|---|---|
| 엔진 | [engine/](../engine/) | `dev-ds` | 게임 엔진 코드, 내부 기술 구조, 실행 방식 |
| 스토리 | [story/](../story/) | `dev-hs` | 메인·NPC·장소·서브·엔딩 이야기 |
| 디자인 | [asset/](../asset/) | `dev-jw` | 이미지 자원, 카테고리 목록, 시각 검수 |
| 백엔드 | [backend/](../backend/) | 사용자 직접 관리; 브랜치 미기재 | API, DB, 향후 관리자 영역 |

[prototype/](../prototype/)은 기존 완성 기준물을 보존하는 영역이며, [lumia/](../lumia/)는 향후 최종 통합 결과물 영역입니다. 둘 다 일반 개인 작업 폴더로 배정하지 않습니다. 기획·제품 결정, 문서, 전체 검수의 개인 담당은 현재 미정입니다.

## 변경 시 인계 규칙

1. 각 담당자는 자신의 디렉터리를 중심으로 수정합니다. 다른 영역의 변경이 필요하면 직접 수정하기 전에 사용자 또는 담당자에게 알립니다.
2. 공통 문서 변경은 최소화합니다. 세계관·캐릭터·콘텐츠 기준이 바뀌면 관련 `document/` 문서와 [AI 요약](../document_for_ai/00_READ_FIRST.md)을 함께 확인합니다.
3. 이미지 추가·삭제·교체 시 해당 `asset/` 하위 README의 파일 목록·설명·미리보기를 함께 갱신합니다.
4. 엔진 실행 방식이 바뀌면 [실행방법](실행방법.md)을 갱신합니다.
5. 담당자·승인권·일정의 실제 배정은 팀이 정한 뒤 기록하고, 근거 없는 인물 배정은 하지 않습니다.
