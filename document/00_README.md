## 기준과 변경 방법

- 이 문서들은 기존 자료를 재구성한 현재 공유본입니다. 현재 저장소에서 확인 가능한 이 디렉터리를 작업 기준으로 사용합니다.
- 과거 원문·제작 기록은 현재 저장소에 포함되어 있지 않습니다. 출처를 확인하지 못한 사항은 확정 근거로 인용하지 마세요.
- 결정되지 않은 기술, 일정, 담당자, 자원 선택은 추측으로 채우지 않고 `미정` 또는 `검토 필요`로 남깁니다.
- 이 디렉터리의 내용이 바뀌면 관련 [AI 기준 문서](../document_for_ai/00_READ_FIRST.md)도 함께 확인·갱신합니다.

이 문서들의 초기 작성에 사용된 통합 기획·세계관·캐릭터·자원 제작 원문은 현재 저장소에 없습니다. 상세 근거가 필요한 결정은 해당 원문을 별도로 확인해야 합니다.
