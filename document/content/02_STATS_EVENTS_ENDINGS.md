# 스탯·이벤트·엔딩 시스템

## 1. 보이는 스탯

플레이어가 직접 확인하고 육성 계획에 사용하는 능력입니다.

| 스탯 | 의미 | 주요 획득 예시 |
|---|---|---|
| 체력 | 일정을 수행할 수 있는 현재 행동 자원 | 휴식, 주말 자동 회복, 일부 영구 보상 |
| 지식 | 학문, 이론, 문제 이해 능력 | 수업, 학술 관련 이벤트 |
| 표현 | 언어, 대화, 발표, 의사 전달 능력 | 관련 수업·대화·이벤트 |
| 기량 | 전투, 신체 활동, 도구 활용 능력 | 훈련형 수업·모험·미니게임 |
| 탐구 | 조사, 발견, 관찰, 탐험 능력 | 모험·조사·발견 이벤트 |
| 룬 | 룬 마법과 마법적 현상을 이해·활용하는 능력 | 룬 수업·퍼즐·스토리 이벤트 |

`체력`은 다른 능력치와 달리 현재 상태에 따라 소모·회복되는 자원입니다. 나머지 능력은 한 회차 동안 성장하는 육성 스탯입니다.

## 2. 보이지 않는 성향

화면에 숫자로 노출하지 않고 플레이 기록 내부에서 누적하는 성향입니다.

| 성향 | 의미 |
|---|---|
| 공감 | 다른 사람의 상황과 감정을 이해하려는 경향 |
| 책임 | 맡은 일과 약속을 끝까지 수행하려는 경향 |
| 호기심 | 새로운 장소·정보·현상을 알아보려는 경향 |
| 용기 | 부담이나 위험이 있어도 행동하려는 경향 |
| 협력 | 다른 사람과 함께 해결하려는 경향 |
| 독립성 | 스스로 판단하고 해결하려는 경향 |
| 신중함 | 충분히 살피고 생각한 뒤 결정하려는 경향 |
| 솔직함 | 자신의 생각과 사실을 숨기지 않고 표현하려는 경향 |

이 성향은 **좋은 사람/나쁜 사람을 판정하는 도덕 점수로 사용하지 않습니다.** 서로 다른 플레이 스타일을 기록하고, 특정 이벤트·대화·엔딩의 조건으로 사용합니다.

예를 들어 `협력`이 높다고 `독립성`이 낮아야 하는 구조로 만들 필요는 없습니다. 한 플레이어가 여러 성향을 동시에 높게 가질 수 있습니다.

## 3. NPC 이벤트 발생 규칙

모험 맵에는 기본적으로 NPC를 **무작위 1~2명** 배치할 수 있습니다. 단순 균등 랜덤 대신 **가중 랜덤**을 사용합니다.

NPC 출현 가중치에는 다음 정보를 사용할 수 있습니다.

1. NPC의 기본 출현 확률
2. 현재 장소와 NPC의 생활권·역할
3. 현재 주차·시기 및 필요 시 달력상의 계절
4. 해당 NPC와의 현재 관계·스토리 진행도
5. 현재 메인 스토리 진행 상태
6. 최근 해당 NPC를 만나지 못한 기간에 대한 보정

이를 통해 우연히 만나는 느낌은 유지하면서도 특정 NPC가 지나치게 오래 등장하지 않는 문제를 줄입니다.

NPC와 만나면 조건에 따라 일반 대화, 짧은 반응, NPC 개별 스토리, 특수 이벤트가 발생할 수 있습니다.

## 4. 공간 이벤트

수업을 진행할 때 일정 확률 또는 조건에 따라 **장소·공간 기반 스토리**가 발생할 수 있습니다.

공간 이벤트의 조건 예시는 다음과 같습니다.

- 특정 수업 또는 장소
- 특정 주차 이후
- 필요한 보이는 스탯
- 특정 NPC 스토리 진행 여부
- 이전 선택 또는 발견 기록

공간 이벤트는 수업에만 영구적으로 제한하지 않습니다. 향후 모험·마이룸·특수 활동에서도 장소 중심 이벤트를 사용할 수 있습니다.

## 5. 엔딩 구조

52주와 마지막 메인 이벤트를 완료하면 플레이 기록을 종합해 **미래 직업 엔딩**을 노출합니다.

엔딩은 최소 **10종 이상**을 목표로 합니다.

엔딩 조건은 단일 스탯 컷이 아니라 다음 요소를 조합합니다.

`보이는 스탯 + 숨은 성향 + 특정 이벤트 완료 + NPC 관계/스토리 + 실제 플레이 행동·선택`

예시 구조:

```text
특정 직업 엔딩
- 지식 일정 수준 이상
- 탐구 일정 수준 이상
- 호기심 관련 내부 조건 충족
- 관련 장소 이벤트 완료
- 특정 NPC 스토리 또는 대화 조건 충족
```

이 방식의 목적은 엔딩이 단순히 숫자를 올린 결과가 아니라 **52주 동안 어떤 활동과 선택을 했는지 보여 주는 결과**가 되게 하는 것입니다.

직업 목록, 각 조건의 정확한 수치, 여러 엔딩 조건을 동시에 만족했을 때의 우선순위는 **미정**입니다.
