# 수집·해금·보상 시스템

## 1. 수집 시스템 목표

수집 배지는 총 **약 200개**를 목표로 합니다.

기존처럼 한 카테고리에 50~60개를 몰아넣지 않고, **20~25개 이상의 작은 카테고리**로 세분화해 비교적 짧은 노력에도 카테고리 완성 보상을 받을 수 있게 합니다.

24개 카테고리를 사용할 경우 평균 약 8~9개의 배지가 한 카테고리에 들어갑니다. 실제 배지 수는 카테고리마다 다를 수 있습니다.

## 2. 수집 조건

배지는 다음과 같은 플레이 기록으로 획득할 수 있습니다.

- 모험에서 특정 획득물 발견
- 특정 보이는 스탯 달성
- 특정 행동·선택 누적
- NPC 개별 스토리 완료
- 특정 공간·서브·메인 이벤트 완료
- 미니게임 기록 달성
- 캐릭터·펫·배경 해금
- 특정 엔딩 확인
- 서로 다른 엔딩 누적 확인

배지를 획득하면 화면 중앙에 **획득 이유 + 배지 이름**을 짧게 노출합니다.

가방 또는 컬렉션 화면에서는 배지를 카테고리별로 확인할 수 있습니다.

## 3. 카테고리명 초안

카테고리 이름은 시스템 용어보다 플레이어가 바로 이해하고 재미를 느낄 수 있는 표현을 우선합니다. 아래 24개는 **초안**이며 실제 배지 설계에 맞춰 조정할 수 있습니다.

| 카테고리명 | 주요 내용 예시 |
|---|---|
| 과학은 재미있어! | 지식·수업·학술 활동 |
| 룬이 반짝! | 룬 능력·룬 퍼즐·마법 발견 |
| 말이 술술 | 표현·대화·발표 관련 기록 |
| 몸이 먼저! | 기량·신체 활동·훈련 기록 |
| 오늘도 탐험! | 모험 참여와 탐험 횟수 |
| 보물 찾았다! | 숨겨진 아이템·획득물 발견 |
| 여기 뭐가 있지? | 숨겨진 장소·조사 포인트 발견 |
| 친구가 생겼어 | NPC 첫 만남·관계 이벤트 |
| 끝까지 들어볼게 | NPC 개별 스토리 완료 |
| 선택의 순간 | 중요한 대화 선택·분기 경험 |
| 용기 한 스푼 | 용기가 필요한 행동·이벤트 |
| 마음을 알아줘 | 공감과 관련된 행동·이벤트 |
| 같이 하면 쉬워 | 협력 행동·공동 해결 |
| 약속은 지켜야지 | 책임 있는 행동·완료 기록 |
| 궁금한 건 못 참아 | 호기심·조사·새 정보 발견 |
| 차근차근 생각해 | 신중한 관찰·판단 행동 |
| 혼자서도 척척 | 독립적으로 해결한 기록 |
| 솔직하게 말해봐 | 솔직한 표현·대화 선택 |
| 미니게임 챔피언 | 미니게임 플레이·기록 달성 |
| 퍼즐 조각 착착 | 배경 퍼즐 조각 수집 |
| 마이룸이 좋아 | 마이룸 배경·꾸미기 해금 |
| 펫과 함께 | 펫 해금·동행 관련 기록 |
| 새로운 얼굴! | 플레이 가능 캐릭터 해금 |
| 또 다른 미래 | 직업 엔딩·복수 엔딩 발견 |

숨은 성향의 실제 내부 수치는 공개하지 않습니다. 성향 관련 배지는 특정 수치 자체보다 **플레이어가 실제로 수행한 사건·행동**을 기준으로 지급하는 것을 우선합니다.

## 4. 카테고리 완성 보상

한 카테고리의 배지를 모두 모으면 다음 중 하나 이상의 보상을 줄 수 있습니다.

- 최대 체력 또는 특정 스탯의 작은 영구 보너스
- 새로운 플레이 가능 캐릭터
- 새로운 펫
- 마이룸 배경 또는 배경 퍼즐 관련 보상
- 기타 꾸미기·특수 해금 요소

영구 체력·스탯 보너스는 다음 회차에도 계승합니다. 반복 플레이 밸런스가 무너지지 않도록 보너스 수치와 누적 상한은 별도 밸런싱이 필요합니다.

## 5. 캐릭터 해금

- 최종적으로 남학생 16명, 여학생 16명, 총 **32명**을 플레이 가능하게 합니다.
- 최초에는 남녀 각각 **3~4명** 정도만 선택할 수 있게 합니다.
- 나머지 캐릭터는 특정 플레이·수집·엔딩 등 조건을 충족하면 해금합니다.
- 캐릭터 32명의 메인 시나리오를 완전히 별개로 제작하기보다 공통 사건에 캐릭터별 대사·반응·일부 전용 장면을 결합하는 구조를 우선 검토합니다.

## 6. 펫 해금

- 처음에는 기본 펫 **1마리**를 사용할 수 있습니다.
- 특정 조건 또는 수집 카테고리 보상으로 추가 펫을 해금합니다.
- 펫의 세부 능력 효과는 **미정**입니다. 능력을 제공할 경우 특정 펫만 정답이 되지 않도록 작은 차이를 주는 방향을 권장합니다.

## 7. 마이룸 배경 퍼즐

미니게임 플레이 기록을 기반으로 배경을 한 번에 지급하지 않고 **퍼즐 조각** 형태로 보상합니다.

`미니게임 기록 달성 → 퍼즐 조각 획득 → 한 세트 완성 → 마이룸 배경 해금 → 사용자가 원하는 배경 선택`

배경 해금 상태는 회차를 넘어 계승합니다.
