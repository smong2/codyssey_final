# 수업·미니게임 시스템

> `engine/minigame-demo/`는 독립 플레이테스트용 참고 구현이며 **본편 수업·장소·스탯 기획을 결정하는 기준이 아닙니다.** 본편 기획은 이 문서와 스탯 시스템의 확정 규칙을 우선합니다.

## 1. 기본 방향

LUMIA의 수업은 **각 보이는 성장 스탯과 대응하는 짧은 미니게임**으로 구성합니다.

교육 내용을 문제 형식으로 직접 제시하기보다, 아이가 재미있는 게임을 플레이하는 과정에서 자연스럽게 `관찰 / 기억 / 분류 / 공간 추론 / 선택적 판단 / 반응 / 표현` 능력을 사용하게 하는 것을 목표로 합니다.

기본 원칙은 다음과 같습니다.

- 한 수업은 하나의 대표 성장 스탯과 연결하는 것을 우선합니다.
- `체력`은 수업으로 성장시키는 스탯이 아니라 수업 수행에 사용하는 행동 자원으로 유지합니다.
- 한 미니게임의 플레이 시간은 **최소 1분, 최대 3분 이내**를 목표로 합니다.
- 반복 플레이 피로도를 고려해 기본 플레이는 약 **60~90초**를 권장하며, 난이도 상승이나 보너스 구간을 포함해도 3분을 넘기지 않습니다.
- 지식을 묻는 퀴즈보다 **게임 행동 자체가 학습 경험**이 되도록 합니다.
- 이미 제작한 게임 규칙을 가능한 한 재활용하고, 수업에 맞게 테마·오브젝트·난이도를 변형합니다.

## 2. 본편 수업·공간 구조

본편은 주요 7개 공간마다 하나의 반복 플레이 콘텐츠를 둡니다. 다만 7개를 모두 미니게임으로 만들지 않고 **6개 미니게임 + 기숙사 공용 공간의 특수 활동 `요정의 거래` 1개**로 구성합니다.

| 장소 | 과목·활동 성격 | 수업·일정명 | 본편 콘텐츠 | 대표 결과 |
|---|---|---|---|---|
| 별빛 천문대 `OBS` | 천문 관측학 | 탐사 실습 | **거울 마법** | 탐험 성장 |
| 시계탑 광장 `CLK` | 공연 표현학 | 표현 수업 | **별빛 무대** | 표현력 성장 |
| 유리 온실·약초원 `GH` | 약초 분류학 | 약초학 실습 | **정령 화분 정리** | 지식 성장 |
| 기숙사 공용 공간 `DRM` | 자율 활동 | 요정과 만나기 | **요정의 거래** | 성장 스탯 간 1:1 이전 |
| 대서고 `LIB` | 고대 기록학 | 기록학 실습 | **봉인 서가** | 지식 성장 |
| 마도 공방 `WRK` | 룬 공학 | 마법훈련 | **룬 회로** | 마법 성장 |
| 수련장 `TRN` | 검술학 | 검술훈련 | **룬 핀 훈련** | 솜씨 성장 |

`거울 마법`과 `룬 회로`는 기존 데모의 핵심 조작을 본편 규칙으로 **재채택**합니다. 나머지 데모 게임은 본편 규칙으로 사용하지 않습니다. 세부 조작·판정·난이도·반복 변형은 [7개 공간 콘텐츠 상세 규칙](06_01_LOCATION_ACTIVITIES.md)을 따릅니다.

수업별 성공·실패·대성공의 판정 조건은 각 미니게임 콘텐츠에서 정의합니다. 판정 결과에 따른 공통 성장량은 [스탯 시스템](02_STATS_EVENTS_ENDINGS/01_STATS_SYSTEM.md)의 난이도별 표를 사용합니다.

## 3. 과거 제작 미니게임 활용 기록

아래 내용은 초기 기획에서 검토한 게임 규칙의 **참고 기록**입니다. 본편 게임의 최종 규칙·장소·난이도를 결정하는 기준으로 사용하지 않습니다.

1. 파이프를 이어 출발점에서 도착점까지 연결하는 퍼즐
2. 보물이 숨겨진 땅을 파서 보물 위치를 찾아내는 게임
3. 사천성처럼 같은 짝을 찾아 맞추는 게임
4. 랜덤으로 떨어지는 아이템 중 필요한 대상을 선택적으로 받아내는 게임

당시에는 네 게임을 다음처럼 수업에 연결하는 안을 검토했습니다.

| 수업 | 미니게임 이름 예시 | 활용 게임 | 게임 플레이 | 자연스럽게 사용하는 능력 |
|---|---|---|---|---|
| 고대학 수업 | 기억의 서고 | 짝 맞추기 | 고대 기록·식물·유물·룬 등의 그림에서 짝을 찾아 연결 | 시각 기억, 분류, 패턴 인식 |
| 검술훈련 | 표적 훈련 | 선택적으로 받아내기 | 날아오거나 떨어지는 대상 중 지정된 표적만 처리하고 다른 대상은 피함 | 선택적 주의, 억제, 반응 속도 |
| 탐사 수업 | 숨겨진 보물 | 땅 파기 | 제한된 탐색 안에서 단서를 이용해 보물 위치를 추론 | 공간 감각, 가설 수립, 탐색 |
| 마법훈련 | 룬 회로 | 파이프 연결 | 마력의 시작점과 최종 마법진을 룬 회로로 연결 | 공간 계획, 연결 관계, 패턴 이해 |

본편에서 이 규칙을 실제로 재사용할지는 각 장소 미니게임 WBS에서 별도로 판단합니다.

## 4. 과거 게임별 확장 아이디어

### 룬 회로 — 마법훈련

파이프 연결 게임을 마력의 흐름을 연결하는 룬 퍼즐로 표현합니다.

- 출발점: 마력석 또는 마력 발생 룬
- 중간: 회전 가능한 룬 회로
- 도착점: 완성해야 하는 마법진
- 난이도 요소: 가짜 룬, 분기, 제한된 회전 횟수, 복수의 마력 흐름

정답 지식을 외우게 하기보다 공간적으로 연결을 계획하는 과정 자체를 마법훈련으로 사용합니다.

### 숨겨진 보물 — 탐사 수업

땅 파기 게임은 단순한 무작위 선택보다 탐색 결과가 다음 선택의 단서가 되도록 구성하는 것을 권장합니다.

예시 단서:

- 보물과 가까워짐 / 멀어짐
- 흙 속에서 발견되는 룬 흔적
- 금속 반응
- 발자국, 뿌리, 돌조각 같은 주변 흔적

플레이어는 단서를 바탕으로 다음 위치를 정하면서 자연스럽게 `가설 → 확인 → 수정`을 반복합니다.

### 기억의 서고 — 고대학 수업

사천성형 짝 맞추기의 기본 규칙은 그대로 사용합니다.

타일 소재는 다음과 같이 바꿀 수 있습니다.

- 아르카디아 식물
- 마법 생물
- 고대 유물
- 별자리
- 룬과 상징

기본 모드는 같은 그림끼리 짝을 맞추는 방식으로 두고, 추후 난이도 확장 시 `씨앗 ↔ 꽃`, `열쇠 ↔ 상자`처럼 서로 연관된 두 대상을 연결하는 변형을 검토할 수 있습니다.

### 표적 훈련 — 검술훈련

랜덤으로 떨어지는 아이템을 받는 게임의 핵심인 **선택적 반응**을 검술훈련으로 변환합니다.

예:

- 훈련 표적 → 처리
- 보호 대상 또는 일반 물건 → 건드리지 않기
- 특수 표적 → 다른 입력 또는 타이밍 사용

플레이어는 짧은 시간 동안 `관찰 → 분류 → 행동 또는 억제`를 반복합니다.

## 5. 표현력 성장 무대와 신규 미니게임

표현력은 기존 장소인 **시계탑 광장** 안의 `아르카디아 야외무대`를 전용 성장 무대로 사용합니다. 새로운 주요 장소를 하나 더 만드는 것이 아니라 광장 내부의 공연 공간으로 취급합니다.

표현력 전용 미니게임의 최종 명칭은 **별빛 무대**를 사용합니다.

- 짧은 공연 또는 연극 상황을 사용합니다.
- 화면에 제시되는 상황·감정·룬 신호를 보고 적절한 표정·몸짓·연출을 타이밍에 맞춰 선택합니다.
- 한 장면의 의도를 관객에게 전달하면 해당 장면을 완성하는 구조를 기본 콘셉트로 합니다.
- 맞춤법이나 정답 대사를 묻는 퀴즈보다 **상황에 맞춰 표현하고 전달하는 행위**에 초점을 둡니다.

성장 대상은 `표현력`으로 확정합니다. 구체적인 입력 방식, 성공·실패·대성공 판정과 난이도별 패턴은 [7개 공간 콘텐츠 상세 규칙](06_01_LOCATION_ACTIVITIES.md)을 따릅니다.

## 6. 교육 설계 원칙

LUMIA의 미니게임은 교육용 게임이지만 플레이어에게 먼저 **재미있는 게임**으로 느껴지는 것을 우선합니다.

피하고 싶은 형태:

```text
이 룬의 이름은 무엇일까요?
1. ...
2. ...
3. ...
```

우선하는 형태:

```text
룬 회로를 연결한다
→ 공간 추론과 계획을 사용한다

짝의 위치를 기억해 찾아낸다
→ 시각 기억과 분류를 사용한다

필요한 표적만 처리한다
→ 선택적 주의와 억제를 사용한다

단서를 보고 다음 탐색 위치를 결정한다
→ 가설 수립과 공간 추론을 사용한다
```

즉 **교육 내용은 설명보다 게임 규칙 안에 녹여 넣는 것**을 기본 원칙으로 합니다.

## 7. 플레이 시간과 난이도

기본 플레이 흐름은 다음 정도를 권장합니다.

| 구간 | 역할 |
|---|---|
| 시작 10~15초 | 조작과 규칙을 자연스럽게 이해하는 쉬운 문제 |
| 약 15~60초 | 기본 난이도의 핵심 플레이 |
| 약 60~90초 | 속도 또는 복잡도 소폭 상승 |
| 이후 | 필요할 경우 보너스 구간, 전체 3분 이내 종료 |

반복 수업이 많은 52주 구조이므로 매번 최대 시간을 채우기보다 **짧게 다시 하고 싶은 플레이**를 목표로 합니다.

## 8. 본편 공통 결과 원칙

- 6개 미니게임은 `FAIL / SUCCESS / GREAT` 중 하나를 반환합니다.
- 결과에 따른 성장량은 [스탯 시스템](02_STATS_EVENTS_ENDINGS/01_STATS_SYSTEM.md)의 공통 표를 사용합니다.
- 운영 중 밸런스 조절을 위해 스탯별 관리자 `rewardMultiplier`가 설정되어 있으면 공통 표로 구한 기본 성장량에 해당 배율을 적용합니다. 이 배율은 플레이 난이도나 SUCCESS/GREAT 판정 자체를 바꾸지 않습니다.
- 플레이어가 미니게임에서 `포기하기`를 누르면 해당 세션은 `FAIL`로 종료합니다. 이미 소비한 체력과 일정 슬롯은 되돌리지 않습니다.
- 최종 결과가 나온 뒤 **같은 일정에서 즉시 다시 하기 기능은 제공하지 않습니다.** 같은 게임에 다시 도전하려면 이후의 다른 평일 일정에 해당 수업을 다시 등록해야 합니다.
- 같은 게임에서 2회 연속 실패하면 다음 플레이부터 실제 게임 난이도를 1단계 낮춥니다. 4회 연속 실패하면 최대 2단계 낮춥니다. 성공 또는 대성공하면 해당 게임의 연속 실패 횟수를 0으로 초기화합니다.
- 난이도 보정은 **플레이 난이도만** 낮춥니다. 성장량을 정하는 `rewardDifficulty`는 원래 `run.stats` 기준 난이도를 유지합니다.
- 브라우저 종료·프로세스 종료·네트워크 장애 같은 비정상 종료는 `FAIL`로 계산하지 않고, 최근 활동 시작 체크포인트에서 복구합니다.
- 기숙사 `요정의 거래`는 미니게임이 아니므로 위 `FAIL/SUCCESS/GREAT`와 연속 실패 보정을 사용하지 않습니다.

공통 결과 객체, 연속 실패 보정과 저장·복구 계약의 상세는 [7개 공간 콘텐츠 상세 규칙](06_01_LOCATION_ACTIVITIES.md)을 따릅니다.

## 9. 기획 완료와 퀄리티 개선의 경계

WBS 2.4의 기획 완료 조건은 `7개 공간 연결 / 조작 / 한 세션 흐름 / 결과 판정 / 4단계 난이도 / 반복 변형 / 포기·실패 보정 / 공통 결과 계약`을 문서로 확정하는 것입니다.

다음 항목은 중요하지만 **기획 작업완료 이후의 구현·플레이테스트·퀄리티 개선**으로 분리합니다.

- 그래픽·애니메이션·파티클·사운드 품질
- 실제 60~120초 체류 여부
- 터치 조작감과 판정 영역 미세 조정
- 난이도별 수치와 스테이지 데이터 튜닝
- 반복 플레이의 재미와 피로도 검증
- 모바일/태블릿 가독성
- 본편 Phaser Scene 통합과 실제 저장 이벤트 연결

## 10. 독립 데모 자료의 경계

과거 독립 플레이테스트의 구현 기록이 필요할 때만 [Phaser 3 미니게임 데모 구현 사양서](07_MINIGAME_DEMO_IMPLEMENTATION_SPEC.md)를 참고합니다.

해당 문서와 `engine/minigame-demo/`는 본편 개발의 기준 그 자체가 아닙니다. 다만 사용자 결정에 따라 `룬 회로`와 `거울 마법`의 핵심 조작만 본편에 재채택했습니다. 본편 구현은 이 문서와 [7개 공간 콘텐츠 상세 규칙](06_01_LOCATION_ACTIVITIES.md)의 최신 확정 내용을 우선합니다.
