# 수업·미니게임 시스템

## 1. 기본 방향

LUMIA의 수업은 **각 보이는 성장 스탯과 대응하는 짧은 미니게임**으로 구성합니다.

교육 내용을 문제 형식으로 직접 제시하기보다, 아이가 재미있는 게임을 플레이하는 과정에서 자연스럽게 `관찰 / 기억 / 분류 / 공간 추론 / 선택적 판단 / 반응 / 표현` 능력을 사용하게 하는 것을 목표로 합니다.

기본 원칙은 다음과 같습니다.

- 한 수업은 하나의 대표 성장 스탯과 연결하는 것을 우선합니다.
- `체력`은 수업으로 성장시키는 스탯이 아니라 수업 수행에 사용하는 행동 자원으로 유지합니다.
- 한 미니게임의 플레이 시간은 **최소 1분, 최대 3분 이내**를 목표로 합니다.
- 반복 플레이 피로도를 고려해 기본 플레이는 약 **60~90초**를 권장하며, 난이도 상승이나 보너스 구간을 포함해도 3분을 넘기지 않습니다.
- 지식을 묻는 퀴즈보다 **게임 행동 자체가 학습 경험**이 되도록 합니다.
- 이미 제작한 게임 규칙을 가능한 한 재활용하고, 수업에 맞게 테마·오브젝트·난이도를 변형합니다.

## 2. 수업과 스탯 대응

현재 `검술훈련`과 `마법훈련`은 필요한 수업으로 방향이 확정되어 있습니다. 나머지 세 수업의 이름과 세부 설정은 현재 제안안입니다.

| 보이는 스탯 | 수업 | 상태 | 수업에서 사용하는 능력 |
|---|---|---|---|
| 지식 | 고대학 수업 | 제안안 | 기억, 분류, 규칙·관계 파악 |
| 표현력 | 연극·표현 수업 | 제안안 | 상황 이해, 표현, 리듬과 타이밍 |
| 솜씨 | 검술훈련 | 방향 확정 | 반응, 집중, 선택적 판단, 조작 |
| 탐험 | 탐사 수업 | 제안안 | 공간 추론, 관찰, 탐색, 가설 확인 |
| 마법 | 마법훈련 | 방향 확정 | 공간 계획, 패턴 이해, 연결과 조합 |

수업별 정확한 스탯 상승량과 성공·실패에 따른 보상 차이는 추후 밸런싱합니다.

## 3. 기존 제작 미니게임 활용안

현재 활용 가능한 기존 미니게임은 다음 4종입니다.

1. 파이프를 이어 출발점에서 도착점까지 연결하는 퍼즐
2. 보물이 숨겨진 땅을 파서 보물 위치를 찾아내는 게임
3. 사천성처럼 같은 짝을 찾아 맞추는 게임
4. 랜덤으로 떨어지는 아이템 중 필요한 대상을 선택적으로 받아내는 게임

네 게임 모두 수업 시스템에 재활용하기 적합하며, 다음과 같이 연결하는 것을 우선 제안합니다.

| 수업 | 미니게임 이름 예시 | 활용 게임 | 게임 플레이 | 자연스럽게 사용하는 능력 |
|---|---|---|---|---|
| 고대학 수업 | 기억의 서고 | 짝 맞추기 | 고대 기록·식물·유물·룬 등의 그림에서 짝을 찾아 연결 | 시각 기억, 분류, 패턴 인식 |
| 검술훈련 | 표적 훈련 | 선택적으로 받아내기 | 날아오거나 떨어지는 대상 중 지정된 표적만 처리하고 다른 대상은 피함 | 선택적 주의, 억제, 반응 속도 |
| 탐사 수업 | 숨겨진 보물 | 땅 파기 | 제한된 탐색 안에서 단서를 이용해 보물 위치를 추론 | 공간 감각, 가설 수립, 탐색 |
| 마법훈련 | 룬 회로 | 파이프 연결 | 마력의 시작점과 최종 마법진을 룬 회로로 연결 | 공간 계획, 연결 관계, 패턴 이해 |

기존 게임의 핵심 규칙은 유지하고, 단순한 파이프·타일·아이템을 **룬 회로 / 고대 기록 / 훈련 표적 / 유적 탐사** 같은 아르카디아 소재로 바꾸는 방식을 우선합니다.

## 4. 기존 게임별 확장 방향

### 룬 회로 — 마법훈련

파이프 연결 게임을 마력의 흐름을 연결하는 룬 퍼즐로 표현합니다.

- 출발점: 마력석 또는 마력 발생 룬
- 중간: 회전 가능한 룬 회로
- 도착점: 완성해야 하는 마법진
- 난이도 요소: 가짜 룬, 분기, 제한된 회전 횟수, 복수의 마력 흐름

정답 지식을 외우게 하기보다 공간적으로 연결을 계획하는 과정 자체를 마법훈련으로 사용합니다.

### 숨겨진 보물 — 탐사 수업

땅 파기 게임은 단순한 무작위 선택보다 탐색 결과가 다음 선택의 단서가 되도록 구성하는 것을 권장합니다.

예시 단서:

- 보물과 가까워짐 / 멀어짐
- 흙 속에서 발견되는 룬 흔적
- 금속 반응
- 발자국, 뿌리, 돌조각 같은 주변 흔적

플레이어는 단서를 바탕으로 다음 위치를 정하면서 자연스럽게 `가설 → 확인 → 수정`을 반복합니다.

### 기억의 서고 — 고대학 수업

사천성형 짝 맞추기의 기본 규칙은 그대로 사용합니다.

타일 소재는 다음과 같이 바꿀 수 있습니다.

- 아르카디아 식물
- 마법 생물
- 고대 유물
- 별자리
- 룬과 상징

기본 모드는 같은 그림끼리 짝을 맞추는 방식으로 두고, 추후 난이도 확장 시 `씨앗 ↔ 꽃`, `열쇠 ↔ 상자`처럼 서로 연관된 두 대상을 연결하는 변형을 검토할 수 있습니다.

### 표적 훈련 — 검술훈련

랜덤으로 떨어지는 아이템을 받는 게임의 핵심인 **선택적 반응**을 검술훈련으로 변환합니다.

예:

- 훈련 표적 → 처리
- 보호 대상 또는 일반 물건 → 건드리지 않기
- 특수 표적 → 다른 입력 또는 타이밍 사용

플레이어는 짧은 시간 동안 `관찰 → 분류 → 행동 또는 억제`를 반복합니다.

## 5. 표현력 수업 신규 미니게임 제안

현재 제작된 4종에는 표현력과 직접 연결하기 좋은 게임이 없으므로 표현력용 미니게임 1종은 신규 제작을 우선 검토합니다.

현재 제안은 **연극·표현 수업 — 마법 무대**입니다.

- 짧은 공연 또는 연극 상황을 사용합니다.
- 화면에 등장하는 감정·동작·마법 신호를 리듬과 타이밍에 맞춰 처리합니다.
- 캐릭터가 성공한 입력에 맞춰 표정, 손짓, 짧은 대사, 마법 효과를 보여 줍니다.
- 맞춤법이나 정답 대사를 묻는 퀴즈보다 **상황에 맞춰 표현하고 전달하는 행위**에 초점을 둡니다.

구체적인 조작 방식과 연출은 아직 **제안 단계**입니다.

## 6. 교육 설계 원칙

LUMIA의 미니게임은 교육용 게임이지만 플레이어에게 먼저 **재미있는 게임**으로 느껴지는 것을 우선합니다.

피하고 싶은 형태:

```text
이 룬의 이름은 무엇일까요?
1. ...
2. ...
3. ...
```

우선하는 형태:

```text
룬 회로를 연결한다
→ 공간 추론과 계획을 사용한다

짝의 위치를 기억해 찾아낸다
→ 시각 기억과 분류를 사용한다

필요한 표적만 처리한다
→ 선택적 주의와 억제를 사용한다

단서를 보고 다음 탐색 위치를 결정한다
→ 가설 수립과 공간 추론을 사용한다
```

즉 **교육 내용은 설명보다 게임 규칙 안에 녹여 넣는 것**을 기본 원칙으로 합니다.

## 7. 플레이 시간과 난이도

기본 플레이 흐름은 다음 정도를 권장합니다.

| 구간 | 역할 |
|---|---|
| 시작 10~15초 | 조작과 규칙을 자연스럽게 이해하는 쉬운 문제 |
| 약 15~60초 | 기본 난이도의 핵심 플레이 |
| 약 60~90초 | 속도 또는 복잡도 소폭 상승 |
| 이후 | 필요할 경우 보너스 구간, 전체 3분 이내 종료 |

반복 수업이 많은 52주 구조이므로 매번 최대 시간을 채우기보다 **짧게 다시 하고 싶은 플레이**를 목표로 합니다.

## 8. 추후 결정할 항목

- `고대학 수업 / 탐사 수업 / 연극·표현 수업` 명칭 최종 확정
- 표현력 미니게임의 실제 조작 방식
- 각 미니게임의 성공·실패 판정
- 미니게임 결과에 따른 스탯 상승량
- 수업별 체력 소비량
- 난이도 상승 방식과 반복 플레이 변형
- 기존 4종 게임의 실제 코드 재사용 범위

## 9. 구현 사양

Phaser 3로 실제 미니게임 데모를 제작할 때는 [Phaser 3 미니게임 데모 구현 사양서](07_MINIGAME_DEMO_IMPLEMENTATION_SPEC.md)를 기준으로 합니다.

해당 문서는 최신 논의 기준인 `몰입 가능 / 일반 플레이 1분 이상 / 단순 반응보다 사고 요구`를 적용해 1차 데모 구현 대상을 7종으로 정리하고, 엔진 담당자가 Scene 단위로 재사용할 수 있는 모듈 구조와 결과 인터페이스를 정의합니다.
