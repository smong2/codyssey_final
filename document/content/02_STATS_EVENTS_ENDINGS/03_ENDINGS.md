# 엔딩 시스템

## 1. 엔딩 구조

52주와 마지막 메인 이벤트를 완료하면 플레이 기록을 종합해 **미래 직업 엔딩**을 노출합니다.

엔딩은 최소 **10종 이상**을 목표로 합니다.

엔딩 조건은 단일 스탯 컷이 아니라 다음 요소를 조합합니다.

`보이는 스탯 + 보이지 않는 스탯 + 특정 이벤트 완료 + NPC 관계/스토리 + 실제 플레이 행동·선택`

예시 구조:

```text
특정 직업 엔딩
- 지식 일정 수준 이상
- 탐험 일정 수준 이상
- 호기심 관련 내부 조건 충족
- 관련 장소 이벤트 완료
- 특정 NPC 스토리 또는 대화 조건 충족
```

이 방식의 목적은 엔딩이 단순히 숫자를 올린 결과가 아니라 **52주 동안 어떤 활동과 선택을 했는지 보여 주는 결과**가 되게 하는 것입니다.

직업 목록, 각 조건의 정확한 수치, 여러 엔딩 조건을 동시에 만족했을 때의 우선순위는 **미정**입니다.
