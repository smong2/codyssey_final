# 엔딩 시스템

## 1. 엔딩 구조

52주와 마지막 메인 이벤트를 완료하면 플레이 기록을 종합해 **미래 직업 엔딩**을 노출합니다.

엔딩은 최소 **10종 이상**을 목표로 합니다.

엔딩 조건은 단일 스탯 컷이 아니라 다음 요소를 조합합니다.

`보이는 스탯 + 보이지 않는 스탯 + 특정 이벤트 완료 + NPC 관계/스토리 + 실제 플레이 행동·선택`

예시 구조:

```text
특정 직업 엔딩
- 지식 일정 수준 이상
- 탐험 일정 수준 이상
- 호기심 관련 내부 조건 충족
- 관련 장소 이벤트 완료
- 특정 NPC 스토리 또는 대화 조건 충족
```

이 방식의 목적은 엔딩이 단순히 숫자를 올린 결과가 아니라 **52주 동안 어떤 활동과 선택을 했는지 보여 주는 결과**가 되게 하는 것입니다.

직업 목록과 각 조건의 정확한 수치는 **미정**입니다.

## 2. 여러 엔딩 조건을 동시에 만족했을 때

한 회차에서 여러 직업 엔딩의 조건을 동시에 만족하는 것은 정상적인 상황으로 처리합니다. 플레이어에게 엔딩을 직접 선택하게 하지 않고, 이번 회차의 조건과 기존 엔딩 노출 기록을 이용해 하나를 결정합니다.

### 결정 순서

1. 이번 회차에서 조건을 만족한 직업 엔딩 후보를 모두 찾습니다.
2. 후보를 **아직 노출되지 않은 엔딩**과 **이미 노출된 엔딩**으로 구분합니다.
3. 아직 노출되지 않은 엔딩이 하나라도 있으면 이미 본 엔딩은 이번 판정에서 우선순위를 낮추고, **미노출 엔딩 후보만 대상으로 결정**합니다.
4. 미노출 후보가 여러 개라면 각 직업의 조건 충족 정도를 비교해 이번 플레이에 가장 가까운 엔딩을 선택합니다.
5. 조건 충족 정도가 같다면 해당 직업과 관련된 **대표 플레이 기록**을 비교합니다.
6. 대표 플레이 기록까지 같다면 해당 직업의 **대표 보이는 스탯**을 비교합니다.
7. 위 비교까지 모두 같다면 후보 중 하나를 무작위로 선택합니다.
8. 이번 회차에서 만족한 엔딩이 **모두 이미 노출된 엔딩**이라면 후보 전체에서 무작위로 하나를 선택합니다.

핵심 원칙은 다음과 같습니다.

`조건을 만족한 엔딩 안에서만 판정 → 미노출 엔딩 우선 → 모두 본 엔딩이면 랜덤`

미노출 엔딩을 우선한다고 해서 이번 회차에서 조건을 만족하지 않은 엔딩을 강제로 보여주지는 않습니다.

## 3. 엔딩 편지

엔딩은 단순 결과표보다 **아르카디아에서 보낸 52주를 돌아보는 편지** 형태로 전달합니다.

편지에는 최소한 다음 내용을 포함합니다.

| 항목 | 내용 |
|---|---|
| 미래 직업 | 이번 회차에서 결정된 직업 엔딩 |
| 스탯 기반 메시지 | 높은 보이는 스탯과 성장 방향을 자연어로 해석한 문장 |
| 플레이 기록 | 이번 회차에서 실제로 무엇을 얼마나 했는지 보여 주는 기록 |
| 기억에 남는 행동 | 가능하면 대표 사건·발견·선택 중 하나를 짧은 문장으로 회고 |

편지에서는 `지식 342`처럼 수치를 그대로 나열하기보다, 스탯 수치를 바탕으로 **어떤 능력이 두드러졌는지 자연어로 설명**하는 것을 기본으로 합니다.

반면 플레이 기록은 실제 횟수를 보여줄 수 있습니다.

예시:

```text
아르카디아에서의 기록
- 수업에 참여한 횟수: 74회
- 모험을 떠난 횟수: 41회
- 새로운 장소를 발견한 횟수: 12회
- NPC와 만난 횟수: 86회
- 중요한 이야기를 완료한 횟수: 9회
```

모든 기록을 고정적으로 나열하기보다 **공통 기록과 해당 직업에 의미 있는 기록을 합쳐 4~6개 정도** 보여 주는 방향을 우선합니다.

예를 들어 탐험 계열 직업이라면 `모험 횟수 / 숨겨진 장소 발견 / 특별한 아이템 발견`을 강조하고, 관계·대화 계열 직업이라면 `NPC 만남 / NPC 스토리 완료 / 함께 해결한 사건`을 강조할 수 있습니다.

같은 직업 엔딩을 다시 보더라도 이번 회차의 플레이 기록과 대표 사건이 다르면 **편지 내용은 달라질 수 있습니다.**

## 4. 편지 기본 템플릿

```text
[캐릭터 이름]에게

아르카디아에서 보낸 52주 동안 너는 많은 것을 배우고,
직접 선택하며 너만의 길을 만들어 왔구나.

너의 미래는 「[직업명]」이야.

[주요 보이는 스탯에 기반한 성장 메시지]
[필요하면 보이지 않는 스탯과 플레이 성향에 기반한 메시지]

아르카디아에서의 기록
- [플레이 기록 1]: [횟수]
- [플레이 기록 2]: [횟수]
- [플레이 기록 3]: [횟수]
- [플레이 기록 4]: [횟수]

[이번 회차에서 기억에 남는 대표 행동·사건에 대한 문장]

[직업과 성장 방향을 연결하는 미래 메시지]

— 아르카디아 아카데미
```

직업별 실제 편지 문구와 어떤 플레이 기록을 우선 노출할지는 각 직업 엔딩 조건을 확정할 때 함께 정의합니다.
