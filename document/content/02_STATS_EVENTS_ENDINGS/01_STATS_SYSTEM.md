# 스탯 시스템

## 1. 보이는 스탯

플레이어가 직접 확인하고 육성 계획에 사용하는 능력입니다.

| 스탯 | 시작값 | 최소 | 최대 | 의미 |
|---|---:|---:|---:|---|
| 체력 | 100 | 0 | 100 | 일정을 수행할 수 있는 현재 행동 자원 |
| 지식 | 50 | 0 | 500 | 학문, 이론, 문제 이해 능력 |
| 표현력 | 50 | 0 | 500 | 언어, 대화, 발표, 의사 전달 능력 |
| 솜씨 | 50 | 0 | 500 | 신체 활동, 도구 활용, 손재주와 실기 능력 |
| 탐험 | 50 | 0 | 500 | 조사, 발견, 관찰, 탐험 능력 |
| 마법 | 50 | 0 | 500 | 룬 마법과 마법적 현상을 이해·활용하는 능력 |

`체력`은 소모·회복되는 현재 자원입니다. 나머지 5개는 한 회차 동안 성장하는 육성 스탯이며, 이후 캐릭터별 초기 보정을 적용합니다.

## 2. 보이지 않는 스탯

플레이어에게 숫자로 직접 노출하지 않고 플레이 행동과 선택을 기록하는 내부 스탯입니다.

보이지 않는 스탯은 모두 `0~300`, 시작값 `0`으로 사용합니다. 한 회차 안에서 선택 성향의 누적 차이를 충분히 남기되 쉽게 상한에 도달하지 않도록 보이는 성장 스탯보다 낮은 빈도와 작은 값으로 증가시킵니다.

| 스탯 | 시작값 | 최소 | 최대 | 의미 |
|---|---:|---:|---:|---|
| 공감 | 0 | 0 | 300 | 다른 사람의 상황과 감정을 이해하려는 경향 |
| 책임 | 0 | 0 | 300 | 맡은 일과 약속을 끝까지 수행하려는 경향 |
| 호기심 | 0 | 0 | 300 | 새로운 장소·정보·현상을 알아보려는 경향 |
| 용기 | 0 | 0 | 300 | 부담이나 위험이 있어도 행동하려는 경향 |
| 협력 | 0 | 0 | 300 | 다른 사람과 함께 해결하려는 경향 |
| 독립성 | 0 | 0 | 300 | 스스로 판단하고 해결하려는 경향 |
| 신중함 | 0 | 0 | 300 | 충분히 살피고 생각한 뒤 결정하려는 경향 |
| 솔직함 | 0 | 0 | 300 | 자신의 생각과 사실을 숨기지 않고 표현하려는 경향 |

보이지 않는 스탯은 도덕적 선악을 판정하는 점수가 아니라 **플레이 스타일을 기록하는 내부 값**입니다. 서로 반대처럼 보이는 항목도 반드시 `+/-` 한 쌍으로 움직일 필요는 없습니다.

보이지 않는 스탯은 감점하지 않습니다. 예를 들어 협력적인 선택을 했을 때 `협력 +3`을 주더라도 `독립성 -3`을 자동으로 적용하지 않습니다.

### 보이지 않는 스탯 증가 기준

보이지 않는 스탯의 주된 성장 수단은 **대화·이벤트에서 플레이어가 실제로 고른 선택**입니다. 수업·미니게임의 성공은 성격이나 태도와 직접 연결하기 어렵기 때문에, 해당 게임 행동이 특정 내부 스탯과 명확히 연결되어 있다고 콘텐츠 데이터에 표시된 경우에만 약한 신호로 반영합니다.

| 발생 원인 | 기본 증가량 | 적용 기준 |
|---|---:|---|
| 관련 수업·미니게임 성공 | `+1` | 해당 게임에 명시적인 내부 스탯 태그가 있을 때만 적용 |
| 일반 대화 선택 | `+3` | 선택의 의미가 해당 성향과 직접 연결될 때 |
| 성향이 명확한 중요 선택 | `+5` | NPC·서브·공간 이벤트의 중요한 선택 |
| 메인·핵심 이벤트 선택 | `+8` | 회차의 주요 사건에서 성향이 뚜렷하게 드러나는 선택 |
| 실패·무관한 행동 | `+0` | 내부 스탯을 억지로 연결하지 않음 |

하나의 선택에는 최대 2개의 보이지 않는 스탯 태그를 부여할 수 있습니다. 복수 태그를 사용할 때는 선택의 핵심 의미를 주 태그로 두고, 부가적으로 드러난 성향은 더 작은 값을 줄 수 있습니다. 어떤 경우에도 반대 성향을 자동으로 감소시키지 않습니다.

## 3. 스탯 증감 원칙

| 변화 유형 | 처리 원칙 |
|---|---|
| 일반 성공 | 관련 스탯 증가 |
| 일반 실패 | 원칙적으로 스탯을 깎지 않고 증가량 감소 또는 0으로 처리 |
| 선택의 대가 | 한 스탯이 오르는 대신 다른 스탯 또는 체력이 감소할 수 있음 |
| 스토리 결과 | 메인·서브 스토리의 중요한 결과에 따라 증가·감소 가능 |
| 과로·저체력 | 성장 스탯 자체를 영구 감소시키지 않고 일시적 효율 감소로 처리 |

스탯 감소는 실패에 대한 벌점보다는 **플레이어가 선택한 행동의 대가 또는 트레이드오프**로 사용하는 것을 기본 원칙으로 합니다.

### 수업·미니게임 성장량

수업·미니게임의 성공·실패·대성공 판정 자체는 각 게임 콘텐츠에서 결정합니다. 스탯 시스템은 현재 저장 성장 스탯에 따라 난이도 단계를 정하고, 전달받은 결과에 따라 아래 값만 적용합니다.

| 현재 `run.stats` | 난이도 | 실패 | 성공 | 대성공 |
|---:|---|---:|---:|---:|
| `0~100` | 쉬움 | `+0` | `+5` | `+10` |
| `101~200` | 보통 | `+1` | `+6` | `+10` |
| `201~350` | 어려움 | `+2` | `+7` | `+10` |
| `351~500` | 매우 어려움 | `+3` | `+8` | `+10` |

- 난이도 단계는 해당 성장 스탯의 **저장값 `run.stats`** 으로 판정합니다. 펫 임시 보정과 저체력 유효값 감소 때문에 난이도 단계가 바뀌지 않습니다.
- 대성공은 난이도와 관계없이 `+10`으로 통일합니다.
- 실패는 성장 스탯을 차감하지 않고 난이도에 따라 `+0~+3`만 적용합니다.
- 적용 후 저장 성장 스탯은 항상 `0~500` 범위로 제한합니다.
- 밸런스 목표는 한 회차에서 모든 스탯을 쉽게 500으로 만드는 것이 아니라, 한두 개의 주력 스탯에 집중했을 때 **12월 시작 무렵 500에 도달할 수 있는 정도**입니다.

## 4. 스탯 변화가 발생하는 주요 콘텐츠

| 콘텐츠 | 보이는 스탯 변화 | 보이지 않는 스탯 변화 | 비고 |
|---|---|---|---|
| NPC 대화·선택 | 가능 | 주요 반영 | 대화 내용과 선택에 따라 결정 |
| 수업·미니게임 | 주요 성장 수단 | 가능 | 수업별 대표 성장 스탯과 미니게임을 연결 |
| 모험 | 가능 | 가능 | 발견·미발견·조사 결과에 따라 차등 |
| 메인 스토리 | 가능 | 주요 반영 | 중요한 선택과 결과에 사용 |
| 서브 스토리 | 가능 | 주요 반영 | NPC·공간·선택과 연계 |
| 체력 부족·과로 | 유효 성장 스탯 `-30%`, 획득 성장량 `-50%` | 보이지 않는 스탯에는 배율 미적용 | 회복하면 원래 적용값으로 복구 |

현재 `검술훈련 → 솜씨`, `마법훈련 → 마법`을 포함한 수업·장소 연결은 [수업·미니게임 시스템](../06_CLASSES_MINIGAMES.md)을 따릅니다. 표현력은 시계탑 광장의 `아르카디아 야외무대`에서 진행하는 `마법 무대` 미니게임을 성장 경로로 사용합니다. 게임별 성공·실패 판정은 각 콘텐츠가 정의하고, 결과에 따른 성장량은 이 문서의 공통 표를 사용합니다.

## 5. 체력과 과로

- 체력 범위는 `0~100`, 시작값은 `100`입니다.
- 수업 1회는 체력 `10`, 모험 1회는 체력 `15`를 소비하며 **활동 시작 시점에 먼저 차감**합니다. 시작한 활동이 성공·실패·중단으로 끝나더라도 이미 소비한 체력은 반환하지 않습니다.
- 휴식은 휴식 활동을 선택한 뒤 `+40 / +50 / +70` 중 하나를 무작위로 회복합니다. 결과 문구는 각각 `조금 더 쉬고 싶다 / 잘 쉬었다 / 너무 잘 쉬었다`를 기본으로 사용합니다. 세부 휴식 선택지는 휴식 콘텐츠에서 정의합니다.
- 토요일과 일요일은 일정 선택 없이 자동으로 지나가지만 **체력을 자동 회복하지 않습니다.**
- 체력이 `10~30`이면 저체력 상태입니다. 이때 체력을 제외한 5개 보이는 성장 스탯의 최종 유효값을 `70%`로 사용하고, 새로 획득하는 성장량은 `50%`만 적용합니다.
- 저체력 성장량은 `floor(기본 획득량 × 0.5)`로 계산합니다.
- 보이지 않는 스탯은 플레이 선택 기록이므로 저체력 `-50%` 성장 효율을 적용하지 않습니다.
- 하루가 시작될 때 체력이 `0~9`이면 그날부터 강제 휴식 상태에 진입합니다. 수업·모험의 시작 비용으로 활동 도중 `0~9`가 된 경우에는 이미 시작된 당일 활동을 종료한 뒤 다음 행동 가능한 평일부터 강제휴식을 시작합니다.
- 강제휴식은 **평일 3일**이며 3일이 끝나면 체력을 `100`으로 회복합니다. 토·일은 강제 휴식 3일에 포함하지 않습니다.
- 강제휴식에 해당하는 기존 일정은 잠긴 `강제휴식`으로 교체하며 플레이어가 수정할 수 없습니다. 강제휴식은 주 경계를 넘어 다음 주 평일까지 이어질 수 있습니다.
- 정상적인 콘텐츠 중단 결과는 스탯 변화를 `0`으로 처리합니다. 비정상 종료의 복구 여부는 저장 시스템의 마지막 안정 저장 경계를 따릅니다.
- 과로에 따른 감소는 성장 스탯 원본값을 깎지 않습니다.

### 보정 적용 순서와 상한

새 회차의 저장 성장 스탯은 다음 순서로 만듭니다.

```text
기본 성장 스탯 50
+ 캐릭터 초기 보정
+ 수집 시스템에서 전달받은 영구 보너스
= 회차 시작 run.stats
```

영구 보너스의 실제 크기와 누적 상한은 수집·보상 시스템에서 결정하며, 스탯 시스템은 전달받은 값을 회차 시작값에 반영합니다.

플레이 중 성장과 펫 보정은 다음처럼 처리합니다.

```text
run.stats + 이번 행동의 성장량
→ 0~500 clamp

clamp(run.stats + petModifier, 0, 500)
= 보정 후 성장 스탯

저체력 상태라면
floor(보정 후 성장 스탯 × 0.70)
= 최종 유효 성장 스탯
```

따라서 어떤 캐릭터·수집·펫 보정을 사용해도 실제 판정에 사용하는 성장 스탯의 최대값은 `500`입니다. 저체력 `-30%`는 이 상한 처리 이후 마지막 단계에서만 적용하며 저장 원본을 변경하지 않습니다.

## 6. 이벤트 결과 처리 기준

하나의 중요한 행동이나 선택은 필요에 따라 다음 결과를 동시에 가질 수 있습니다.

`보이는 스탯 변화 + 보이지 않는 스탯 변화 + NPC 관계 변화 + 이벤트/스토리 플래그`

이 구조를 통해 같은 사건에서도 선택에 따라 서로 다른 성장 기록을 만들고, 이후 이벤트와 엔딩 조건에 활용합니다.
