# 스탯·이벤트·엔딩 시스템

이 디렉터리는 캐릭터 육성 결과를 만드는 **스탯, 이벤트, 엔딩** 규칙을 관리합니다.

## 문서 구성

1. [01_STATS_SYSTEM.md](01_STATS_SYSTEM.md) — 보이는·보이지 않는 스탯의 범위, 난이도별 성장량, 체력·저체력·보정 계산 규칙
2. [02_EVENTS.md](02_EVENTS.md) — NPC·공간 이벤트 발생 규칙
3. [03_ENDINGS.md](03_ENDINGS.md) — 52주 종료 후 미래 직업 엔딩 판정 구조

## 핵심 연결

`행동·선택 → 보이는 스탯 변화 + 보이지 않는 스탯 변화 + 관계·이벤트 기록 → 52주 종료 시 엔딩 판정`

수업·미니게임의 성공/실패/대성공 판정은 각 게임 콘텐츠에서 정의하고, 판정 결과가 성장 스탯을 얼마나 올리는지는 [스탯 시스템](01_STATS_SYSTEM.md)의 공통 난이도·성장량 표를 사용합니다.
