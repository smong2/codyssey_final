# 스탯·이벤트·엔딩 시스템

이 디렉터리는 캐릭터 육성 결과를 만드는 **스탯, 이벤트, 엔딩** 규칙을 관리합니다.

## 문서 구성

1. [01_STATS_SYSTEM.md](01_STATS_SYSTEM.md) — 보이는·보이지 않는 스탯의 범위, 난이도별 성장량, 체력·저체력·보정 계산 규칙
2. [02_EVENTS.md](02_EVENTS.md) — NPC·공간 이벤트 발생 규칙, 대화 선택 합류 규칙, 선택 결과·기록 계약
3. [03_ENDINGS.md](03_ENDINGS.md) — 52주 종료 후 `무엇을 지켰니?` 고정 문구, 미래 직업 엔딩 판정·개인화 편지 구조
4. [04_STORY_CHOICE_REWARDS.md](04_STORY_CHOICE_REWARDS.md) — Main/NPC/Location 77개 canonical choice의 스탯 보상 계층, Hidden 편향 보정, 이벤트 종료 결과 공개·DB 적재 규칙

## 핵심 연결

`행동·선택 → 보이는 스탯 변화 + 보이지 않는 스탯 변화 + NPC 조우·스토리·이벤트 기록 → 이벤트 END에서 보이는 성장 합계만 공개 → 52주 종료 시 엔딩 판정`

수업·미니게임의 성공/실패/대성공 판정은 각 게임 콘텐츠에서 정의하고, 판정 결과가 성장 스탯을 얼마나 올리는지는 [스탯 시스템](01_STATS_SYSTEM.md)의 공통 난이도·성장량 표를 사용합니다.
