# 콘텐츠 후속 결정 목록

현재 방향을 확정했지만 아직 세부 결정을 미룬 항목입니다. 시나리오·밸런스·UI·구현이 구체화될 때 이 목록에서 하나씩 확정합니다.

## 수업·미니게임

- `고대학 / 탐사 / 연극·표현` 수업 명칭 최종 확정
- 표현력 미니게임의 실제 조작 방식
- 각 미니게임 성공·실패·대성공 판정
- 기존 4종 게임의 실제 코드 재사용 범위

## 엔딩

- 직업 엔딩 최종 목록(최소 10종 이상)
- 엔딩별 보이는 스탯 조건
- 보이지 않는 스탯·NPC·이벤트·선택 조건
- 직업별 편지 문구와 직업별 우선 노출 플레이 기록

## 저장·계승

- 세이브 데이터 손상·버전 업그레이드 대응 방식
- 자동 저장 요청 실패 시 재시도 정책
- 동일 캐릭터 재플레이 횟수를 UI에 표시할지 여부

## 표현 범위

- 달력의 계절 아이콘 디자인
- 계절을 이벤트 조건으로 실제 사용할지 여부
- 계절별 배경 변화는 현재 범위에서 제외하지만 향후 확장 여부
