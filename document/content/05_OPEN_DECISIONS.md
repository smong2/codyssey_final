# 콘텐츠 후속 결정 목록

현재 방향을 확정했지만 아직 세부 결정을 미룬 항목입니다. 시나리오·밸런스·UI·구현이 구체화될 때 이 목록에서 하나씩 확정합니다.

## 스토리·일정

- 메인 스토리 총 회차
- 메인 이벤트 발생 주차와 간격
- 메인 이벤트가 발생한 주의 일반 일정 처리 방식
- 주말 자동 체력 회복량
- 일정별 체력 소비량
- 저체력 구간별 스탯 효율 감소 수치

## 이벤트

- NPC별 기본 출현 가중치
- 장소·주차·관계·최근 미등장 보정의 실제 계산식
- 공간 이벤트 발생 확률과 중복 방지 규칙

## 수업·미니게임

- `고대학 / 탐사 / 연극·표현` 수업 명칭 최종 확정
- 표현력 미니게임의 실제 조작 방식
- 각 미니게임 성공·실패 판정과 스탯 상승량
- 수업별 체력 소비량
- 기존 4종 게임의 실제 코드 재사용 범위

## 엔딩

- 직업 엔딩 최종 목록(최소 10종 이상)
- 엔딩별 보이는 스탯 조건
- 보이지 않는 스탯·NPC·이벤트·선택 조건
- 직업별 편지 문구와 직업별 우선 노출 플레이 기록

## 수집·보상

- 총 배지 수 최종 확정(현재 목표 약 200개)
- 5개 대분류와 총 25개 소분류의 최종 이름·배치
- 각 소분류에 들어갈 8개 실제 배지 획득 조건
- 소분류별 3단계 보상 기준과 보상 내용
- 각 카테고리 완성 보상
- 영구 체력·스탯 보너스의 크기와 누적 상한
- 캐릭터 해금 조건
- 펫 획득 조건 초안의 최종 수치와 펫 8·9 세부 조건

## 저장·계승

- 실제 세이브 슬롯 개수
- 자동 저장 사용 여부와 시점
- 세이브 슬롯 간 메타 진행 공유 여부
- `새로하기`에서 계승 원본을 선택하는 방식
- 완전 초기화/새 프로필 기능 필요 여부

## 표현 범위

- 달력의 계절 아이콘 디자인
- 계절을 이벤트 조건으로 실제 사용할지 여부
- 계절별 배경 변화는 현재 범위에서 제외하지만 향후 확장 여부
