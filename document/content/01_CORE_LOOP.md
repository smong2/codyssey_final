# 52주 플레이 루프와 주간 일정

## 1. 전체 플레이 흐름

현재 기준의 큰 플레이 흐름은 다음과 같습니다.

`주인공 선택 → 메인 스토리 1회차 → 마이룸 → 주간 일정 등록 → 평일 5회 행동 → 주말 자동 경과·체력 소폭 회복 → 다음 주 → 중간 메인 이벤트 → 52주 종료 → 마지막 메인 이벤트 → 직업 엔딩`

메인 스토리의 총 회차와 발생 주차는 **미정**입니다. 실제 시나리오가 작성된 뒤 이야기 호흡에 맞춰 결정합니다.

## 2. 주간 일정

한 주의 직접 행동은 **월요일부터 금요일까지 5회**입니다. 토요일과 일요일은 별도의 일정 선택 없이 자동으로 지나가며 체력이 소폭 회복됩니다.

| 일정 | 기본 플레이 | 주요 결과 |
|---|---|---|
| 수업 | 1~2분 내외 캐주얼 미니게임 | 관련 보이는 스탯 상승, 간헐적 공간 스토리 발생 |
| 모험 | 모험 맵 이동·조사·숨겨진 획득물 발굴 | 아이템·수집품 발견, NPC 조우·NPC 스토리 발생 |
| 휴식 | 휴식 행동 수행 | 체력 회복 |

토·일의 자동 회복량은 **미정**이며 밸런스 테스트로 결정합니다.

## 3. 체력 운영

체력은 행동을 제한하기 위한 처벌 수치가 아니라 **일정 관리에 긴장감을 주는 자원**으로 사용합니다.

- 수업과 모험 등 일정 수행 시 체력을 소모합니다.
- 체력이 낮아지면 스탯 상승 효율이 감소하거나 상승하지 않을 수 있습니다.
- 체력을 무시하고 무리하면 강제 휴식 상태에 들어갈 수 있습니다.
- 강제 휴식 상태에서는 체력이 **70% 이상 회복되어야** 다시 일반 일정을 수행할 수 있습니다.
- 정확한 일정별 체력 소모량, 저체력 구간별 페널티, 주말 자동 회복량은 밸런싱 단계에서 결정합니다.

강제 휴식은 단순 제재 화면보다 캐릭터나 학원 인물이 주인공의 상태를 걱정하는 짧은 장면과 연결할 수 있습니다.

## 4. 52주 구조

- 한 회차는 총 **52주**입니다.
- 직접 선택하는 일정은 기본적으로 `52주 × 평일 5회 = 최대 260회`입니다.
- 중간 메인 이벤트가 발생하는 주에는 일반 일정 수가 달라질 수 있습니다.
- 메인 이벤트의 회차와 발생 간격은 시나리오 확정 후 결정합니다.
- 52주 마지막에는 최종 메인 이벤트를 진행한 뒤 엔딩으로 이어집니다.

## 5. 달력과 계절 표현

대규모 계절별 배경 제작은 현재 범위에 포함하지 않습니다.

대신 달력 UI에서 봄·여름·가을·겨울을 작은 아이콘이나 색상 구분 등 **가벼운 시각 정보**로 표현하는 방향을 사용합니다. 향후 특정 이벤트의 발생 조건에 계절 또는 시기를 사용할 수 있지만, 계절별 전체 배경 교체를 전제로 하지 않습니다.

## 6. 반복 플레이를 위한 원칙

52주를 여러 캐릭터로 다시 플레이하는 게임이므로 매 회차가 완전히 같은 순서가 되지 않도록 다음 요소를 조합합니다.

- 주간 일정 선택
- NPC 가중 랜덤 조우
- 공간 이벤트
- 수집·해금 상태
- 캐릭터별 대사·반응
- 플레이어의 대화 선택
- 스탯과 숨은 성향
- 이전 회차에서 계승된 보상
