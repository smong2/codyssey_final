# 52주 플레이 루프와 주간 일정

## 1. 전체 플레이 흐름

현재 기준의 큰 플레이 흐름은 다음과 같습니다.

`주인공 선택 → MS01 입학·온보딩 → 52주 주간 육성 → 12월 3일 MS05 별빛 축제·수호 룬 최종 해결 → 49~51주차 안정된 학교생활 → 12월 24일 MS06 겨울 놀이회·후일담 → 52주차 마지막 자유 플레이 → 12월 31일 마지막 주간 요약 → 무엇을 지켰니? → 직업 엔딩·개인화 편지`

메인 스토리의 52주 배치는 확정합니다. `MS01 1월 1일 / MS02 3월 5일 / MS03 6월 4일 / MS04 9월 3일 / MS05 12월 3일 / MS06 12월 24일`이며 모두 해당 주의 일반 일정 시작 전에 노출합니다. **최종 위기와 수호 룬 문제는 12월 3일 `MS05`에서 완전히 해결**하고, 12월 24일 `MS06`은 새로운 위기가 없는 겨울 놀이회·후일담으로 진행합니다. `MS06`을 마친 뒤 `12월 24~30일`은 마지막 자유 플레이 주간이고 `12월 31일`은 엔딩 전용일입니다. 상세 제작 구조는 `story/main/MAIN_STORY_PRODUCTION.md`를 우선하고 `story/main/main_final.md`는 제작본에 맞춰 동기화합니다.

## 2. 주간 일정

한 주의 직접 행동은 **월요일부터 금요일까지 5회**입니다. 토요일과 일요일은 별도의 일정 선택 없이 자동으로 지나가며 **체력은 자동 회복하지 않습니다.**

| 일정 | 기본 플레이 | 주요 결과 |
|---|---|---|
| 수업 | 1~3분 이내 캐주얼 미니게임 | 관련 보이는 스탯 상승, 간헐적 공간 스토리 발생 |
| 모험 | 모험 맵 이동·조사·숨겨진 목표 발견 | 임시 목표 아이템 탐색, 발견 기록. Location Story는 활동 시작 체크포인트 뒤 실제 모험 화면 전에, NPC Story는 활동 완료 저장 뒤 별도 장면에서 판정 |
| 휴식 | `무엇을 하고 쉴지` 휴식 활동을 선택 | 결과에 따라 체력 `+40 / +50 / +70` 중 무작위 회복 |
| 특수 활동 | 현재는 기숙사 공용 공간의 `요정의 거래` | 성장 스탯 합계를 늘리지 않고 최대 5포인트 이전 |

휴식 결과의 기본 문구는 `+40 조금 더 쉬고 싶다 / +50 잘 쉬었다 / +70 너무 잘 쉬었다`로 사용합니다. 구체적인 휴식 활동 선택지는 휴식 콘텐츠에서 별도로 정의합니다.

수업과 공간 콘텐츠는 [수업·미니게임 시스템](06_CLASSES_MINIGAMES.md) 및 [7개 공간 콘텐츠 상세 규칙](06_01_LOCATION_ACTIVITIES.md)을 따릅니다. 본편은 6개 미니게임과 기숙사 공용 공간의 특수 활동 `요정의 거래`를 사용합니다.

### 주간 일정 등록 규칙

주간 일정은 월요일부터 금요일까지 5칸을 모두 채운 뒤 시작합니다.

1. 활동 카드를 월~금의 일정 칸에 배치합니다.
2. 날짜를 따로 지정하지 않고 활동을 선택하면 **현재 주에서 가장 이른 미등록 평일**에 자동으로 들어갑니다. 예를 들어 월요일에 마법수업이 이미 등록된 상태에서 운동 활동을 선택하면 화요일, 이어서 모험을 선택하면 수요일에 자동 등록합니다.
3. 특정 평일을 달력에서 먼저 선택한 뒤 활동을 선택하면 그 날짜에 등록합니다.
4. 이미 활동이 등록된 날짜를 클릭·터치하면 `활동명 / 닫기 / 일정 삭제`를 제공하는 상세 표시를 엽니다. 일정 삭제 후 해당 날짜를 다른 활동으로 다시 채울 수 있습니다.
5. `일정 시작` 전에는 삭제·재배치 방식으로 자유롭게 수정할 수 있습니다.
6. 강제휴식으로 잠긴 날짜를 포함해 월~금 5칸이 모두 채워져야 `일정 시작`을 사용할 수 있습니다.
7. `일정 시작` 후에는 해당 주의 일반 일정을 수정할 수 없습니다. 단, 강제휴식이 발생하면 시스템 규칙에 따라 예정된 일정이 강제휴식으로 교체될 수 있습니다.
8. 모험을 등록할 때는 `유리 온실·약초원 / 대서고 / 별빛 천문대` 중 실제 모험 장소까지 함께 지정합니다. 주간 일정 실행 중 장소 선택을 다시 묻지 않습니다.

### 평일 일정 실행

- `일정 시작`을 누르면 월요일 활동부터 순서대로 진행합니다.
- 월요일 활동이 끝나면 플레이어가 다시 `시작`을 누르지 않아도 화요일 예정 활동 화면으로 바로 전환하며 같은 방식으로 금요일까지 진행합니다.
- 여기서 `바로 전환`은 활동 자체를 입력 없이 자동 완료한다는 뜻이 아니라, 다음 수업·모험·휴식 콘텐츠의 시작 화면을 자동으로 보여 준다는 뜻입니다.
- 한 평일 활동이 끝날 때마다 마이룸으로 돌아가지 않습니다. **Location Story는 활동 시작 체크포인트 저장 뒤 실제 플레이 화면을 띄우기 전에 판정·재생하고, NPC Story는 활동 결과 저장 뒤 판정합니다. 필요한 이야기 장면 저장까지 끝난 뒤 다음 예정 활동으로 자동 진행**합니다.
- 정상 평일 진행에서 마이룸을 활동 공간으로 사용하는 일정은 `휴식`입니다. 휴식 일정에서는 마이룸에서 무엇을 하며 쉴지 선택하고 회복 결과 저장 후 다음 일정으로 자동 진행합니다.
- `오늘을 마무리하기`처럼 사용자가 임의로 평일 연속 흐름을 끝내는 기능은 사용하지 않습니다.
- 수업과 모험의 체력은 **활동 시작 시점**에 먼저 소비합니다.
- 일정 자체를 취소하고 같은 날 다른 행동으로 바꾸는 `행동 중단`은 제공하지 않습니다.
- 미니게임 내부에는 `포기하기`를 둘 수 있으며, 포기하면 해당 게임의 결과를 `FAIL`로 확정합니다. 체력과 일정 슬롯은 반환하지 않고 즉시 재도전도 제공하지 않습니다.
- `요정의 거래`에서 `거래하지 않기`를 선택하면 스탯 변화 없이 해당 일정 슬롯을 사용한 것으로 처리합니다.
- 브라우저 강제 종료·네트워크 장애·프로세스 종료 같은 비정상 중단은 `FAIL`로 처리하지 않고 활동 시작 체크포인트에서 복구합니다. 재접속/`이어 하기`에서는 해당 활동을 `INTERRUPTED`로 종료하고 복구 상태를 저장한 뒤 **마이룸을 복귀 허브로 먼저 표시**합니다. 마이룸에서 저장 phase를 확인해 다음 예정 활동으로 연결하며, 다음 일정이 휴식이면 그대로 마이룸의 휴식 UI를 사용합니다. 정상 플레이에서 활동 하나가 끝날 때마다 마이룸을 거치는 규칙으로 해석하지 않습니다.

### 모험 공통 흐름

직접 모험 장소는 `유리 온실·약초원 / 대서고 / 별빛 천문대` 3곳입니다. 세 장소 모두 제한시간 안에 숨겨진 목표 아이템을 전부 찾는 공통 미션을 사용합니다.

- 난이도에 따라 목표 아이템을 `1~5개` 배치합니다.
- 아이템은 충돌 마스크에서 시작점과 실제로 연결된 도달 가능 영역 안에만 배치합니다.
- 시작 전 모든 목표 아이템의 시계 방향 단서를 보여 주며, 플레이어가 추적할 단서를 선택할 수 있습니다.
- 최초 단서 화면에서는 이동과 타이머가 정지하고 `모험 시작`을 누른 뒤 카운트다운을 시작합니다.
- 수업 미니게임과 직접 모험 플레이 내부에는 NPC를 배치하지 않으며 NPC 대화·NPC/Location Story를 실행하지 않습니다.
- 모험 중 단서를 다시 보는 동안과 조사·시스템 로딩 중에는 타이머를 일시정지합니다.
- 조사 횟수 제한은 없으며 조사 실패 시 현재 추적 아이템을 기준으로 방향·거리 추가 힌트를 제공합니다.
- 추적하지 않은 아이템의 위치를 우연히 정확히 조사해도 발견으로 인정합니다.
- 탐험 스탯 `50 이하`는 `120초`, `50~500`은 `120~240초` 선형 증가, `500 이상`은 `240초`를 사용합니다. 시간 계산에는 활성 펫의 탐험 보정을 포함하되 저체력 유효 스탯 감소로 시간을 다시 줄이지 않습니다.
- 모든 목표를 찾으면 `MISSION_COMPLETE`, 시간이 끝날 때 하나라도 남아 있으면 `TIMEOUT`입니다.
- `TIMEOUT`이면 그 판에서 발견한 목표 아이템도 실제 획득으로 남기지 않아 다음 도전에서 다시 찾아야 합니다. 대신 한 개 이상 발견했다면 발견 비율에 따라 성공 성장량보다 작은 탐험 성장 일부를 제공합니다.
- `MISSION_COMPLETE`여도 숨은 목표 아이템 자체를 가방 영구 수집품으로 저장하지 않습니다. 필요하면 성공한 발견을 기존 플레이 기록 카운터에만 반영합니다.
- 날짜를 되돌리는 모험 `중단` 버튼은 사용하지 않습니다. 비정상 종료는 `INTERRUPTED`이며 목표 아이템·부분 성장 없이 다음 일정으로 복구합니다.

모험 UI·배치·조사·결과의 상세 계약은 [공통 엔진 프레임·마이룸·모험 흐름](10_COMMON_ENGINE_FRAME.md)을 따릅니다.

## 3. 체력 운영

체력은 행동을 제한하기 위한 처벌 수치가 아니라 **일정 관리에 긴장감을 주는 자원**으로 사용합니다.

- 수업 1회는 체력 `10`, 모험 1회는 체력 `15`를 소비합니다. 기숙사 `요정의 거래`는 일정 슬롯을 사용하지만 체력은 소비하지 않습니다.
- 체력 `10~30`은 저체력 구간입니다. 체력을 제외한 보이는 성장 스탯의 유효값은 `-30%`, 새로 얻는 성장량은 `-50%`가 됩니다.
- 저체력은 저장 성장 스탯 자체를 깎지 않으며 체력 수치 자체에도 별도 능력치 디버프를 적용하지 않습니다.
- 하루가 시작될 때 체력이 `0~9`이면 그날부터 **평일 3일을 강제 휴식**하고, 3일 종료 후 체력을 `100`으로 회복합니다. 토·일은 3일에 포함하지 않습니다.
- 수업·모험을 시작하면서 체력이 `0~9`로 내려간 경우에는 이미 시작된 당일 활동을 끝낸 뒤 **다음 행동 가능한 평일**부터 강제휴식을 시작합니다.
- 강제휴식 3일에 이미 등록된 수업·모험·일반 휴식 일정이 있으면 모두 잠긴 `강제휴식` 일정으로 교체하고 플레이어가 수정할 수 없게 합니다.
- 예를 들어 목요일이 첫 강제휴식일이면 `목요일 / 금요일 / 다음 주 월요일`이 강제휴식입니다. 강제휴식이 다음 주로 넘어가면 다음 주 일정 화면에서 해당 날짜를 먼저 잠긴 상태로 표시하고 나머지 평일만 등록합니다.
- 달력에서는 일반 휴식과 구별되는 `강제휴식` 표시를 사용합니다.
- 토·일에는 자동 체력 회복이 없습니다.

강제 휴식은 단순 제재 화면보다 캐릭터나 학원 인물이 주인공의 상태를 걱정하는 짧은 장면과 연결할 수 있습니다.

## 4. 52주 구조

- 한 회차는 총 **52주**입니다.
- 직접 선택하는 일정은 기본적으로 `52주 × 평일 5회 = 최대 260회`입니다.
- 메인·NPC·지역 이벤트는 평일 일정 슬롯을 소비하지 않습니다. 이벤트가 발생한 주에도 월~금의 일반 일정 5회는 유지합니다. 서브스토리는 본편 범위에서 제외합니다.
- 일정과 충돌하지 않는 이벤트는 토·일을 우선적인 발생 구간으로 활용합니다. 다만 스토리에서 날짜가 고정된 이벤트는 임의로 주말로 이동하지 않으며 평일에 발생하더라도 예정 활동을 대체하지 않습니다.
- 메인 이벤트의 발생 날짜는 `1/1, 3/5, 6/4, 9/3, 12/3, 12/24`로 사용하며 일정 소모 여부는 위 공통 규칙을 따릅니다.
- `12/3 MS05`는 별빛 축제의 위기와 시계탑 수호 룬 문제를 같은 장면 안에서 최종 해결합니다. `12/24 MS06`에는 위기를 재발시키지 않고, 앞선 사건이 행복한 학교 일상으로 남았음을 보여 주는 겨울 놀이회·후일담을 진행한 뒤 마지막 자유 플레이 주간으로 연결합니다.

### 주말 처리와 다음 주 전환

금요일 활동이 끝나면 별도의 주말 일정 선택 없이 토·일을 자동으로 처리합니다. 주말에는 체력 자동 회복이 없으며, 조건을 만족한 이벤트가 있다면 우선적인 이벤트 표시 구간으로 사용할 수 있습니다.

주말 처리와 해당 주 이벤트 결과가 끝나면 주간 결과를 확정하고 자동 저장한 뒤 다음 월요일로 이동합니다. 월요일 아침에는 새 일정을 등록하기 전에 **지난주 주간 요약**을 한 번 보여 줍니다.

주간 요약의 기본 항목은 다음과 같습니다.

- 지난주 보이는 스탯의 시작값 대비 최종 변화량
- 수업 총 진행 횟수와 필요 시 수업별·계열별 진행 횟수
- 체력 총 소비량과 총 회복량
- 주간 시작 체력과 주간 종료 체력
- 강제휴식이 있었다면 강제휴식 일수

주간 요약은 이미 확정된 기록을 읽기 쉽게 보여 주는 화면이며 스탯·체력·보상을 다시 적용하지 않습니다. 요약을 닫으면 해당 월요일의 일정 등록으로 이어집니다. 52주차가 끝난 뒤에는 12월 31일에 마지막 주간 요약을 보여 준 뒤 고정 문구 **`무엇을 지켰니?`** 로 엔딩에 진입하고, 직업 엔딩과 개인화 편지를 노출합니다. 12월 31일에는 새 주간 일정을 만들지 않습니다.

## 5. 달력과 계절 표현

대규모 계절별 배경 제작은 현재 범위에 포함하지 않습니다.

대신 달력 UI에서 봄·여름·가을·겨울을 작은 아이콘이나 색상 구분 등 **가벼운 시각 정보**로 표현하는 방향을 사용합니다. 향후 특정 이벤트의 발생 조건에 계절 또는 시기를 사용할 수 있지만, 계절별 전체 배경 교체를 전제로 하지 않습니다.

## 6. 반복 플레이를 위한 원칙

52주를 여러 캐릭터로 다시 플레이하는 게임이므로 매 회차가 완전히 같은 순서가 되지 않도록 다음 요소를 조합합니다.

- 주간 일정 선택
- NPC 가중 랜덤 조우
- 공간 이벤트
- 수집·해금 상태
- 캐릭터별 대사·반응
- 플레이어의 대화 선택
- 보이는 스탯과 보이지 않는 스탯
- 이전 회차에서 계승된 보상
