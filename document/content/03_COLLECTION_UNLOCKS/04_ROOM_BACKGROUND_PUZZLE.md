# 마이룸 배경 퍼즐 시스템

## 1. 기본 구조

- 기본 마이룸 배경은 **기본 기숙사방 1종**이며 처음부터 사용할 수 있습니다.
- 추가 마이룸 배경은 같은 기숙사방의 다른 디자인인 `기숙사방 1`, `기숙사방 2`, `기숙사방 3`으로 구성합니다.
- 추가 배경 1종은 **12개의 고유 퍼즐 조각**으로 구성합니다.
- 추가 배경 3종의 전체 퍼즐 조각은 `3 × 12 = 총 36개`입니다.
- 퍼즐 조각은 중복으로 획득하지 않습니다.
- 특정 배경 하나를 먼저 선택해 진행하지 않습니다. 잠긴 모든 배경의 미획득 퍼즐 조각을 하나의 공통 풀로 관리합니다.

## 2. 퍼즐 조각 지급

퍼즐 보상 조건 하나를 최초로 달성할 때마다 다음 순서로 처리합니다.

`조건 달성 → 전체 미획득 퍼즐 조각 조회 → 무작위 1개 선택 → 퍼즐 조각 획득 → 해당 배경 12/12 여부 확인 → 완성 시 배경 영구 해금`

- 확률 가중치, 특정 배경 우선 지급, 천장 시스템은 사용하지 않습니다.
- 이미 획득한 퍼즐 조각은 랜덤 후보에서 제외합니다.
- 따라서 여러 배경이 동시에 `10/12`, `11/12`처럼 비슷하게 진행될 수 있습니다.
- 한 배경의 12개 조각을 모두 획득하면 해당 기숙사방 배경을 즉시 해금합니다.
- 해금한 배경은 마이룸의 가방 → `마이룸` 탭에서 자유롭게 선택할 수 있으며 회차를 넘어 영구 계승합니다.
- 마이룸에는 각 배경의 획득 조각과 진행률을 확인할 수 있는 **배경 퍼즐 현황 메뉴**를 둡니다.

### 배경 퍼즐 화면

배경별 `12개` 조각은 실제 완성 배경에서의 위치가 고정되어 있습니다.

- 획득한 조각 위치에는 실제 배경 이미지 조각을 표시합니다.
- 미획득 위치는 `? / 잠금 / 가림`으로 처리합니다.
- 조각을 드래그·회전해 맞추는 별도 퍼즐 미니게임으로 만들지 않고, **수집한 조각만큼 배경이 점진적으로 드러나는 진행도 화면**으로 사용합니다.
- 가방 마이룸 목록에서는 각 배경의 `N / 12`를 먼저 보여 주고 상세 화면에서 12조각 상태를 확인합니다.

### 완성 배경 적용

- `12 / 12`가 되면 해당 배경을 계정 전역으로 해금합니다.
- **완성만으로 현재 배경을 자동 변경하지 않습니다.**
- 사용자가 `이 배경 사용하기`를 선택했을 때만 계정 설정의 `activeRoomBackgroundId`를 변경합니다.
- 한 번 해금한 배경은 마이룸에서 가방을 열 수 있는 정상 상태라면 언제든 다른 해금 배경으로 다시 변경할 수 있습니다.
- 배경 선택은 세이브 슬롯별 설정이 아니라 계정 전체에서 공유합니다.
- 잠긴 배경에는 선택/사용 버튼을 제공하지 않습니다.

퍼즐 조각 획득 시 주간 활동 흐름을 강제로 중단해 퍼즐 화면으로 이동하지 않습니다. 일반 조각은 짧은 획득 알림과 가방의 새 항목 표시만 남깁니다. 한 배경이 `12 / 12`가 된 경우에도 자동으로 가방을 열지 않고 `새로운 마이룸 배경을 완성했어요! 가방 > 마이룸에서 확인해보세요.` 같은 안내만 보여 준 뒤 현재 진행을 계속합니다.

가방에서 해금 배경의 `이 배경 사용하기`를 누르면 `activeRoomBackgroundId` 저장을 먼저 완료하고, **가방의 마이룸 탭은 그대로 유지**하면서 선택 배경을 `사용 중`으로 표시합니다. 사용자가 가방을 닫아 마이룸으로 돌아갈 때 새 배경을 실제 화면에 반영합니다. 설정 저장에 실패하면 기존 배경을 유지하고 재시도를 제공합니다.

화면의 상세 진입·복귀 계약은 [기능 프레임](../11_FEATURE_FRAME.md)을 따릅니다.

## 4. 진행 속도 의도

- 첫 52주 플레이에서 배경 완성을 보장하지 않습니다.
- 퍼즐 조각 지급은 위 조건만 사용하며 별도의 확률 보정 로직을 추가하지 않습니다.
- 초기·중기 조건을 통해 첫 회차부터 많은 조각을 얻을 수 있지만, 실제 배경 완성 시점은 36개 조각의 무작위 분포에 따라 달라질 수 있습니다.
- 장기 조건인 `250회 / 250회 / 500회`는 여러 캐릭터를 반복 플레이하면서 마지막 조각까지 점진적으로 획득하게 하기 위한 기준입니다.
- 실제 내부 테스트에서 회차당 평균 `미니게임 횟수 / 모험 횟수 / NPC 조우 횟수`를 측정한 뒤 장기 조건 수치만 조정할 수 있습니다. 퍼즐 지급 구조 자체는 유지합니다.

## 5. 필요한 저장 데이터

구현 시 최소한 다음 값을 저장합니다.

- 전체 미니게임 플레이 누적 횟수
- 서로 다른 미니게임 최초 클리어 목록
- 전체 모험 누적 횟수
- 전체 NPC 조우 누적 횟수
- 계열별 수업 수행 누적 횟수
- 달성한 퍼즐 보상 조건 ID 목록
- 획득한 퍼즐 조각 ID 목록
- 배경별 퍼즐 진행도
- 해금된 마이룸 배경 목록
