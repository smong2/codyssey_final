# 수집·해금·보상 시스템

## 1. 수집 시스템 목표

수집 배지는 총 **200개**로 확정합니다.

구조는 **5개 대분류 × 대분류당 5개 소분류 × 소분류당 8개 배지 = 총 200개**입니다.

소분류별 보상은 3단계로 구성하여 전체 보상 지점은 `25 × 3 = 75개`를 기준으로 합니다. 배지 디자인은 200개를 모두 별도로 제작하지 않고 대분류 프레임 5종, 소분류 심볼 25종, 공용 장식 8종, 상태 표현 3종을 조합하는 방식을 사용합니다.

세부 디자인 기준은 [가방 수집 배지 분류·디자인 시스템](01_BADGE_COLLECTION_DESIGN.md)을 따릅니다.

## 2. 수집 조건

배지는 다음과 같은 플레이 기록으로 획득할 수 있습니다.

- 모험에서 특정 획득물 발견
- 특정 보이는 스탯 달성
- 특정 행동·선택 누적
- NPC 개별 스토리 완료
- 특정 공간·서브·메인 이벤트 완료
- 미니게임 기록 달성
- 캐릭터·펫·배경 해금
- 특정 엔딩 확인
- 서로 다른 엔딩 누적 확인

배지를 획득하면 화면 중앙에 **획득 이유 + 배지 이름**을 짧게 노출합니다.

가방 또는 컬렉션 화면에서는 배지를 카테고리별로 확인할 수 있습니다.

## 3. 최종 분류와 조건

최종 대분류는 `탐험과 발견 / 배움과 성장 / 활동과 성취 / 관계와 공감 / 각성과 선택` 5개입니다. 각 대분류에는 제작 완료된 심볼 기준으로 5개 소분류를 배치하며, 소분류별 8개 조건까지 [배지 분류·디자인 시스템](01_BADGE_COLLECTION_DESIGN.md)에 확정합니다.

보이지 않는 스탯의 실제 내부 수치는 공개하지 않습니다. 관련 배지는 특정 수치가 아니라 **태그가 붙은 실제 행동·선택의 계정 누적 횟수**로 지급합니다.

## 4. 단계 보상과 영구 보너스

모든 소분류는 `2/8, 5/8, 8/8`에서 해당 대분류의 성장 스탯을 영구 `+1`씩 지급합니다. 한 소분류 최대 `+3`, 한 대분류 최대 `+15`입니다.

- 탐험과 발견 → 탐험 최대 `+15`
- 배움과 성장 → 지식 최대 `+15`
- 활동과 성취 → 솜씨 최대 `+15`
- 관계와 공감 → 표현력 최대 `+15`
- 각성과 선택 → 마법 최대 `+15`

최대 체력 영구 보너스는 사용하지 않고 체력 상한 `100`을 유지합니다. 영구 성장 보너스는 현재 회차를 소급 수정하지 않고 **다음 회차 생성 시** 반영합니다.

소분류 8/8에는 골드 완성 표시를, 대분류 40/40에는 대분류 프레임의 골드 강조와 완료 알림을 제공합니다. 대분류 완성에 추가 수치 보너스는 없습니다.

## 5. 캐릭터 해금

- 최종적으로 남학생 16명, 여학생 16명, 총 **32명**을 플레이 가능하게 합니다.
- 최초에는 남학생 **3명**, 여학생 **3명**, 총 **6명**을 선택할 수 있게 합니다.
- 기본 오픈 캐릭터는 `카엘 / 로빈 / 니코 / 세라 / 아이리스 / 티아`이며, 이 6명은 캐릭터별 시작 스탯 보정을 적용하지 않습니다.
- 나머지 26명은 캐릭터 설정에 따라 성장 스탯 한 항목에 `+10`, 다른 한 항목에 `-10`을 적용합니다.
- 나머지 26명의 실제 해금 조건은 배지 진행 23명 + 회차/엔딩 진행 3명으로 확정합니다.
- 해금 조건은 52주 플레이 중 언제든 달성할 수 있지만, 실제 캐릭터 해금은 엔딩의 마지막 `타이틀로` 저장 성공으로 현재 회차 종료가 확정될 때 반영하며 **다음 회차부터 선택 가능**하게 합니다.
- 캐릭터 32명의 메인 시나리오를 완전히 별개로 제작하기보다 공통 사건에 캐릭터별 대사·반응·일부 전용 장면을 결합하는 구조를 우선 검토합니다.

캐릭터별 실제 해금 조건과 처리 시점은 [플레이 가능 캐릭터 해금 시점](02_CHARACTER_UNLOCK_TIMING.md)을 따릅니다.

## 6. 펫 해금

- 펫은 총 **10마리**이며 처음에는 기본 펫 **1마리**를 사용할 수 있습니다.
- 나머지 **9마리**는 특정 조건을 달성하면 순차적으로 해금합니다.
- 본편에는 데모의 단일 펫 캐릭터 **베른이 등장하지 않으며**, `asset/bern/`의 동물 이미지 10종을 각각 독립된 `PET01~PET10` 펫 자원으로 사용합니다.
- 해금된 펫은 마이룸의 가방 → 펫 탭에서 언제든 1마리를 선택할 수 있고, 잠긴 펫은 선택할 수 없습니다. 별도의 환경설정 펫 화면은 두지 않습니다.
- 활성 펫은 성장 스탯에 작은 임시 보정 효과를 제공합니다. 보정은 저장 스탯을 영구 변경하지 않고 현재 활성 펫 기준으로 계산합니다.
- 해금 속도는 추가 캐릭터 약 2명 해금당 펫 1마리 수준을 기준으로 하며, 플레이 가능 캐릭터가 약 **25 / 32명** 해금된 시점에 펫 10마리가 모두 열리는 것을 목표로 합니다.
- 펫 2~10은 `첫 엔딩 / 캐릭터 해금 수 / 모험 누적 / NPC 스토리 / 서로 다른 엔딩 / 배지 소분류 완성 / 복합 누적 기록`을 분산해 사용하며 세부 조건은 [펫 해금 시점](03_PET_UNLOCK_TIMING.md)에 확정되어 있습니다.
- `PET01~PET07`은 `+5/+3`, 후반 수집 보상인 `PET08~PET10`은 `+5/+5`의 성장 스탯 보정을 제공합니다.
- 10마리의 이름·외형 자원·게임 화면 설명은 [펫 시스템](05_PET_SYSTEM.md)에 확정되어 있습니다.

펫별 해금 시점과 속도 기준은 [펫 해금 시점](03_PET_UNLOCK_TIMING.md)을 따릅니다.
펫 선택·스탯 보정·저장·이름/설명 마스터는 [펫 시스템](05_PET_SYSTEM.md)을 따릅니다.

## 7. 마이룸 배경 퍼즐

기본 기숙사방 외에 추가 마이룸 배경 `기숙사방 1~3`을 퍼즐 수집으로 해금합니다.

- 배경 1종당 12조각, 총 36개의 고유 퍼즐 조각을 사용합니다.
- 조건 달성 시 아직 획득하지 않은 36개 조각 중 무작위 1개를 지급하며 중복은 없습니다.
- 특정 배경 하나를 먼저 진행하지 않고 세 배경의 조각을 동시에 수집합니다.
- 한 배경의 12개 조각을 모두 모으면 해당 배경을 영구 해금하고 마이룸에서 선택할 수 있습니다.
- 미니게임·모험·NPC 만남·계열별 수업의 최초/누적 기록을 퍼즐 지급 조건으로 사용합니다.
- 가방의 마이룸 탭에서 획득한 조각 위치만 실제 배경 조각으로 보여 주고 미획득 위치는 가립니다.
- 배경을 완성해도 자동 적용하지 않으며, 플레이어가 직접 선택한 해금 배경만 `activeRoomBackgroundId`로 적용합니다.
- 해금된 배경은 회차·슬롯과 무관하게 마이룸에서 언제든 다시 선택할 수 있습니다.

배경 해금 상태는 회차를 넘어 계승합니다.

36개 지급 조건과 저장 데이터의 상세 기준은 [마이룸 배경 퍼즐 시스템](04_ROOM_BACKGROUND_PUZZLE.md)을 따릅니다.

가방·배지·마이룸 퍼즐의 화면 상태와 진입/복귀 기준은 [기능 프레임](../11_FEATURE_FRAME.md)을 따릅니다.
