# 수집·해금·보상 시스템

## 1. 수집 시스템 목표

수집 배지는 총 **약 200개**를 목표로 합니다.

현재 기본안은 **5개 대분류 × 대분류당 5개 소분류 × 소분류당 8개 배지 = 총 200개** 구조입니다.

소분류별 보상은 3단계로 구성하여 전체 보상 지점은 `25 × 3 = 75개`를 기준으로 합니다. 배지 디자인은 200개를 모두 별도로 제작하지 않고 대분류 프레임 5종, 소분류 심볼 25종, 공용 장식 8종, 상태 표현 3종을 조합하는 방식을 사용합니다.

세부 디자인 기준은 [가방 수집 배지 분류·디자인 시스템](01_BADGE_COLLECTION_DESIGN.md)을 따릅니다.

## 2. 수집 조건

배지는 다음과 같은 플레이 기록으로 획득할 수 있습니다.

- 모험에서 특정 획득물 발견
- 특정 보이는 스탯 달성
- 특정 행동·선택 누적
- NPC 개별 스토리 완료
- 특정 공간·서브·메인 이벤트 완료
- 미니게임 기록 달성
- 캐릭터·펫·배경 해금
- 특정 엔딩 확인
- 서로 다른 엔딩 누적 확인

배지를 획득하면 화면 중앙에 **획득 이유 + 배지 이름**을 짧게 노출합니다.

가방 또는 컬렉션 화면에서는 배지를 카테고리별로 확인할 수 있습니다.

## 3. 카테고리명 초안

카테고리 이름은 시스템 용어보다 플레이어가 바로 이해하고 재미를 느낄 수 있는 표현을 우선합니다. 아래 목록은 기존에 정리한 **24개 소분류 이름 초안**이며, 현재 확정한 총 25개 소분류 구조에 맞춰 1개를 추가하고 대분류별 5개씩 재배치해야 합니다.

| 카테고리명 | 주요 내용 예시 |
|---|---|
| 과학은 재미있어! | 지식·수업·학술 활동 |
| 룬이 반짝! | 마법·룬 퍼즐·마법 발견 |
| 말이 술술 | 표현력·대화·발표 관련 기록 |
| 몸이 먼저! | 솜씨·신체 활동·훈련 기록 |
| 오늘도 탐험! | 모험 참여와 탐험 횟수 |
| 보물 찾았다! | 숨겨진 아이템·획득물 발견 |
| 여기 뭐가 있지? | 숨겨진 장소·조사 포인트 발견 |
| 친구가 생겼어 | NPC 첫 만남·관계 이벤트 |
| 끝까지 들어볼게 | NPC 개별 스토리 완료 |
| 선택의 순간 | 중요한 대화 선택·분기 경험 |
| 용기 한 스푼 | 용기가 필요한 행동·이벤트 |
| 마음을 알아줘 | 공감과 관련된 행동·이벤트 |
| 같이 하면 쉬워 | 협력 행동·공동 해결 |
| 약속은 지켜야지 | 책임 있는 행동·완료 기록 |
| 궁금한 건 못 참아 | 호기심·조사·새 정보 발견 |
| 차근차근 생각해 | 신중한 관찰·판단 행동 |
| 혼자서도 척척 | 독립적으로 해결한 기록 |
| 솔직하게 말해봐 | 솔직한 표현·대화 선택 |

보이지 않는 스탯의 실제 내부 수치는 공개하지 않습니다. 관련 배지는 특정 수치 자체보다 **플레이어가 실제로 수행한 사건·행동**을 기준으로 지급하는 것을 우선합니다.

## 4. 카테고리 완성 보상

한 카테고리의 배지를 모두 모으면 다음 중 하나 이상의 보상을 줄 수 있습니다.

- 최대 체력 또는 특정 스탯의 작은 영구 보너스
- 새로운 플레이 가능 캐릭터
- 새로운 펫
- 기타 꾸미기·특수 해금 요소

영구 체력·스탯 보너스는 다음 회차에도 계승합니다. 반복 플레이 밸런스가 무너지지 않도록 보너스 수치와 누적 상한은 별도 밸런싱이 필요합니다.

## 5. 캐릭터 해금

- 최종적으로 남학생 16명, 여학생 16명, 총 **32명**을 플레이 가능하게 합니다.
- 최초에는 남학생 **3명**, 여학생 **3명**, 총 **6명**을 선택할 수 있게 합니다.
- 기본 오픈 캐릭터는 `카엘 / 로빈 / 니코 / 세라 / 아이리스 / 티아`이며, 이 6명은 캐릭터별 시작 스탯 보정을 적용하지 않습니다.
- 나머지 26명은 캐릭터 설정에 따라 성장 스탯 한 항목에 `+10`, 다른 한 항목에 `-10`을 적용합니다.
- 나머지 캐릭터는 특정 플레이·수집·엔딩 등 조건을 충족하면 해금합니다.
- 해금 조건은 52주 플레이 중 언제든 달성할 수 있지만, 실제 캐릭터 해금은 현재 회차 종료 시 확정하며 **다음 회차부터 선택 가능**하게 합니다.
- 캐릭터 32명의 메인 시나리오를 완전히 별개로 제작하기보다 공통 사건에 캐릭터별 대사·반응·일부 전용 장면을 결합하는 구조를 우선 검토합니다.

캐릭터 해금 시점과 조건 유형별 처리 기준은 [플레이 가능 캐릭터 해금 시점](02_CHARACTER_UNLOCK_TIMING.md)을 따릅니다.

## 6. 펫 해금

- 펫은 총 **10마리**이며 처음에는 기본 펫 **1마리**를 사용할 수 있습니다.
- 나머지 **9마리**는 특정 조건을 달성하면 순차적으로 해금합니다.
- 해금 속도는 추가 캐릭터 약 2명 해금당 펫 1마리 수준을 기준으로 하며, 플레이 가능 캐릭터가 약 **25 / 32명** 해금된 시점에 펫 10마리가 모두 열리는 것을 목표로 합니다.
- 펫 2~10의 현재 획득 조건 초안은 `첫 엔딩 / 캐릭터 해금 수 / 모험 누적 / NPC 스토리 / 서로 다른 엔딩 / 배지 완성 / 복합 누적 기록`을 분산해 사용하는 구조입니다.
- 펫의 세부 능력 효과는 **미정**입니다. 능력을 제공할 경우 특정 펫만 정답이 되지 않도록 작은 차이를 주는 방향을 권장합니다.

펫별 해금 시점과 속도 기준은 [펫 해금 시점](03_PET_UNLOCK_TIMING.md)을 따릅니다.

## 7. 마이룸 배경 퍼즐

기본 기숙사방 외에 추가 마이룸 배경 `기숙사방 1~3`을 퍼즐 수집으로 해금합니다.

- 배경 1종당 12조각, 총 36개의 고유 퍼즐 조각을 사용합니다.
- 조건 달성 시 아직 획득하지 않은 36개 조각 중 무작위 1개를 지급하며 중복은 없습니다.
- 특정 배경 하나를 먼저 진행하지 않고 세 배경의 조각을 동시에 수집합니다.
- 한 배경의 12개 조각을 모두 모으면 해당 배경을 영구 해금하고 마이룸에서 선택할 수 있습니다.
- 미니게임·모험·NPC 만남·계열별 수업의 최초/누적 기록을 퍼즐 지급 조건으로 사용합니다.

배경 해금 상태는 회차를 넘어 계승합니다.

36개 지급 조건과 저장 데이터의 상세 기준은 [마이룸 배경 퍼즐 시스템](04_ROOM_BACKGROUND_PUZZLE.md)을 따릅니다.
