# 펫 해금 시점

## 1. 기본 원칙

- 펫은 총 **10마리**로 구성합니다.
- 게임 시작 시 **기본 펫 1마리**를 제공합니다.
- 나머지 **9마리**는 플레이 진행에 따라 순차적으로 해금합니다.
- 펫 해금 속도는 단순 회차 수보다 **추가로 해금한 플레이 가능 캐릭터 수**를 기준으로 맞춥니다.
- 전체 펫 10마리는 플레이 가능 캐릭터가 약 **25 / 32명** 정도 해금된 시점에 모두 사용할 수 있게 하는 것을 목표로 합니다.

기본 해금 속도는 다음과 같습니다.

`기본 펫 1마리 제공 → 추가 캐릭터 약 2명 해금할 때마다 펫 1마리씩 추가 → 캐릭터 약 25명 보유 시 펫 10마리 전체 해금`

## 2. 펫별 해금 시점

| 펫 | 해금 기준 | 예상 사용 가능 캐릭터 수 |
|---|---|---:|
| 펫 1 | 게임 시작 시 기본 제공 | 6명 |
| 펫 2 | 추가 캐릭터 2명 해금 | 8명 |
| 펫 3 | 추가 캐릭터 4명 해금 | 10명 |
| 펫 4 | 추가 캐릭터 6명 해금 | 12명 |
| 펫 5 | 추가 캐릭터 8명 해금 | 14명 |
| 펫 6 | 추가 캐릭터 10명 해금 | 16명 |
| 펫 7 | 추가 캐릭터 12명 해금 | 18명 |
| 펫 8 | 추가 캐릭터 14명 해금 | 20명 |
| 펫 9 | 추가 캐릭터 16명 해금 | 22명 |
| 펫 10 | 추가 캐릭터 19명 해금 | 25명 |

최초 기본 캐릭터 수는 **6명**으로 확정되었습니다. 해금 흐름은 다음과 같습니다.

`6명 → 펫 1 / 8명 → 펫 2 / 10명 → 펫 3 / 12명 → 펫 4 / 14명 → 펫 5 / 16명 → 펫 6 / 18명 → 펫 7 / 20명 → 펫 8 / 22명 → 펫 9 / 25명 → 펫 10`

## 3. 해금 조건 설계 기준

위 표는 **펫의 실제 조건 종류를 고정하는 규칙이 아니라 해금 속도를 맞추기 위한 기준**입니다.

실제 펫의 해금 조건은 다음과 같이 다양하게 설계할 수 있습니다.

- 특정 수집 카테고리 또는 단계 보상 달성
- 특정 엔딩 확인
- 특정 NPC 스토리 완료
- 특정 이벤트 완료
- 누적 모험·수업·미니게임 기록 달성
- 플레이 가능 캐릭터 해금 수 달성

각 펫의 실제 조건을 결정할 때는 위 해금 속도표와 비교하여 너무 빠르거나 늦게 몰리지 않도록 배치합니다.

## 4. 전체 해금 목표

- 최종 캐릭터 목표: **32명**
- 전체 펫 해금 목표 시점: 캐릭터 약 **25명 해금 시점**
- 따라서 마지막 7명 정도의 캐릭터를 해금하는 장기 구간에서는 펫 수집이 이미 끝나고, 캐릭터·엔딩·배지 등 다른 메타 목표에 집중할 수 있습니다.

기본 캐릭터가 6명으로 확정되었으므로 마지막 펫만 `추가 캐릭터 19명`, 즉 **총 25명 시점**에 맞춥니다.

## 5. 추후 결정할 항목

- 펫 2~10의 실제 해금 조건
- 각 펫의 이름·외형·설정
- 각 펫의 고유 능력 효과
- 펫 능력의 수치와 밸런스
- 펫 해금 알림 및 마이룸 표시 방식
