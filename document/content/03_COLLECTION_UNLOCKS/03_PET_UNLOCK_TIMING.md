# 펫 해금 시점

이 문서는 펫의 **해금 조건과 속도**를 관리합니다. 펫 선택, 스탯 보정, 이름·설명 마스터는 [펫 시스템](05_PET_SYSTEM.md)을 따릅니다.

## 1. 기본 원칙

- 펫은 총 **10마리**로 구성합니다.
- 게임 시작 시 **기본 펫 1마리**를 제공합니다.
- 나머지 **9마리**는 플레이 진행에 따라 순차적으로 해금합니다.
- 본편에서는 베른을 사용하지 않고 `PET01~PET10`의 독립된 펫 10마리를 사용합니다.
- 해금된 펫은 즉시 마이룸의 가방 → 펫 탭에서 선택할 수 있으며, 펫 해금을 회차 종료까지 지연하지 않습니다.
- 펫 해금 속도는 단순 회차 수보다 **추가로 해금한 플레이 가능 캐릭터 수**를 기준으로 맞춥니다.
- 전체 펫 10마리는 플레이 가능 캐릭터가 약 **25 / 32명** 정도 해금된 시점에 모두 사용할 수 있게 하는 것을 목표로 합니다.

기본 해금 속도는 다음과 같습니다.

`기본 펫 1마리 제공 → 추가 캐릭터 약 2명 해금할 때마다 펫 1마리씩 추가 → 캐릭터 약 25명 보유 시 펫 10마리 전체 해금`

## 2. 펫별 해금 시점

| 펫 | 해금 기준 | 예상 사용 가능 캐릭터 수 |
|---|---|---:|
| 펫 1 | 게임 시작 시 기본 제공 | 6명 |
| 펫 2 | 추가 캐릭터 2명 해금 | 8명 |
| 펫 3 | 추가 캐릭터 4명 해금 | 10명 |
| 펫 4 | 추가 캐릭터 6명 해금 | 12명 |
| 펫 5 | 추가 캐릭터 8명 해금 | 14명 |
| 펫 6 | 추가 캐릭터 10명 해금 | 16명 |
| 펫 7 | 추가 캐릭터 12명 해금 | 18명 |
| 펫 8 | 추가 캐릭터 14명 해금 | 20명 |
| 펫 9 | 추가 캐릭터 16명 해금 | 22명 |
| 펫 10 | 추가 캐릭터 19명 해금 | 25명 |

최초 기본 캐릭터 수는 **6명**으로 확정되었습니다. 해금 흐름은 다음과 같습니다.

`6명 → 펫 1 / 8명 → 펫 2 / 10명 → 펫 3 / 12명 → 펫 4 / 14명 → 펫 5 / 16명 → 펫 6 / 18명 → 펫 7 / 20명 → 펫 8 / 22명 → 펫 9 / 25명 → 펫 10`

## 3. 해금 조건 설계 기준

위 표는 **펫의 실제 조건 종류를 고정하는 규칙이 아니라 해금 속도를 맞추기 위한 기준**입니다.

실제 펫의 해금 조건은 다음과 같이 다양하게 설계할 수 있습니다.

- 특정 수집 카테고리 또는 단계 보상 달성
- 특정 엔딩 확인
- 특정 NPC 스토리 완료
- 특정 이벤트 완료
- 누적 모험·수업·미니게임 기록 달성
- 플레이 가능 캐릭터 해금 수 달성

각 펫의 실제 조건을 결정할 때는 위 해금 속도표와 비교하여 너무 빠르거나 늦게 몰리지 않도록 배치합니다.

### 펫 2~10 획득 조건 최종안

아래 조건을 본편의 기본 해금 조건으로 확정합니다. 모두 계정 전역 누적 기록을 기준으로 판단합니다.

| 펫 | 이름 | 획득 조건 | 조건 성격 |
|---|---|---|---|
| `PET01` | 에든 | 게임 시작 시 기본 제공 | 기본 |
| `PET02` | 루엔 | 첫 직업 엔딩 확인 | 엔딩 |
| `PET03` | 포포 | 플레이 가능 캐릭터 총 10명 해금 | 캐릭터 수집 |
| `PET04` | 마린 | 모험 누적 100회 | 누적 플레이 |
| `PET05` | 토비 | NPC 개별 스토리 5개 완료 | NPC 스토리 진행 |
| `PET06` | 니브 | 서로 다른 직업 엔딩 3개 확인 | 엔딩 수집 |
| `PET07` | 로코 | 플레이 가능 캐릭터 총 18명 해금 | 캐릭터 수집 |
| `PET08` | 피핀 | 배지 소분류 1개를 `8 / 8`로 완성 | 수집 완성 |
| `PET09` | 브램 | **수업 누적 150회 + 모험 누적 150회 + NPC 누적 만남 30회**를 모두 달성 | 복합 장기 플레이 |
| `PET10` | 세렌 | 플레이 가능 캐릭터 총 25명 해금 | 장기 수집 |

`PET08~PET10`은 후반 수집 보상으로 일반 펫보다 조금 높은 `+5/+5` 보정을 제공합니다. `PET09`는 하나의 행동만 반복해서 얻는 보상이 되지 않도록 수업·모험·NPC 경험을 모두 요구합니다.

이 초안은 펫을 캐릭터 수만으로 일렬 해금하기보다 **엔딩 / 모험 / NPC 스토리 / 배지 / 캐릭터 수집** 등 이미 기록하는 플레이 데이터를 골고루 사용하기 위한 방향입니다.

## 4. 전체 해금 목표

- 최종 캐릭터 목표: **32명**
- 전체 펫 해금 목표 시점: 캐릭터 약 **25명 해금 시점**
- 따라서 마지막 7명 정도의 캐릭터를 해금하는 장기 구간에서는 펫 수집이 이미 끝나고, 캐릭터·엔딩·배지 등 다른 메타 목표에 집중할 수 있습니다.

기본 캐릭터가 6명으로 확정되었으므로 마지막 펫만 `추가 캐릭터 19명`, 즉 **총 25명 시점**에 맞춥니다.

## 5. 구현·테스트 단계 확인 항목

- 실제 플레이 속도에서 `PET04`의 모험 100회와 `PET09`의 복합 누적 조건이 지나치게 빠르거나 늦지 않은지 확인
- `PET08~PET10`의 `+5/+5` 보정이 일반 펫을 완전히 대체하지 않고 플레이 스타일 선택으로 남는지 확인
- 펫 해금 알림 및 가방 → 펫 탭 표시 방식의 최종 화면 디자인
