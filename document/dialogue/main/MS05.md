# MS05 · 별빛 축제의 마지막 소원

> 상태: **검수용 대화 마스터**  
> 날짜: 12월 3일 · 49주차  
> 선택 화면: 5회  
> 신규 이미지: 0장 · 기존 축제 광장 밝음/꺼짐 배경 재사용

## 장면 목적

- 한 해 동안 간헐적으로 흐려졌던 수호 룬 문제를 **이 장면에서 완전히 해결**한다.
- 해결의 핵심은 한꺼번에 힘을 밀어 넣는 것이 아니라 사람들의 서로 다른 소원을 하나씩 듣고 연결하는 과정이다.
- 플레이어 혼자 학교를 구한 이야기로 만들지 않고, 앞선 사건에서 만난 친구들과 함께 해결한다.
- 5개 선택 모두 정답/오답이 아니라 `듣는 순서 / 알리는 방식 / 장치를 멈추는 접근 / 역할을 나누는 방식 / 개인 표식`의 차이로 만든다.
