# MS06 · 우리가 지켜낸 것

> 상태: **검수용 대화 마스터**

> 선택 화면: 2회  
> 신규 이미지: `ART-M06`

## 장면 목적

- 새로운 위기 없이 앞선 사건들이 평범하고 즐거운 일상으로 남았음을 보여 준다.
- 선택하지 않은 놀이도 다른 친구가 즐기고 있어 `모두 해야 한다`는 압박을 만들지 않는다.
- 한 해를 교훈 문장으로 정리하지 않고 친구들의 말과 작은 놀이로 회상한다.
- 종료 후 12월 24~30일 마지막 자유 플레이 주간으로 자연스럽게 넘긴다.

## 검수 메모

- 새로운 위기, 수호 룬 재발, 숨은 적 복선을 넣지 않는다.
- S3의 세 놀이와 S4의 세 친구 선택은 어떤 항목을 골라도 동일한 가치로 취급한다.
- `마지막 한 주에 무엇을 해야 한다`는 결론을 NPC가 대신 내려 주지 않는다.
- 직업 엔딩이나 12월 31일의 `무엇을 지켰니?` 질문을 미리 설명하지 않는다.
