# 게임 콘텐츠 요소

이 문서는 플레이어가 경험할 콘텐츠의 **유형과 연결 관계**를 설명합니다. 모든 유형이 이미 제작·출시되었다는 목록이 아닙니다. 52주 육성 루프와 스탯·이벤트·수집·저장·회차 계승의 최신 상세 기획은 [콘텐츠 상세 기획](content/README.md)을 기준으로 합니다.

## 기본 플레이 흐름

`주인공 선택 → MS01 입학·온보딩 → 52주 동안 평일 5회 주간 일정(수업·모험·휴식·특수 활동)과 메인 이벤트 진행 → 12월 24일 최종 위기 해결 → 마지막 자유 플레이 주간 → 12월 31일 마지막 주간 요약 → 무엇을 지켰니? → 미래 직업 엔딩·개인화 편지 → 다음 회차`

생활 화면은 장소의 큰 배경과 인물, 대화·선택·사건에 초점을 둡니다. 직접 탐험은 같은 세계의 장소를 조작 가능한 시점으로 보여줍니다. 한 에피소드에 직접 탐험이 반드시 들어가야 하는 것은 아닙니다.

## 콘텐츠 유형

| 유형 | 플레이어가 하는 일 | 설계 원칙 |
|---|---|---|
| 캐릭터 선택·입학 | 학생의 배경·성향을 살피고 이야기의 주인공을 정함 | 32명의 고유 설정을 보존하고 인물의 장단점을 점수로 평가하지 않음 |
| 장소 생활 | 광장·기숙사·서고·온실 등을 방문하고 인물과 교류 | 기존 아르카디아 장소가 이야기와 활동의 기반 |
| 에피소드 | 하나의 갈등을 발견하고 선택·변화·돌아보기를 경험 | 완결된 이야기 단위이며 탐험과 1:1 관계 아님 |
| 이벤트·사이드 이벤트 | 조건에 따라 짧은 장면과 반응을 만남 | 메인·서브·NPC·지역 이벤트는 평일 일정 슬롯을 소비하지 않으며 자유로운 이벤트는 주말을 우선 활용 가능 |
| 목표 | 현재 할 일을 한 문장으로 이해 | 단순 체크리스트·점수표 중심으로 만들지 않음 |
| 대화·선택 | 사람의 사연을 듣고 현실적인 접근 중 선택 | 모든 대화에 선택지가 필요한 것은 아님; 정답/오답 구도 피함 |
| 탐험·상호작용 | 이동, 관찰, 조사, 채집, 물건·장소 이용 | 플레이어가 직접 발견해야 할 답을 먼저 알려주지 않음 |
| 지식·단서 | 관찰과 대화에서 사실을 알아냄 | `아이템=가진 것`, `지식=알게 된 것`; 새 대화·행동에 영향 |
| 아이템·소지품 | 재료, 도구, 이야기 물건, 수집품을 모음 | 이야기 물건을 임의 판매·소모하는 자원처럼 다루지 않음 |
| 조우·퍼즐 | 인물·환경·룬 이상 현상을 해결 | 전투·체력 소모가 기본 해법이 아님; 실패는 새 정보를 줌 |
| 세계 변화 | 룬, 식물, 장소, NPC 반응의 차이를 확인 | 별도 점수보다 눈에 보이는 반응으로 성취 전달 |
| 마이룸·기록 | 오늘의 장면·선택을 돌아보고 수집·기록을 확인 | 개인적이고 안전한 공간; 도덕적 채점 금지 |
| 주간 일정 | 월~금 5회의 수업·모험·휴식·특수 활동을 계획하고 수행 | 5칸을 모두 채운 뒤 시작; 시작 전 수정 가능·시작 후 수정 불가; 수업은 체력 10, 모험은 15를 활동 시작 시 소비; 기숙사 `요정의 거래`는 주 1회·체력 0; 토·일은 별도 일정·자동 체력 회복 없이 경과 |

주간 일정 화면에서는 활동을 가장 이른 빈 평일에 순차 배치하거나 달력에서 특정 날짜를 먼저 선택해 배치할 수 있습니다. 등록된 날짜를 누르면 활동명 확인과 일정 삭제가 가능하며, 5칸을 모두 채워야 시작할 수 있습니다. 일정 시작 후 월요일부터 금요일까지 순차적으로 다음 활동 화면을 자동 노출합니다. 강제휴식은 평일 3일의 기존 일정을 잠긴 `강제휴식`으로 교체하며 주 경계를 넘을 수 있습니다. 새 회차 생성, 일정 확정, 각 활동 시작/완료, 주간 종료, 엔딩 확정을 안정 자동저장 경계로 사용합니다. 비정상 종료 시 시작 체크포인트의 활동은 `INTERRUPTED`로 소비하고 마이룸을 거쳐 다음 일정으로 자동 진행합니다.

본편 공간 콘텐츠는 `별빛 천문대-거울 마법 / 시계탑 광장-별빛 무대 / 유리 온실-정령 화분 정리 / 기숙사-요정의 거래 / 대서고-봉인 서가 / 마도 공방-룬 회로 / 수련장-룬 핀 훈련`으로 확정합니다. 6개 미니게임에는 즉시 재도전을 두지 않고 `포기하기=FAIL`로 처리합니다. 같은 게임을 2회 연속 실패하면 다음 플레이 난이도를 1단계, 4회 이상 연속 실패하면 최대 2단계 낮추되 성장 보상은 원래 `run.stats` 기준 난이도로 계산합니다.

메인 스토리는 `1/1 → 3/5 → 6/4 → 9/3 → 12/3 → 12/24`의 해당 주 일정 시작 전에 노출합니다. 원작 EP4는 12월 3일의 대응 방식·역할 결정과 12월 24일의 실제 공동 대응·수호 룬 안정으로 나눕니다. 12월 24~30일은 위기 해결 후 마지막 자유 플레이 주간입니다. 엔딩에서는 작가의 질문 `무엇을 지켰니?`를 고정 문구로 사용하되 AI가 답을 대신 판정하지 않습니다. 대표 사건 목록은 AI 입력에서 제외하고 실제 플레이 횟수 4~6개와 필요한 경우 중요 선택 최대 2개만 개인화에 사용합니다.

## 선택과 실패의 규칙

- 작은 선택, 상태를 바꾸는 선택, 중요한 이야기 선택은 영향 범위가 다릅니다. 중요한 선택의 결과는 이후 인물·대화·룬·환경에 남을 수 있습니다.
- NPC 친밀도·호감도 수치는 두지 않습니다. NPC 교류는 만남 횟수와 이야기 진행 단계, 필요한 선택 플래그만 기록하며, 선택 직후에는 선택에 맞는 짧은 반응을 보여 준 뒤 앞선 답을 단정하지 않는 공통 대화로 합류합니다.
- 조우는 몬스터를 처치하는 독립 전투 시스템이 아니라 존재·환경·마법 이상·인물·돌발 사건을 이해하고 풀어 가는 장면입니다.
- 퍼즐과 짧은 조작 활동은 이야기 맥락과 세계의 변화에 연결합니다. 실패에 죽음, 게임 오버, 횟수 제한, 점수 벌점이 따르지 않습니다.
- 힌트는 관찰 대상 → 규칙·원리 → 첫 행동 순으로 점진적으로 제시할 수 있습니다.

## 제작 단위로 볼 때

새 에피소드를 만들 때는 경험 목표, 시작/종료 상태, 중심 갈등, 주요 목표, 이벤트, 단서·지식, 필요한 탐험, 조우·퍼즐, 중요한 선택, 세계 변화, 돌아보기, 기록을 한 묶음으로 점검합니다. 필요하지 않은 요소는 억지로 넣지 않습니다.

## 별도 결정이 필요한 범위

후속 장소별 직접 탐험, 질문 풀과 서버 연결, 아이템 제작·수리의 범위, 장기 성장·보호자용 피드백 형식, 게임 엔진·DB 계약 등은 현재 문서만으로 확정하지 않습니다. 초기 기술 문서의 점수형 리포트와 보이는 성격 수치는 현재 원칙과 충돌하므로 기준으로 사용하지 않습니다.

작성 당시 통합 게임 기획과 초기 세계관의 순환 구조를 참고했습니다. 원문은 현재 저장소에 없어 상세 근거 확인이 필요합니다.
