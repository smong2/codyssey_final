# 게임 콘텐츠 요소

이 문서는 플레이어가 경험할 콘텐츠의 **유형과 연결 관계**를 설명합니다. 모든 유형이 이미 제작·출시되었다는 목록이 아닙니다. 52주 육성 루프와 스탯·이벤트·수집·저장·회차 계승의 최신 상세 기획은 [콘텐츠 상세 기획](content/README.md)을 기준으로 합니다.

## 기본 플레이 흐름

`주인공 선택 → MS01 입학·온보딩 → 52주 동안 평일 5회 주간 일정(수업·모험·휴식·특수 활동)과 메인 이벤트 진행 → 12월 3일 MS05 별빛 축제·수호 룬 최종 해결 → 회복된 학교생활 → 12월 24일 MS06 겨울 놀이회·후일담 → 마지막 자유 플레이 주간 → 12월 31일 마지막 주간 요약 → 무엇을 지켰니? → 미래 직업 엔딩·개인화 편지 → 다음 회차`

생활 화면은 장소의 큰 배경과 인물, 대화·선택·사건에 초점을 둡니다. 직접 탐험은 같은 세계의 장소를 조작 가능한 시점으로 보여줍니다. 한 에피소드에 직접 탐험이 반드시 들어가야 하는 것은 아닙니다.

## 콘텐츠 유형

| 유형 | 플레이어가 하는 일 | 설계 원칙 |
|---|---|---|
| 캐릭터 선택·입학 | 학생의 배경·성향을 살피고 이야기의 주인공을 정함 | 32명의 고유 설정을 보존하고 인물의 장단점을 점수로 평가하지 않음 |
| 장소 생활 | 광장·기숙사·서고·온실 등을 방문하고 인물과 교류 | 기존 아르카디아 장소가 이야기와 활동의 기반 |
| 에피소드 | 하나의 갈등을 발견하고 선택·변화·돌아보기를 경험 | 완결된 이야기 단위이며 탐험과 1:1 관계 아님 |
| 이벤트·사이드 이벤트 | 조건에 따라 짧은 장면과 반응을 만남 | 메인·서브·NPC·지역 이벤트는 평일 일정 슬롯을 소비하지 않으며 자유로운 이벤트는 주말을 우선 활용 가능 |
| 목표 | 현재 할 일을 한 문장으로 이해 | 단순 체크리스트·점수표 중심으로 만들지 않음 |
| 대화·선택 | 사람의 사연을 듣고 현실적인 접근 중 선택 | 모든 대화에 선택지가 필요한 것은 아님; 정답/오답 구도 피함 |
| 탐험·상호작용 | 모험 장소를 직접 이동하고 단서를 이용해 숨은 목표 아이템을 조사·발견 | 플레이어가 직접 발견하되 단서·실패 피드백을 통해 위치를 추론할 수 있게 함 |
| 지식·단서 | 관찰과 대화에서 사실을 알아냄 | 실제 소지품 계약이 있는 일반 아이템은 `가진 것`, 지식은 `알게 된 것`으로 구분. 모험 목표 아이템은 소지품이 아닌 임시 미션 목표 |
| 아이템·소지품 | 재료, 도구, 이야기 물건 등의 후보 자원을 사용 | 실제 보유·획득 인벤토리 계약은 별도 확정 대상이며 모험 목표 아이템을 자동 영구 수집품으로 취급하지 않음 |
| 조우·퍼즐 | 인물·환경·룬 이상 현상을 해결 | 전투·체력 소모가 기본 해법이 아님; 실패는 새 정보를 줌 |
| 세계 변화 | 룬, 식물, 장소, NPC 반응의 차이를 확인 | 별도 점수보다 눈에 보이는 반응으로 성취 전달 |
| 마이룸·기록 | 오늘의 장면·선택을 돌아보고 수집·기록을 확인 | 개인적이고 안전한 공간; 도덕적 채점 금지 |
| 주간 일정 | 월~금 5회의 수업·모험·휴식·특수 활동을 계획하고 수행 | 5칸을 모두 채운 뒤 시작; 시작 전 수정 가능·시작 후 수정 불가; 수업은 체력 10, 모험은 15를 활동 시작 시 소비; 기숙사 `요정의 거래`는 주 1회·체력 0; 토·일은 별도 일정·자동 체력 회복 없이 경과 |

주간 일정 화면에서는 활동을 가장 이른 빈 평일에 순차 배치하거나 달력에서 특정 날짜를 먼저 선택해 배치할 수 있습니다. 등록된 날짜를 누르면 활동명 확인과 일정 삭제가 가능하며, 5칸을 모두 채워야 시작할 수 있습니다. 모험은 등록 단계에서 `유리 온실·약초원 / 대서고 / 별빛 천문대` 중 장소까지 정합니다. 일정 시작 후 월요일부터 금요일까지 한 활동 결과 저장이 성공하면 다음 활동 화면으로 자동 전환하며, 평일마다 마이룸을 경유하지 않습니다. **휴식 일정만 마이룸에서 휴식 방법을 선택하는 활동**으로 처리합니다. 다만 재접속·타이틀의 `이어 하기`는 마이룸을 기본 복귀 허브로 사용해 저장 phase를 판별한 뒤 스케줄 작성 또는 다음 예정 활동으로 연결합니다. 강제휴식은 평일 3일의 기존 일정을 잠긴 `강제휴식`으로 교체하며 주 경계를 넘을 수 있습니다. 새 회차 생성, 일정 확정, 각 활동 시작/완료, 주간 종료, 엔딩 확정을 안정 자동저장 경계로 사용합니다. 비정상 종료 시 시작 체크포인트의 활동은 `INTERRUPTED`로 소비하고 복구 저장 후 마이룸에서 다음 진행을 판별합니다.

본편 공간 콘텐츠는 `별빛 천문대-거울 마법 / 시계탑 광장-별빛 무대 / 유리 온실-정령 화분 정리 / 기숙사-요정의 거래 / 대서고-봉인 서가 / 마도 공방-룬 회로 / 수련장-룬 핀 훈련`으로 확정합니다. 6개 미니게임에는 즉시 재도전을 두지 않고 `포기하기=FAIL`로 처리합니다. 같은 게임을 2회 연속 실패하면 다음 플레이 난이도를 1단계, 4회 이상 연속 실패하면 최대 2단계 낮추되 성장 보상은 원래 `run.stats` 기준 난이도로 계산합니다.

직접 모험 콘텐츠는 **유리 온실·약초원 / 대서고 / 별빛 천문대** 3곳을 사용합니다. 모험 난이도에 따라 숨은 목표 아이템 `1~5개`를 실제 도달 가능한 충돌 영역에 배치하고, 모든 아이템의 시계 방향 단서를 처음부터 공개합니다. 플레이어는 단서를 선택해 추적할 수 있지만 다른 아이템을 우연히 조사해도 발견으로 인정합니다. 탐험 수치 `50 이하`는 120초, `50~500`은 120~240초 선형 증가, `500 이상`은 240초의 이동 시간을 제공합니다. 단서 읽기·조사·NPC/공간 스토리 중에는 타이머를 멈춥니다. 모두 찾으면 `MISSION_COMPLETE`, 시간 초과 시 `TIMEOUT`이며, 실패한 판의 목표 아이템은 일부 발견했더라도 획득하지 않습니다. 대신 발견 비율에 따라 성공보다 작은 탐험 성장 일부를 제공합니다. 상세 흐름은 [공통 엔진 프레임·마이룸·모험 흐름](content/10_COMMON_ENGINE_FRAME.md)을 따릅니다.

모험의 숨은 목표 아이템은 **해당 모험판의 성공 조건용 임시 오브젝트**이며 현재 가방 수집품으로 보관하지 않습니다. 성공한 발견이 기존 배지·엔딩용 `특별 발견/장소 발견` 횟수 통계에 해당하는 경우에는 플레이 기록 카운터만 반영할 수 있지만, 개별 아이템 ID를 영구 인벤토리로 저장한다는 의미는 아닙니다.

메인 스토리는 `1/1 → 3/5 → 6/4 → 9/3 → 12/3 → 12/24`의 해당 주 일정 시작 전에 노출합니다. 최신 확정 시나리오 `story/main/main_final.md`를 기준으로 **12월 3일 `MS05`의 별빛 축제에서 한 해의 최대 위기와 시계탑 수호 룬 문제를 모두 해결**합니다. 이후 49~51주차에는 안정된 학교생활이 이어지고, **12월 24일 `MS06`은 위기 재발이나 추가 해결 없이 친구들과 보내는 겨울 놀이회·후일담**입니다. `MS06` 이후 12월 24~30일은 마지막 자유 플레이 주간입니다. 엔딩에서는 작가의 질문 `무엇을 지켰니?`를 고정 문구로 사용하되 AI가 답을 대신 판정하지 않습니다. 대표 사건 목록은 AI 입력에서 제외하고 실제 플레이 횟수 4~6개와 필요한 경우 중요 선택 최대 2개만 개인화에 사용합니다.

## 선택과 실패의 규칙

- 작은 선택, 상태를 바꾸는 선택, 중요한 이야기 선택은 영향 범위가 다릅니다. 중요한 선택의 결과는 이후 인물·대화·룬·환경에 남을 수 있습니다.
- NPC 친밀도·호감도 수치는 두지 않습니다. NPC 교류는 만남 횟수와 이야기 진행 단계, 필요한 선택 플래그만 기록하며, 선택 직후에는 선택에 맞는 짧은 반응을 보여 준 뒤 앞선 답을 단정하지 않는 공통 대화로 합류합니다.
- 조우는 몬스터를 처치하는 독립 전투 시스템이 아니라 존재·환경·마법 이상·인물·돌발 사건을 이해하고 풀어 가는 장면입니다.
- 퍼즐과 짧은 조작 활동은 이야기 맥락과 세계의 변화에 연결합니다. 실패에 죽음, 게임 오버, 횟수 제한, 점수 벌점이 따르지 않습니다.
- 힌트는 관찰 대상 → 규칙·원리 → 첫 행동 순으로 점진적으로 제시할 수 있습니다.

## 제작 단위로 볼 때

새 에피소드를 만들 때는 경험 목표, 시작/종료 상태, 중심 갈등, 주요 목표, 이벤트, 단서·지식, 필요한 탐험, 조우·퍼즐, 중요한 선택, 세계 변화, 돌아보기, 기록을 한 묶음으로 점검합니다. 필요하지 않은 요소는 억지로 넣지 않습니다.

## 별도 결정이 필요한 범위

일반 아이템/소지품의 실제 획득·보유 인벤토리 계약, 질문 풀과 서버 연결, 아이템 제작·수리의 범위, 장기 성장·보호자용 피드백 형식, 세부 게임 엔진·DB 필드 계약 등은 현재 문서만으로 확정하지 않습니다. 모험 목표 아이템은 이 미정 인벤토리를 요구하지 않고 모험판 내부 임시 목표로 처리합니다. 초기 기술 문서의 점수형 리포트와 보이는 성격 수치는 현재 원칙과 충돌하므로 기준으로 사용하지 않습니다.

작성 당시 통합 게임 기획과 초기 세계관의 순환 구조를 참고했습니다. 원문은 현재 저장소에 없어 상세 근거 확인이 필요합니다.
