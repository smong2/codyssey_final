# UI08–UI10 공통 아이콘

제작 요청서 1.10의 필수 아이콘을 기존 파일 검색 후 제작했다. 기존 그림이나 아이콘을 재생성하지 않았다. 이미지 생성 호출 0회, 직접 작성한 SVG 3개다.

| 번호 | 파일 | 크기 | 기능 |
|---|---|---|---|
| UI08 | [가방](06_images/UI08_가방.svg) | 128×128 | 소지품 열기 |
| UI09 | [발견 기록](06_images/UI09_발견기록.svg) | 128×128 | 발견한 내용 열기 |
| UI10 | [힌트](06_images/UI10_힌트.svg) | 128×128 | 도움말 열기 |

투명 배경, 128 viewBox, 크림·세이지·잉크색과 절제된 금색. 기본 선은 출력 기준 3.2px, 최소 여백 16px. 32~48px 표시를 시험하되 클릭 영역은 UI에서 별도로 확보한다. 선택·비활성 상태는 동일 SVG에 UI 테두리·배경·투명도를 적용한다. 상태별 이미지 파일은 추가하지 않는다. 버튼 접근성 이름은 실제 기능에 맞게 UI에서 제공한다.

XML 및 규격 확인, 실제 PNG 렌더 후 형태·여백 육안 확인을 수행했다. 게임 화면의 대비·터치 조작성은 아직 검수하지 않았다. 렌더 PNG는 임시 검수 자료이며 납품 중복 파일로 추가하지 않는다.
