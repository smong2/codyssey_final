# 10. 무드 수정 시안

이전 MAP01~03은 구조/수집 기능 검토 기록으로 보존하며 무드 기준으로 사용하지 않는다. 이번에는 사용자 요청에 따라 전체맵 1장과 플레이 시안 1장만 생성했다.

- [MAP04 전체맵](../assets/map_images/MAP04_adventure_full_map_mood_concept_003.png): 기존 화단/아치/식물의 크림·세이지·황동·청록 색감과 손그림 질감 참조. 입구, 분기, 조사 화단, 동쪽 약초 구역, 북쪽 룬이 연결된다.
- [MAP05 플레이](../assets/map_images/MAP05_adventure_play_mood_concept_004.png): MAP04의 오른쪽 약초 구역을 참조한 가까운 시야. 카엘 SD와 작은 목표/기록/힌트/백팩 UI.

직접 확인: 두 장의 소재·팔레트 연결, 플레이 시야에서 입구/북쪽 룬 제외, 경계 밖으로 이어지는 길, SD 식별 요소와 한국어 HUD. 식물이 조밀한 정도와 카엘 화면 점유 크기는 사용자 시안 검토 항목으로 남긴다.

이 결과는 아트디렉션 이미지이며 엔진 캡처·정확한 픽셀 크롭·분리 타일셋이 아니다. 생성 참조로 연결했으므로 세부 배치는 픽셀 단위로 같지 않다. 구현 시 같은 타일/오브젝트 데이터로 정확한 전체맵과 카메라를 구성한다. Life 배경을 사용하지 않았다.

생성 원본은 01_art_sources, 1920×1080 정규화 검토본은 00_images에 보존한다. 실제 반환 크기와 해시는 11_art_revision_verification.json 참조. 크기 정규화는 디테일 향상이 아니다. 마이룸은 승인 대기 그대로 유지한다.
