# 08. 공통 UI 재사용 검수 결과

## 실행 결과

- UI08 가방·UI09 발견 기록·UI10 힌트를 각각 32px/48px로 렌더하고 육안 확인했다. 세 아이콘의 외곽 형태는 구별된다. 32px에서는 내부 장식이 작으므로 글자 라벨을 함께 쓰고, 여유가 있으면 48px 표시를 사용한다.
- 원본 SVG 128×128은 변경하지 않았다. 렌더 PNG 6개는 임시 검수 파일이며 저장소 납품 에셋으로 중복 추가하지 않았다.
- [07_ui_review.html](../code/ui_ui_review_008.html)은 기존 UI01·UI02·UI08~10을 참조한다. 이미지/질감 참조 14개 존재 확인, 누락 0개.
- 공통 패널, 기본/선택/비활성 버튼, 48px 이상 클릭 영역, 키보드 포커스 스타일, 긴 한국어 문구, 폭 선택 기능을 구성했다.
- 별도 이미지 생성 호출 0회. 새로운 그림·아이콘·상태별 에셋 없음.
- 최초 저장소 원본 5개와 기존 아이콘 3개의 해시가 보존됐다.

## 아직 검수하지 않은 항목

- 실제 브라우저 360·768·1920px에서 줄바꿈·가로 넘침·포커스 이동·버튼 동작.
- 터치 기기의 조작과 실제 게임 배경 위 대비.
- 실제 플레이 기록 또는 확정 대본. 페이지 문구는 검수 예시일 뿐이다.

HTML 파일을 브라우저에서 열면 기존 에셋을 그대로 비교할 수 있다. 고정 화면 캡처나 게임 구현 완료를 의미하지 않는다. SD·베른·식물 미해결 수정은 이번에 재시도하지 않았다.
