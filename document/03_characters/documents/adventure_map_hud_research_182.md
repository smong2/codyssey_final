# 04. 탐험 화면 정보 조사와 루미아 제안

조사 2026-10-02 / 정리 2026-10-04. 아래는 참고 게임의 사실과 루미아 제안을 구분한 문서다. 수치형 시스템은 사용자 승인 전 확정하지 않는다.

## 비교 사례
|게임|확인한 내용|루미아에 적용할 판단|
|---|---|---|
|Princess Maker 2 Regeneration|공식 소개는 딸의 상태를 파악해 육성 판단을 내리도록 파라미터를 상시 표시한다고 설명한다.|상시 정보는 다음 행동 판단에 필요한 것만. 육성 수치 전체를 탐험 HUD에 복사하지 않는다. 이 출처만으로 모든 탐험 장면의 정확한 HUD 위치/항목을 단정하지 않는다.|
|Stardew Valley|에너지 막대는 도구 사용에 소모되는 자원을 나타낸다. 백팩 전체 목록과 빠른 사용용 hotbar를 구분하고 수량 합치기/나누기를 제공한다.|소모 규칙이 있어야 에너지 표시가 필요하다. 백팩 전체 목록은 열어서 확인하고 자주 쓰는 물건만 추후 단축칸 후보로 둔다.|
|Palia|공식 0.176 패치에서 퀘스트 관련 물건을 인벤토리의 Quest Pouch 탭으로 분리했다. 초기 공식 설계 설명은 생존 행동의 미실행 벌점보다 참여 보상을 강조한다.|중요 사건 아이템과 일반 재료를 구분하는 탭은 확장 후보. 현재는 1종 약초 수집 검토이며, 식사/피로/실패 페널티를 임의 추가하지 않는다.|

## 권장 HUD
엄밀히 말해 목표·위치·백팩은 능력치가 아닌 상태/조작 정보다. 현재 비전투 탐험에서는 수치형 능력치보다 이 정보가 우선이다.

|표시|위치|시점|판정|
|---|---|---|---|
|현재 지역/구역|상단 왼쪽|상시|채택 제안, 시안 반영|
|현재 목표 한 줄|지역명 아래|상시|채택 제안, 시안 반영|
|발견한 단서 수|상단 오른쪽|상시 또는 신규 발견 시|시안 반영. 미발견 총수와 100% 완수 압박은 제외|
|백팩 버튼·새 획득 표시|하단 오른쪽|상시|사용자 요청 반영|
|보관 종류 수 / 개별 수량|종류는 요약, 개별 수량은 백팩 안|백팩 열기|12칸은 시안 배열이며 수집 한도가 아님|
|조사/채집 안내|대상 근처|가까이 갔을 때만|시안 반영|
|획득 알림|상단 중앙|획득 직후 잠시|시안에서는 다음 이동까지 표시, 실제 게임 자동 숨김 예정|
|발견 기록·힌트 버튼|하단 오른쪽|상시|시안 반영|
|에너지/피로/컨디션|상단 작은 막대 후보|소모·휴식 규칙을 승인한 경우만|현재 미채택|
|게임 내 시간대|상단 지역 옆 후보|시간 규칙 확정 후|마이룸 시간대 논의와 연결, 현재 미채택|
|통화/건축 재료|백팩·구입/업그레이드 화면|소비 판단 시|후속 마이룸 계획 승인 대기|
|HP/MP/공격력/경험치/레벨|표시 안 함|관련 규칙 없음|현 시안 제외|
|공감·인성·MBTI 점수|표시 안 함|평가 척도로 만들지 않음|제외|

전체 맵 조립도는 제작자용이며 플레이 중 미니맵 추가 승인을 뜻하지 않는다. 지도와 빠른 사용칸도 현재 필수 요소로 늘리지 않는다.
