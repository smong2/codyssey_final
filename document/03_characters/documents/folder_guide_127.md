# 루미아 제작물 폴더 안내

- assets: 이미지 전용. character_images / item_images / stat_images / background_images / ui_images / effect_images / environment_images / puzzle_images / screen_images / map_images.
- documents: 설명·기획·프롬프트·제작 및 검수 기록.
- code: 미리보기 HTML/CSS/JS, 검수 및 제작 보조 코드.

각 폴더 파일명 끝에 _000부터 연속 번호를 부여합니다. 추가 파일은 마지막 번호 다음에 넣고, 기존 파일 번호는 다시 바꾸지 않습니다. 이번 정리는 이미지를 재생성하거나 수정하지 않습니다. stat_images는 아직 전용 제작 이미지가 없는 예약 카테고리입니다.

기존 기획 원본 5개와 sources는 수정하지 않았습니다. 160개 표정 검토본은 승인 대기이므로 이 저장소 정리에 포함하지 않았습니다.
