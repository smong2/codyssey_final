# 퍼즐 시험 규격

- 3×3 타일, 256×256, 간격 16px: 보드 800×800. 반응형 화면에서는 전체 보드를 같은 비율로 축소한다.
- PZ01 바탕 위에 SVG 한 장을 겹친다. 동일 타일의 활성·비활성 파일은 기하가 같다.
- 직선/곡선/시작/도착은 중앙 (128,128)을 기준으로 90도씩 회전한다. 가장자리 끝점은 중앙 128에 맞춘다.
- 시작은 원, 도착은 마름모로 구별한다. 활성 여부는 게임에서 색뿐 아니라 FX01 또는 짧은 움직임으로 보완한다.
- 연결 경로는 별도 데이터로 판정하며 이 이미지 자체에 정답을 저장하지 않는다. 퍼즐 난이도와 조작 테스트는 미완료다.

래스터 바탕은 내장 이미지 생성 도구, 경로 8종은 직접 작성한 SVG이다.
