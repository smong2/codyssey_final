# 검토 기록
- SVG 10종: 대화창 1280×320 5개, 참조카드 384×448 5개.
- 제목·화자명·본문은 HTML 텍스트로 별도 표시, SVG는 프레임만 포함.
- 참조카드 상단 타이틀 없음, 모든 제목은 참조 이미지 아래에 배치.
- 긴 이름 검사: 발렌티누스 아르카디아 교수 / 빛을 되찾은 온실의 유리꽃. 10종 모두 제목 박스 스크롤 영역 넘침 없음.
- 긴 화자명 검사 모드에서는 글자를 줄여 넣음. 최종에서는 선택된 이름표 크기에 맞는 글자 크기 기준을 확정해야 함.
- 참조 이미지 중앙 그림은 자리 표시용 식물 기호이며 새 아이템 그림이 아님.
- 기존 장식 PNG를 교체하지 않고 위치·비율 판단용으로 간소화한 SVG 프레임을 별도 제작. 승인 후 선택 레이아웃을 기존 장식 톤의 최종 에셋에 반영.
- 온실 기존 배경 위 대화창/카드 선택 조합 제공.
- 로컬 검토만, GitHub 원본/저장본 수정 없음. 사용자 선택 대기.
