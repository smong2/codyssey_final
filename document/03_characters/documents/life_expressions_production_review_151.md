# 제작·검토 기록

## 사용자 확정 분류
01 기존 표정 고정 / 02 경청 / 03 생각 / 04 격려 / 05 안도. 대상: 32인 선택 캐릭터. NPC는 포함하지 않음. 마이룸 5안 GitHub 저장 승인과 캐릭터 검토를 구분함.

## 중복 방지
32개 기존 원본 얼굴을 유지. 카엘·하젤의 이전 변형 6장 재사용. 카엘 04 설명을 격려로, 하젤 03 걱정을 생각으로 수정 생성. 나머지 30명 × 4안 순차 생성. 실패한 파일 경로 확인 1회는 이미지 생성 결과를 만들지 못했으며 이후 Unicode 경로 전달을 수정함.

## 규격 및 승인
변형: 1024×1536 RGBA. 전신 원본은 각 캐릭터의 00_original에 그대로 보존. 사용자 후속 답변에 따라 01 기존상반신 파일을 잘라 내보냈으며 얼굴 재생성은 하지 않음. 얼굴 기준점 정밀 정렬은 시각 검토 단계.
표정·손·얼굴 정체성·의상·외곽은 시각 검토 항목. 생성 완료는 최종 승인이나 엔진 적용 완료를 의미하지 않음.
캐릭터는 GitHub 보관본(최종 채택은 별도 검토), 시안 검토 후 저장.

## 파일 번호
이 폴더의 문서는 00~07, 캐릭터 폴더는 00~31, 각 폴더 파일은 00 목차 / 01 원본 / 02~05 표정 순서. 생성 대기 파일은 실제 생성 후 채워짐.

## 전체 파일 준비 완료
160/160 상반신 PNG 준비. 01 원본 크롭 32장, 02~05 변형 128장(기존 6장 재사용, 신규 122장). 전신 32장 보존. 연결/실행 세션 중단 시 저장된 상태 기록을 대조하여 미완료 항목만 재개함. 엘리아 04의 첫 생성은 출력 필터로 결과가 없었으며, 단정한 상반신 의상/포즈를 명시한 재시도로 생성됨.

크기·파일 준비 검사와 미술 검수를 구분함. 원본 01과 새 변형의 얼굴 크기 정렬, 일부 경청/생각 손 자세 유사성, 머리/소품의 프레임 외곽, 원화에서 이어진 색 번짐은 사용자 검토 후 수정 범위를 정할 항목. 캐릭터는 GitHub 보관본(최종 채택은 별도 검토).
