# 07. 다음 작업안 — 마이룸 시간대와 구입·업그레이드

2026-10-04 / **사용자 확인 대기. 이미지 생성·게임 구현 미착수.**

## 사용자 요청
Adventure에서 하나의 경험을 마친 뒤 My Room에 돌아온다. 창밖에서 시간대를 알 수 있어야 하며 3가지 시간대 이미지가 필요하다. 획득물이 늘고 일정한 달성 조건을 충족하면 My Room을 구입하고 업그레이드할 수 있게 한다.

## 제안하는 범위
1. 시간대: 낮 / 노을 / 밤 3종. 동일한 창틀·시점·바깥 지형을 유지하고 하늘, 빛, 실내 조명만 바꾼다. 기존 My Room 원화에서 분리 가능한 창 영역을 먼저 확인한다. 창밖 3레이어 + 필요한 실내 빛 레이어로 구성해 방 전체 3장 중복 생성을 줄인다. 최종 화면 1920×1080, 창밖 레이어는 확인된 창 영역 실측 후 규격 확정.
2. 시간 흐름: 현실 시각 연동보다 게임 내 경험 진행에 맞춘 시간대 전환을 우선 제안. 밤에 실제 접속해야만 밤을 볼 수 있는 조건은 두지 않는다. 한 경험 완료마다 무조건 시간대가 바뀌는지는 미확정.
3. 주거 흐름: 기본 제공 기숙사 방 → 조건을 달성해 첫 개인 마이룸 구입 → 같은 방의 수납/배치 공간/창가 등 확장. 이는 제안이며 현재 마이룸이 이미 개인 소유인지부터 사용자 확인 필요.
4. 해금과 지불 분리: 경험 완료 등으로 구입 자격을 해금하고, 획득한 일반 재료 또는 게임 내 재화로 비용을 지불하는 안. 요구 수량·가격·단계는 아직 정하지 않는다. 사건 핵심 아이템을 지불 재료로 소모하지 않는다. 현금 결제는 이번 제안에 포함하지 않는다.
5. 필요한 UI: 획득물 보관 목록, 방 구입/업그레이드 미리보기, 현재 단계, 달성 조건, 보유/필요 수량, 부족 상태, 구입 확인, 완료 표시. 회고용 베른과 마음 일기의 공간도 유지한다.

## 승인 후 순서
기존 방/창/가구 실사 → 창 레이어 분리안 → 낮·노을·밤 비교 시안 → 기본 방과 첫 업그레이드 비교 시안 → 조건·비용 UI. 모든 단계의 이미지를 한꺼번에 생성하지 않는다.

## 먼저 확인받을 사항
- 낮·노을·밤 3종과 게임 내 시간 진행을 기준으로 할지.
- 기본 방을 받은 뒤 첫 개인 마이룸을 구입하는 흐름인지, 처음부터 가진 마이룸만 업그레이드하는 흐름인지.
- 업그레이드 비용을 일반 수집 재료로 할지, 별도 게임 재화도 사용할지.

이 문서는 작업 정리일 뿐 승인 기록이 아니다.
