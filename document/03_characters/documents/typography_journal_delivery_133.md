# 승인 타이포그래피 · 기록 UI 전달

2026-10-08 사용자 승인 디자인과 무료 웹폰트 적용 예시.

## 무료 웹폰트 적용

기존 3종 Pretendard / Noto Serif KR / Gowun Batang을 유지합니다. 대제목은 Noto Serif KR 500, 31px, 줄간격 1.5; 설명문은 Pretendard 400, 16px, 줄간격 1.85입니다. 기존 3종 아래에 실제 문구를 사용한 적용 예시를 추가했습니다. 두 폰트가 새로 추가된 종류는 아닙니다.

세 무료 글꼴은 SIL OFL 1.1이며 상업적 웹 사용·임베딩이 가능합니다. 라이선스를 함께 보관하며 글꼴 자체 단독 판매 및 수정 시 예약 이름 조건 등은 각 원문을 따릅니다.

[대제목 라이선스](https://github.com/google/fonts/blob/main/ofl/notoserifkr/OFL.txt) · [본문 라이선스](https://github.com/orioncactus/pretendard/blob/main/LICENSE)

## 저장 범위

- 자체 설계 글꼴 3종 TTF / WOFF2: 각 198 코드 포인트의 시제품이며 완성 한글 폰트가 아닙니다.
- 대화기록 버튼 및 다이어리 5가지: HTML/CSS 기반 인터랙티브 UI와 SVG 아이콘.
- 달력 3가지: 월간 날짜+별도 일정, 주간 카드, 일간 일정.
- 룬 디자인 10세트: 세트당 6글리프, U+05D0~05D5 대응 식별자. 실제 히브리어 번역이 아닙니다.
- 무료 폰트 3종 원본과 라이선스.
