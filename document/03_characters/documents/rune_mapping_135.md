# 히브리어 코드 포인트 대응 창작 기호 10세트

- U+05D0 א / U+05D1 ב / U+05D2 ג / U+05D3 ד / U+05D4 ה / U+05D5 ו
- SVG 기호 ID는 u05d0~u05d5, 코드 포인트와 일대일 대응. 실제 히브리어 문자 모양이나 번역을 대체하는 언어 체계가 아닙니다.
- 각 SVG의 왼쪽부터 위 코드 순으로 배치. 게임의 오른쪽→왼쪽 표시 시 순서를 반전합니다.
- 색은 currentColor로 변경 가능.
