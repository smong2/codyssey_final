2026-10-08. 기존 3종 보존, 신규 검토용 5안. GitHub 반영은 선택 후 진행.

## 공통 비교 규격
- 가로형 1536×1024 요청. 실제 반환 규격은 생성 후 기록.
- 같은 크림 바탕, 동일 비교 문구, 짙은 잉크색. 장식으로 글자의 부족함을 가리지 않는다.
- 주 문구: 마음의 기록 / LUMIA. 소제목: 오늘의 이야기. 인물명: 카엘 · 하젤.
- 이미지 레터링 시안이며 설치 가능한 완성 글꼴 파일이 아니다. 대화문은 승인된 무료 웹폰트 유지.

## 조사와 적용 판단
- [Cormorant 공식 설명](https://github.com/google/fonts/blob/main/ofl/cormorant/DESCRIPTION.en_us.html): 제목용 글자의 획 대비·속공간·세리프 구조 참고. 특정 글꼴 윤곽 복제 없이 독자 레터링 제안.
- [EB Garamond 공식 견본](https://googlefonts.github.io/ebgaramond-specimen/): 고전 서적의 비례와 읽기 리듬 비교.
- [Noto Serif KR 공식 견본](https://notofonts.github.io/noto-docs/specimen/NotoSerifCJKkr/): 한국어 명조 가독성 비교 기준.

위 사례를 새로운 자체 폰트로 표시하지 않는다. 이미지의 작은 글자는 폰트 기능 검증에 사용하지 않는다.
## 추가 조사 · 제목과 본문 분리

- [Google Design, 웹폰트 선택 가이드](https://design.google/library/choosing-web-fonts-beginners-guide): 제목에 개성을 부여하더라도 긴 문장은 익숙하고 명료한 글자로 조합하는 방향. 루미아에서는 디자인 글자를 제목·이름으로 제한하고 대화문을 무료 웹폰트로 유지한다.
- [Type Network, Optical sizes](https://typenetwork.com/articles/inside-the-fonts-optical-sizes): 큰 제목과 작은 본문은 요구하는 획 대비와 세부 구조가 다르다. 큰 제목 시안을 축소했다고 본문용 폰트가 완성된 것으로 판단하지 않는다.

선택 후 결정할 사항: 고정 문구별 최종 레터링, 인물 이름 확장, 작은 크기에서의 획 보정, 벡터 윤곽과 필요 코드 포인트 범위. 현 단계에서는 방향 검토만 진행한다.
