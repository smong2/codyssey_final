**입구 배경 제작용 브리프:** 사용자 제공 아르카디아 배경을 공간 참조로 삼아, 따뜻한 오후의 호숫가 룬 학술 마을 입구를 제작한다. 좌우 담쟁이 석문과 남색 깃발, 중앙의 열린 테라스와 맑은 호수, 먼 아치형 연결로·학원 첨탑, 오른쪽 청록 룬빛의 거대한 고목을 유지한다. 크림색 석재·세이지 식생·호박색 등·부드러운 회화적 질감. UI 중앙 영역은 저대비, 인물·문자·로고·UI 없는 16:9 배경. 전경 장식이 모바일 중앙 크롭의 주요 경관을 막지 않도록 한다. 배경 생성에는 인물 전용 LUMIA-S1을 사용하지 않는다.

## ③ 캐릭터 디자인 시스템

### 공통 미술 방향

**서정적 아카데믹 클래식 판타지:** 오래된 학술 마을의 질서와 청소년의 개성 있는 일상이 공존한다. 가는 잉크 선, 부드러운 수채·색연필 같은 채색, 무광 천과 낡은 가죽, 절제된 황동·은 장식, 작은 식물 문양으로 표현한다. 현대적인 후드·카디건·운동화도 기존 시안의 일부로 유지하며 플라스틱 로고나 전자 화면 대신 룬 공예를 접목한다.

학생은 약 6.5~7등신을 제안한다. 15세는 성숙한 청소년 범위 안에서 조금 짧고 부드러운 얼굴, 18세는 어깨·자세의 안정감으로 구분한다. 모든 여학생을 가늘게, 모든 남학생을 넓게 그리지 않는다. 시안의 다양한 피부색과 곱슬·땋은 머리 질감을 보존한다. 피부색·체형에 MBTI나 도덕적 의미를 부여하지 않는다.

가문은 거대한 왕관이나 새 문장 남발 대신 **한 곳의 작은 상속 표식+재료/마모+사용하는 도구**로 전달한다. 학원 소속은 작은 동일 룬 핀을 가슴 또는 옷깃의 빈 곳에 둔다. 가문 표식의 구체 형상은 아래 DELTA의 신규 제작 제안이다.

### 중복 방지 규칙

비교 축은 실루엣·헤어·복식·대표 소품·팔레트·포즈 6개다. 모든 색과 옷 종류를 32명 사이에서 완전히 배타적으로 만드는 것은 기존 시안과 양립하지 않으므로, **6축의 조합을 고유하게 만들고 가장 가까운 인물끼리 최소 4축을 구별**한다. 같은 MBTI의 남녀를 같은 옷의 성별 변형으로 만들지 않는다.

- 책 계열: 카엘=펼친 전략 고서/짧은 코트, 클레어=잠금 기록책/격자 스커트, 시온=세로 노트/후드, 빅터=평판 점검판/카디건. 책만 바꾸는 디자인 금지.
- 식물 계열: 리네=한 화분/반바지 멜빵, 요한=여러 약초 바구니/앞치마, 하젤=보온병/패딩, 이시스=은펜/긴 학원 코트. 모두 녹색 로브로 통일 금지.
- 지도자 계열: 레온=버건디 정장/대각선, 벨라=짧은 야구형 재킷/붉은 높은 포니테일, 바론=판금과 방패/사각형, 로렌=초록 훈련복/넓은 사다리꼴.
- 공연 계열: 루카=기타/부드러운 조끼, 스텔라=지휘봉/긴 치마바지, 니코=실크햇/연미복, 리코=빛 리본/토끼귀 후드. 공통 별 지팡이로 치환 금지.
- 공방 계열: 유안=작은 유리 연금 도구/청록 셔츠, 아이리스=환형 시공 장치/보라 쌍번, 렌=마석/작업 조끼, 다나=렌치/멜빵 작업복.

관절 뒤쪽에는 겹침 여유 24~48px를 제안하고, 최대 변형 범위에서 빈틈이 보이면 더 보완한다. 팔이 가리는 몸통·머리카락 아래 목·소품 뒤 손바닥을 복원한다. 손과 소품은 잡는 위치를 고정하고, 얼굴은 과도한 메시 변형 없이 패치 교체를 우선한다. 모든 레이어는 같은 원점과 캔버스로 내보낸다.

Idle 시작값: 호흡 3.5~5초/상체 높이 0.5~1%, 눈깜빡임 3~7초 간격/0.12~0.2초, 헤어·천 ±1~2도, 룬 밝기 4~6초의 느린 변화. 발은 고정한다. 각 인물의 주기는 약간 어긋나게 하고 저동작 모드에서는 정지 원화로 전환한다. 원화 생성만으로 이 동작이 완성되었다고 처리하지 않는다.

## ④ 공통 이미지 생성 프롬프트

### 사용 방법과 토큰 절약의 실제 범위

아래 두 LOCK은 이 문서에 한 번만 정의한다. DELTA에서 `LUMIA-S1 / LUMIA-N1`을 참조한다. **이미지 모델이 이 ID를 자체적으로 기억한다고 가정하면 안 된다.** Work에서 이 문서를 읽는 실행 담당자가 해당 LOCK의 실제 내용을 생성 요청에 함께 전달해야 한다. 모델에 공통 문맥이 실제 전달되는 환경에서만 이전 블록 참조를 사용한다.

새 Work 대화의 첫 요청 예:

> 첨부한 LUMIA_DESIGN_BIBLE_v1.0.md를 읽고 LUMIA-S1과 LUMIA-N1을 적용하라. CH01 DELTA와 원본 32인 시안 1행 1열을 참조해 카엘 단독 전신 원화 1장을 생성하라. 생성 도구에는 LOCK 실제 내용과 해당 DELTA를 전달하라. 이번에는 다른 캐릭터나 레이어 시트를 생성하지 말라.

같은 작업에서 후속 요청 예: `동일 LOCK과 승인 스타일 기준 유지. CH02 DELTA, 시안 1행 2열. 세라 단독 전신 1장.`

실제 생성 입력의 논리 구조: **STYLE LOCK 본문 + NEGATIVE LOCK 본문 + 대상 DELTA 1개 + 해당 인물 참조 이미지**. 전체 기획·다른 34개 DELTA를 매번 이미지 도구에 보내지 않는다. MBTI 네 글자만으로 외형을 추론시키지 않는다. 공통 블록화는 작성·관리 토큰을 줄이지만, 도구의 과금·문맥 캐싱·재생성 횟수 감소를 보장하지 않는다. 비용 절감의 중심은 소수 파일럿, 크롭 재사용, 승인본 국소 수정이다.

### STYLE LOCK — LUMIA-S1

> 독자적인 서정적 아카데믹 클래식 판타지 게임용 완성형 캐릭터 원화. 따뜻한 그림책 감성, 섬세하고 안정된 잉크 선, 수채와 색연필 같은 부드러운 채색, 절제된 종이결, 무광 천·가죽·소량의 금속. 기존 32인 시안의 개인별 피부색·헤어·복식·소품 정체성을 유지하며 DELTA로 세부를 명확히 한다. 판타지와 친근한 학원 일상복이 공존한다. 학생은 15~18세의 자연스러운 청소년 약 6.5~7등신; NPC 연령·종·비율은 DELTA 우선. 단독 인물, 정수리부터 신발 끝까지 전신, 앞면 기반 약한 3/4, 얼굴이 읽히는 가슴 높이 시점, 안정된 지지발. 양손과 발의 형태를 명확히 하고 팔·몸·소품 사이에 분리 가능한 간격을 둔다. 작은 학원 룬 핀 1개, DELTA의 대표 소품과 최소 장식만. 좌상단의 따뜻한 확산광, 부드러운 명암, 고유 팔레트 보존, 청록 기반의 작은 룬 광채. 머리·신발·소품 끝까지 사방 6% 이상 여백. 투명 배경 RGBA, 배경·글자·이름표·테두리 없음. 얼굴·앞뒤 머리·팔·의상 끝·소품·FX를 후속 마스킹하기 쉬운 선명한 경계, 자연스러운 완성 일러스트 한 장. FX는 작고 신체 윤곽과 분리. 세로 2:3 구도.

### NEGATIVE LOCK — LUMIA-N1

### 참조 및 수정 규칙

- 32인 시안은 행·열을 DELTA의 ID와 연결한다. 가능하면 원본 해당 칸의 크롭을 참조로 전달한다. 전체 시안만 전달할 경우 인물 위치를 명확히 지정한다.
- 시안의 작은 크기로 판독되지 않는 세부는 이 문서의 제안값으로 고정한다. 원문과 실제 충돌하는 후속 [03]이 확인되면 해당 ID만 변경 이력을 남긴다.
- 투명도 옵션이 있으면 프롬프트와 함께 활성화한다. 지원하지 않으면 단색 배경 출력 후 정밀 마스킹하고 가장자리 QA를 수행한다.
- 수정 요청은 `승인 원화 참조, 얼굴/피부/헤어/의상/구도 유지. [변경 부위]만 [목표]로 수정` 형태로 한다. 수정 뒤 기존 부위가 변하지 않았는지 재검사한다.

### 생성 순서

1. **기준 묶음 준비:** 이 문서, 사용자가 지정한 데스크톱 폴더의 기획 마스터와 원본 32인 시안, 공통 톤 문서. 인물별 시안 위치와 ID를 확인한다. 현재 제작은 이 원본을 기준으로 실행한다. 이후 다른 [03] 파일이 제공될 경우 변경된 ID만 대조한다.
2. **파일럿 4명, 각각 1장:** 카엘(학원 일상복·책), 엘리아(짙은 피부·긴 머리·긴 드레스), 바론(판금·방패), 티아(15세·반투명 FX). 같은 비율·빛·질감과 다른 체형/소재를 동시에 확인한다. 4인 합동 이미지를 생성하지 않는다.
3. **LOCK 고정:** 얼굴 가독성·선·채도·전신 비율을 비교해 S1을 필요 시 S2로 수정한다. 4명 모두를 매번 재생성하지 않고 실패한 항목만 수정한다. 이후 사용할 승인 원화 1~2장을 스타일 참조로 지정하되 대상 캐릭터의 외형을 복제하지 않도록 인물 참조와 구분한다.
4. **나머지 28명:** 혼동 가능 그룹별로 단독 생성 후 나란히 비교한다. 학술/지도=세라·시온·로엔·레온·벨라·클레어·빅터·로렌(8), 식물/돌봄=리네·요한·하젤·아드리안·테오·미리엄(6), 공방=유안·아이리스·렌·다나(4), 예술/모험=에녹·루카·스텔라·로빈·미엘·실비아·카일·제나·니코·리코(10).
5. **NPC 3명:** 이시스→발렌티누스→베른. 이시스/카엘, 교수/학생, 베른/생물 부엉이의 혼동을 별도 검사한다. 기본 생성 계획은 총 35회 단독 원화 요청이며, 실패 수정·레이어 제작은 별도다. 실제 비용·횟수는 도구와 출력 품질에 따라 달라진다.
6. **35인 비교판:** 승인 원화를 축소 합성해 만든다. 비교판 자체를 다시 생성하면 인물 정체성이 변하므로 하지 않는다. 인물별 크기 차이를 확인하는 공통 신장 척도판과 동일 카드 면적의 가독성판을 구분한다. 베른은 사람 크기로 확대하지 않는 척도판도 필요하다.
7. **정체성 잠금 후 파생:** 카드·초상·상반신은 원화에서 파생. 표정은 얼굴 영역만 편집. 다음으로 마스킹·숨은 부분 보완·눈 패치·리깅·FX 분리를 진행한다.
8. **실제 화면 검증:** 밝은 미리보기 배경, 어두운 사건 배경, 작은 선택 카드, 모바일 폭에서 확인한다. 첫 검증 캐릭터 한 명의 Idle을 끝낸 뒤 나머지에 분리 규격을 적용한다.

### 합격 기준

#### A. 설정과 정체성

- [ ] 16 MBTI×남녀 2명=32명, 중복 ID·이름 누락 없음. NPC 3명은 별도다.
- [ ] 학생 나이는 원문과 일치한다. 이시스 19세·교수 60대·베른 오토마톤 예외가 유지된다.
- [ ] 얼굴·피부·헤어·주요 복식·소품이 해당 시안의 인물과 연결된다.
- [ ] 역할과 가문이 소품/작은 표식으로 읽히고, 가문 배경이 명시되지 않은 NPC에 임의 귀족 설정을 넣지 않았다.
- [ ] 장점과 약점의 긴장이 표정에 남는다. 모든 인물이 같은 활짝 웃는 얼굴이 아니다.
- [ ] MBTI를 외모·피부색·성별·도덕성의 고정관념으로 표현하지 않는다.

#### B. 독자성·중복

- [ ] 특정 기존 작품의 캐릭터·문장·의상·작가 화풍 복제 지시가 없다.
- [ ] 검정 실루엣만으로 가장 가까운 두 인물을 구분할 수 있다.
- [ ] 가장 비슷한 쌍에서 6축 중 최소 4축이 다르다. 실패 시 가장 싼 수정 축부터 고친다: 소품 위치/포즈→의상 끝선→헤어 세부. 원본 주요 외형 변경은 마지막 수단이다.
- [ ] 흑백 축소에서도 헤어와 명도 덩어리가 달라 색상만으로 인물을 구별하지 않는다.
- [ ] 해당 DELTA의 금지 중복 요소가 들어오지 않았다.

#### C. 전신 원화 품질

- [ ] 머리·발·모자·날개·활·검·리본이 모두 프레임 안에 있고 여백이 있다.
- [ ] 손가락/관절/접지/소품을 잡는 방식이 자연스럽다. 베른의 날개 집게 구조가 읽힌다.
- [ ] 15세 캐릭터가 유아화되지 않고 18세가 성인 장군처럼 노화되지 않았다.
- [ ] 얼굴·양손·대표 소품이 빛이나 머리카락에 가리지 않는다.
- [ ] 배경은 실제 알파다. 회색 체크무늬·크림 배경·후광 테두리가 픽셀로 남지 않았다.
- [ ] 따뜻한 밝은 배경과 짙은 배경 위에서 흰 테두리·색 번짐·마스크 구멍이 없다.
- [ ] 글자·워터마크·로고·불필요한 마법진·추가 소품이 없다.

#### D. 레이어와 Idle

- [ ] 승인 원화와 레이어 합성 결과가 일치한다. 편집 원본과 레이어 PNG가 실제 존재한다.
- [ ] 모든 레이어 캔버스·원점이 같고 눈/입 패치가 정확히 정렬된다.
- [ ] 가려졌던 몸·목·손·머리 뒤가 보완되어 최대 움직임에서도 빈틈이 없다.
- [ ] 손과 도구가 따로 미끄러지지 않고 발은 바닥에 고정된다.
- [ ] 눈깜빡임 시 눈썹·안경·눈 테두리가 튀지 않는다. 안경/렌즈는 별도 취급한다.
- [ ] 호흡 때문에 얼굴 크기·가슴·의상 문양이 과도하게 변형되지 않는다.
- [ ] 머리·망토·리본·FX가 서로 관통하지 않는다. 티아의 날개는 몸 뒤 FX로 분리된다.
- [ ] 모션 중단 시에도 완성 원화로 자연스럽고, 저동작 모드에서 안정된 정지 화면을 제공한다.

#### E. 화면·성능·파일 관리

- [ ] 480×640 카드와 작은 얼굴 초상에서 인물과 표정이 구별된다.
- [ ] 모바일 크롭에서 모자·날개·활이 잘리지 않으며 텍스트/선택 상태가 읽힌다.
- [ ] 배경은 인물보다 대비가 낮고 룬 효과가 대사·선택지를 가리지 않는다.
- [ ] 선택 상태를 산호색만으로 전달하지 않고 테두리·체크 등으로 보조한다.
- [ ] 파일명·버전·참조·LOCK·DELTA·실제 생성 설정·승인 이력이 기록되어 있다.
- [ ] 게임에는 필요한 크기로 줄인 파일을 쓰고, 35인 고해상도 원화를 한꺼번에 GPU에 올리지 않는다. 2048×3072 RGBA 한 장은 비압축 약 24MiB이므로 실제 기기에서 지연 로딩과 메모리를 측정한다.
- [ ] 파일 바이트 용량·알파·색 프로필·크롭·리그 최대 변형·대상 브라우저의 렌더링을 확인했다. 웹에서의 동작 검증 전에는 “게임 적용 완료”로 표시하지 않는다.

### 실패 처리와 기록

실패 등급: **차단**=잘못된 인물/나이/성별, 손·해부 오류, 얼굴 변화, 주요 소품 누락, 크롭; **수정**=색/표정/문양/작은 경계 문제; **후속 공정**=레이어 분리·패치·리깅 미완료. 차단 항목은 파생 제작 전에 해결한다. 후속 공정을 이미지 생성 실패로 취급해 전신을 반복 생성하지 않는다.

관리표 열: `ID | 원문 검증 상태 | 시안 위치 | DELTA 버전 | 원화 상태 | 최근접 비교 ID | 6축 차이 | 수정 항목 | 레이어 상태 | Idle 상태 | 납품 경로`.

이 문서는 **사용자가 지정한 원본 폴더를 대조한 35종 기본 원화 제작 제안본**이다. 이미지 생성·PSD 분리·애니메이션 자체는 이 문서 작성 범위에서 수행하지 않았다. 프롬프트만으로 재작업 0회를 보장할 수는 없으며, 파일럿과 국소 수정을 통해 재작업 범위를 줄인다.
