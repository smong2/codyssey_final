- 온실 배경·카엘 RGBA·6종 실제 폰트·1안 이름 원본 모두 재사용. 이미지 생성 0회.
- 기존 원화는 화면에서 확대·클리핑만 적용. 이름은 1안 카엘 레터링의 고정 영역을 SVG 뷰포트로 표시하며 원본 PNG를 수정하지 않음.
- 이름 옆 가운데점은 이름 표시 영역에서 제외. 캐릭터 옆과 대화창 이름칸에 동일하게 적용.
- 6개 서체 카드를 실제 클릭해 각각의 본문 font-family와 표시 이름, 선택 상태 1개를 확인.
- 38px 선택 상태에서 대화문이 대화창 안에 들어가는지 확인. 34px로 복귀.
- 대화문은 자체 3종 지원 목록과 대조했으며 미지원 문자가 없음. 198자 범위를 넘어 일반 대사를 입력하면 별도 폰트 작업이 필요.

- GitHub 및 보호된 원본 파일 변경 없음. 검토용 화면만 제작.
