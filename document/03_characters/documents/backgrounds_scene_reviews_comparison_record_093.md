# 마이룸 실제 에셋 배치 비교

- [06_actual_asset_comparison.html](../code/backgrounds_scene_reviews_actual_asset_comparison_007.html): 목표 시안/기존 에셋 배치 전환. 이미지 경계 표시.
- [05_layer_layout.json](backgrounds_scene_reviews_layer_layout_092.json): 1920×1080 기준 위치·폭·앞뒤 순서. 모든 소스 경로 연결.
- 신규 이미지 생성 0회. 기존 배경·책상·의자·침대·러그·램프·일기·베른은 파일 변경 없이 참조한다.
- 참조 9개 존재 확인. 최초 원본 5개 해시 보존 확인.
- 브라우저 렌더·조작 검수 미실행. 초기 배치 수치는 조정 후보이며 완성 게임 장면 승인본이 아니다.

목표 시안은 미술적으로 통합된 화면이고, 이 HTML은 원본의 실제 투명도·시점을 보여주는 검수 도구다. 후광·원근·가림·접지 문제를 숨기기 위한 이미지 필터나 마스크는 없다. 이 비교를 기준으로 필요한 원본 수정만 선정한다.
