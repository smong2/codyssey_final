# 이미지 크기 점검 및 후속 제작 목록

기준: 현재 저장된 PNG 62장 직접 실측, 00_design_spec.md의 A01~F03 전 항목, 공통 UI 에셋 규격, 실제 파일 매칭표. 이번 작업은 점검·제작 계획이며 기존 이미지를 확대·수정하거나 새 이미지를 생성하지 않았다.

## 1. 실제 크기와 통일 여부

| 분류 | 실측 | 수량 | 분류 내 통일 | 기존 명세 대비 |
|---|---|---:|---|---|
| 학생 전신 | 1024×1536 | 31 | 엘리아 제외 동일 | 원화 목표 2048×3072 미달 |
| CH10 엘리아 | 1024×1535 | 1 | 높이 1px 부족 | 규격 정리 필요 |
| 아이템·가구 | 1254×1254 | 20 | 모두 동일 | 이 크기를 소품 납품 기준으로 고정 |
| 배경 | 1672×941 | 10 | 모두 동일 | 목표 2560×1440 미달, 정확한 16:9도 아님 |

[파일별 실측 결과](03_size_audit.json). 같은 픽셀 크기라는 사실은 인물 발 기준선·소품 점유율·가구 시점·알파 품질까지 통일됐다는 뜻은 아니다.

## 2. 앞으로의 카테고리별 고정 규격

단위 px. 아래는 **최종 납품 규격**이다. 생성 도구가 요청한 픽셀 크기를 그대로 반환한다고 가정하지 않는다. 생성 직후 실제 값을 읽고 불일치하면 원본을 보존한 채 후처리/편집 대기로 기록한다. 규격이 다르면 납품 완료로 표시하지 않는다.

| 분류 | 최종 규격 | 형식·적용 기준 |
|---|---|---|
| 학생·NPC 전신 마스터 | 2048×3072 | 투명 PNG, 기존 명세 유지. 고해상도 미확보 상태를 숨기지 않음 |
| 학생·NPC 웹용 전신 | 1024×1536 | 투명 PNG/WebP. 베른도 같은 캔버스, 몸집은 합성 크기로 조절 |
| 캐릭터 레이어·표정 패치 | 마스터 2048×3072 / 웹용 1024×1536 | 각 세트 내 동일 캔버스·좌표, 투명 PNG. 얼굴 패치도 전신 좌표 유지 |
| 선택 카드 | 480×640 | 승인 전신에서 파생 |
| 얼굴 초상 | 512×512 | 승인 얼굴 크롭, 얼굴 중심·여백 통일 |
| 대화용 상반신 | 800×1200 | 투명, 원화에서 파생 |
| 단독 아이템·가구·환경 소품 | 1254×1254 | 투명 PNG, 사방 여백과 실제 배치 크기 별도 기록 |
| 인벤토리 아이콘 | 256×256 | 승인 소품에서 파생, 작은 크기 가독성 확인 |
| 배경·배경용 오버레이 | 2560×1440 | 정확한 16:9, 배경 불투명 / 오버레이 투명 |
| 양피지 타일 | 512×512 | WebP, 이음새 검수 |
| UI 프레임 모서리 | 192×192 | 투명 PNG, 좌상단 1개를 회전 재사용 |

| 전신 미리보기 배경 | 800×1200 | WebP, 인물 없음 |
| 룬 문장·개인 룬·가문 표식 | 256×256 | SVG 원본 우선, PNG가 필요하면 동일 크기로 내보내기 |
| 재사용 FX 텍스처 | 512×512 | 투명 PNG, 실제 효과는 코드/리그 조합 |
| 선택적 버튼 질감 | 600×160 | 투명 PNG, 9-slice, 글자 별도 |
| 지도·로고·시스템 아이콘 | SVG viewBox 고정 | 래스터 생성 대상 아님, 매체별 내보내기 별도 |

기존 학생 32장과 배경 10장은 생성 원본으로 보존한다. 엘리아의 웹용 납품본은 이미지 늘이기보다 투명 캔버스 1px 보충으로 정리할 수 있다. 다른 배경·고해상도 마스터는 단순 확대를 세부 묘사 개선으로 표현하지 않으며 필요한 편집/재생성과 품질 검수를 거친다. 현재 그 보정 작업은 미실시다.

## 5. SVG·UI 구현 대상으로 남아 있는 작업

- E01: 타이틀 로고, 학원 문장 — 각각 독립 벡터 원본.
- B08: 아르카디아 지도 — 장소 노드·연결선 SVG, 위치 이름은 UI 텍스트.
- E03~E09: 캐릭터 선택, 대화·선택·관계, 탐색·의뢰·인벤토리, 마이룸 배치·일기, 부모 리포트, 공통 시스템/접근성 상태.
- 이전·다음·닫기·정보·설정·소리·도움·저장·불러오기 아이콘, 로딩·빈 상태·오류·연결 끊김, 포커스·눌림·비활성·선택·저동작.
- 이미지 버튼은 기본 제작 대상 아님. 필요할 때 UI06_버튼_질감.png 600×160만 추가.
- PC/모바일 UI를 통째로 이미지로 생성하지 않는다. 기존 공통 재료를 재사용한다.

## 6. 에피소드·출시 계획에 따라 추가할 후보

아래는 미제작이지만 현재 즉시 생성할 확정 큐와 구분한다. 수량을 지어내어 누락 없음으로 단정하지 않는다.

- B09: BG13_음악당, BG14_아틀리에, BG15_마음_치유실, BG16_성소, BG17_숲길 — 최대 5곳, 사용 에피소드 확정 후 2560×1440.
- B10: 낮/저녁/밤, 계절, 그림자·정화 상태 — 필요한 장소·상태 조합만 편집/오버레이로 제작.
- A06: 사건별 특별 포즈·의상 — 해당 인물 원화 기준 편집.
- C05: 단서·편지·의뢰·보상 — 기존 양피지와 글자 재사용, 고유 물건만 추가.
- F01: 첫 진입 안내·세계관 삽화 — 기존 배경·인물 합성 우선.
- F02: 갈등·화해·축제·엔딩 삽화 — 대본의 장면 목록이 있어야 파일명·수량 확정 가능.
- F03: 키비주얼·배너·앱 아이콘 — 출시 매체와 비율 확정 후 파생. 규격 미정 상태에서 임의 생성 금지.
