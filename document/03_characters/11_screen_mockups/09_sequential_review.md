## 유지/변경
- MAP04/05의 톤앤매너는 사용자 긍정 확인. 맵 규모와 전체 구성이 승인된 것은 아니다.
- Adventure는 Life와 별도 공간. SD는 Adventure에서만 사용한다.
- 전체 탐험을 작은 중정 하나에 압축하지 않는다. 입구 → 이동 회랑 → 조사 구역 → 약초 구역 → 단서 구역 → 사건 중심부가 여러 카메라 화면에 걸쳐 이어진다. 기존 온실 소재를 반복 활용하고 새로운 지역 테마·전투·기능은 추가하지 않는다.
- 공간 가안: 1920×1080 카메라의 가로 6배·세로 4배에 해당하는 11520×4320 월드 범위(24 화면 면적). 실제 화면은 약 4.2%를 보여준다. 이는 검토용 제안이며 최종 타일 크기나 이동 시간 확정이 아니다. 경로는 굴곡과 분기, 구역 사이 가림을 두며 불필요하게 긴 빈 길로 늘리지 않는다.
- 큰 맵 조감도는 동선 검토 자료다. 실제 플레이는 타일·오브젝트로 구성한 월드를 카메라가 따라간다.
- 검토 이미지 기준 1920×1080, 16:9. 생성 원본 크기는 별도 기록하고 기존 에셋은 덮어쓰지 않는다.
