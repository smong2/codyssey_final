# 마이룸 완성 화면 시안 — 사전 명세

- 사용자 요청: 기존 제작 아이템이 2.5D 화면에서 어우러지는지 확인할 완성 시안 1컷. 다른 작업보다 우선.
- 화면: 마이룸 Life 정적 장면, 16:9, 납품 1920×1080, 불투명 PNG.
- 참조: BG03 배경, NPC03 베른, IT07 책상, IT09 침대, IT08 의자, IT11 러그, IT02 룬 램프, IT01 마음 일기.
- 기존 파일을 직접 확인. 원본 변경·덮어쓰기 없음. 개별 아이템 재생성 아님.
- 한 공간의 원근·스케일·왼쪽 창 광원·바닥 접지 그림자·전후 가림을 통일한 장면 편집 1회.
- 배치: 책상/일기는 창가 왼쪽, 침대는 뒤쪽 오른쪽, 러그는 중앙, 베른은 중앙 오른쪽 전경. 이동 통로와 화면 하단 여백 확보.
- 화면 UI는 최소화. 장면 감상과 가구 조화가 우선. 별도 SD 캐릭터·전투 HUD·점수 표시 없음.
- 결과는 아트디렉션 목표 시안이다. 원본 픽셀을 그대로 엔진에 합성한 실행 스크린샷 또는 투명도 문제 해결 증거가 아니다.
