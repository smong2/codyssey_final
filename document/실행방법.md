# LUMIA 실행방법

이 문서는 향후 통합 게임의 공식 실행 안내를 기록할 자리입니다. 현재 [engine/](../engine/)에는 엔진 코드가 없고 [backend/](../backend/)와 [lumia/](../lumia/)도 작업 공간만 준비되어 있어, 아래 값을 확정된 명령으로 채우지 않습니다. 각 담당자가 실행 방식을 결정하면 실제 검증한 명령과 확인 날짜를 기록하세요.

## 실행에 필요한 환경

미정. 지원 OS, 런타임·버전, 필수 도구를 기록합니다.

## 설치 방법

미정. 저장소 복제 후 설치 명령과 의존성을 기록합니다.

## 실행 명령

미정. 게임·서버별 명령과 실행 위치를 구분하여 기록합니다.

## 개발 서버

미정. 시작 명령, 접속 주소, 재시작 방식을 기록합니다.

## 테스트 실행

미정. 단위·통합 테스트 명령과 기대 결과를 기록합니다.

## 환경 변수

미정. 변수 이름, 용도, 예시 파일 위치를 기록합니다. 비밀값 자체는 문서나 저장소에 넣지 않습니다.

## 포트

미정. 기본 포트와 변경 방법을 기록합니다.

## 종료 방법

미정. 프로세스 종료 및 정리 절차를 기록합니다.

## 갱신 규칙

엔진 담당자가 실행·설치·테스트 방식을 변경하면 이 문서도 같은 작업에서 갱신합니다. 백엔드 실행 절차가 결정되면 해당 담당자와 조율해 구분하여 기록합니다. 실행 명령은 실제 파일과 동작을 확인한 후에만 확정합니다.
