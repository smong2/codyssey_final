# LUMIA 실행방법

이 문서는 통합 게임의 공식 실행 안내를 기록할 자리입니다. 현재 통합 게임의 실행 방법은 미정입니다. 다만 [engine/minigame-demo/](../engine/minigame-demo/README.md)에 독립 실행형 Phaser 3 미니게임 데모가 있으며, 아래 데모 명령은 2026-10-11에 검증했습니다. 이 명령을 통합 게임 실행법으로 혼동하지 마세요. [backend/](../backend/)와 [lumia/](../lumia/)의 실행 절차도 담당 영역에서 확정해야 합니다.

## 실행에 필요한 환경

통합 게임: 미정. 미니게임 데모: Node.js가 필요하며 별도 패키지 설치는 필요하지 않습니다. Phaser 배포본은 데모 폴더에 동봉되어 있습니다.

## 설치 방법

통합 게임: 미정. 미니게임 데모: 설치 명령 없이 저장소 파일만으로 실행합니다.

## 실행 명령

미니게임 데모는 저장소 루트에서 `node engine/minigame-demo/server.mjs`를 실행합니다. 통합 게임 명령은 미정입니다.

## 개발 서버

미니게임 데모: `http://127.0.0.1:4174/`. 소스 변경 후 브라우저를 새로고침하면 됩니다. 통합 게임 서버는 미정입니다.

## 테스트 실행

미니게임 데모: `cd engine/minigame-demo && npm test`. 7종 게임의 순수 로직 테스트가 통과해야 합니다. 통합 엔진 테스트는 미정입니다.

## 환경 변수

미니게임 데모: 비밀값 없음. `LUMIA_MINIGAME_PORT`로 로컬 포트를 변경할 수 있습니다. 통합 게임 변수는 미정입니다.

## 포트

미니게임 데모 기본 포트: `4174` (127.0.0.1 전용). 예: `LUMIA_MINIGAME_PORT=4175 node engine/minigame-demo/server.mjs`. 통합 게임 포트는 미정입니다.

## 종료 방법

미니게임 데모 서버는 실행 터미널에서 `Ctrl+C`로 종료합니다. 통합 게임 종료 절차는 미정입니다.

## 갱신 규칙

엔진 담당자가 실행·설치·테스트 방식을 변경하면 이 문서도 같은 작업에서 갱신합니다. 백엔드 실행 절차가 결정되면 해당 담당자와 조율해 구분하여 기록합니다. 실행 명령은 실제 파일과 동작을 확인한 후에만 확정합니다.
