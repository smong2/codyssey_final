# LUMIA 실행·배포 방법

최종 사용자는 별도 설치 없이 **Vercel에 배포된 LUMIA 웹 주소**로 접속합니다. 게임 클라이언트는 Vercel에서 제공하고, 백엔드 API는 Render의 FastAPI Web Service로 운영합니다. 실제 배포 URL은 배포 완료 후 이 문서와 루트 README에 기록합니다.

## 실행에 필요한 환경

최종 사용자에게 별도 실행 환경은 필요하지 않습니다. Chrome, Edge, Safari 등 현대적인 웹 브라우저에서 Vercel 주소로 접속합니다.

개발 환경은 게임 클라이언트에 Node.js, 백엔드에 Python이 필요합니다. 정확한 버전과 로컬 명령은 통합 코드가 들어올 때 실제 설정 파일을 기준으로 확정합니다.

## 설치 방법

최종 사용자는 설치하지 않습니다. 개발자용 설치 절차는 최종 통합 코드 구조 확정 후 기록합니다.

## 실행 명령

운영 서비스는 Vercel URL 접속으로 실행합니다. 별도 서버 명령을 사용자가 실행하지 않습니다.

독립 미니게임 데모는 저장소 루트에서 `node engine/minigame-demo/server.mjs`로 계속 실행할 수 있지만, 이는 최종 LUMIA 실행 방법이 아닙니다.

## 개발 서버

운영 프론트: `https://<vercel-service>.vercel.app` 형태의 주소를 사용하며 실제 URL은 배포 후 기록합니다.

운영 API: `https://<render-service>.onrender.com` 형태의 주소를 사용하며 게임 클라이언트 내부에서 호출합니다. 일반 사용자가 API 주소를 직접 사용할 필요는 없습니다.

## 검증

최종 사용자 실행 안내에 별도 테스트 명령은 두지 않습니다. 구현 과정의 자동 테스트·통합 검증 명령은 해당 코드 영역에서 관리합니다. 현재 독립 미니게임 데모에는 `cd engine/minigame-demo && npm test`가 존재합니다.

## 환경 변수

운영 환경변수의 기준 목록은 [기술 스택](10_TECH_STACK.md)을 따릅니다.

- Vercel: `VITE_API_BASE_URL`, Firebase Web App 설정
- Render: `CORS_ORIGINS`, Firebase Admin 자격 증명, `GEMINI_API_KEY`, `GEMINI_MODEL`, `GEMINI_THINKING_LEVEL`

API 키·서비스 계정 같은 비밀값은 Git에 커밋하지 않습니다.

## 포트

운영 서비스의 외부 포트는 Vercel/Render가 관리합니다. Render FastAPI는 배포 시 플랫폼이 제공하는 `$PORT`를 사용합니다. 미니게임 데모만 로컬 기본 포트 `4174`를 사용합니다.

## 종료 방법

웹 게임은 브라우저 탭을 닫아 종료합니다. Render/Vercel 운영 서비스의 시작·종료는 배포 플랫폼에서 관리합니다.

## 갱신 규칙

실제 Vercel·Render 서비스가 생성되면 URL을 이 문서와 루트 README에 기록합니다. 엔진 또는 백엔드의 로컬 실행 방식이 확정되거나 바뀌면 실제 설정 파일과 검증 결과를 기준으로 갱신합니다.
