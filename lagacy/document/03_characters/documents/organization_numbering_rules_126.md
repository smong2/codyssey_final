# 01. 각 폴더의 00 시작 번호 규칙

2026-10-05 · dev-jw · 사용자의 최신 지시로 이전 혼합 번호 규칙을 대체한다.

1. **하위 폴더 번호와 파일 번호를 별도로 매긴다.** 각 그룹은 00부터 시작하고 01, 02, 03 순서로 연속된다. 파일 번호 때문에 폴더 번호가 05 또는 10으로 건너뛰지 않는다.
2. 모든 깊이에 적용한다. 제작 루트도 00_design, 01_characters, 02_items…11_adventure_map, 12_organization 순서다. 각 폴더 안에 들어가면 다시 00부터 시작한다.
3. 안내 파일은 00_README.md다. 파일 순서는 00_README, 01 안내, 02 이후 자료로 이어진다. 폴더가 먼저 표시되는 탐색기와 GitHub에서도 각 그룹의 순서가 그대로 보인다.
4. 이미지·프롬프트·원본 보관본·내보내기 파일도 00부터 연속 번호를 갖는다. 예: 00_CH01_카엘.png. CH01은 캐릭터 ID이고 앞의 00은 해당 폴더의 정렬 번호다. 고유 ID·이름·상태·버전을 번호 뒤에 보존한다. 이미지 내용은 바꾸지 않는다.
5. 제공 문서의 제작 폴더 내 사본은 파일명 앞의 정렬 번호만 바꾸고 본문을 보존한다. 저장소 원본 README.md 및 document/01_project_overview.md, 02_worldview.md, 03_characters.md, 04_tech_stack.md와 프로젝트 sources/는 수정·이동하지 않는다.
6. 새 하위 폴더는 폴더 그룹의 마지막 번호+1, 새 파일은 파일 그룹의 마지막 번호+1을 사용한다. 해당 그룹이 비어 있으면 00을 사용한다. 다른 그룹의 번호를 합산하지 않는다. 같은 그룹에서 중복·빈 번호를 만들지 않는다.
7. 이동할 때 링크·목록·동적 이미지 경로·폴더 목차를 함께 갱신한다. 전체 폴더/파일 그룹의 00 시작·연속 번호, 이미지 해시, 원본 보호, 시안 이미지 로딩을 검사한 뒤 dev-jw에 저장한다.
