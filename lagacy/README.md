# 이전 자료 보관소

이 디렉터리는 새 문서를 만들기 전 자료를 원래의 묶음대로 보존합니다. 자료 삭제나 과거 결정의 재승인을 뜻하지 않습니다.

- `docs/`: 통합 기획, 디자인 가이드, 작업·검수 기록
- `document/`: 초기 개요·세계관·캐릭터·기술 제안, 제작 문서·이미지·코드, PDF
- `LUMIA_AI_HANDOFF.md`: 이전 AI 인계 초안. 일부 이미지 경로가 현재 구조와 다를 수 있습니다.
- `README_original.md`: 이전 루트 안내
- `rumia_doc.zip`: 기존 압축 자료

새 팀 문서는 [문서 안내](../document_new/00_README.md), AI 시작 문서는 [AI 시작 지침](../document_for_ai/00_READ_FIRST.md)을 사용하세요. 이곳의 기술 제안·후보 이미지·작업 기록은 현재 확정 사항과 구분하여 읽어야 합니다.
